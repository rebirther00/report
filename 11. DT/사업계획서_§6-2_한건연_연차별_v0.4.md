# 사업계획서 §6-2 한건연 1·2·3·4차년도 연차별 계획 v0.4

> 변경 사유 : 가이드 v0.3 §6-2를 4대항목 구조 (합성 데이터 / AI 정책 / Sim2Real / 실차 수집·시험 환경) 로 재정리.
>  (a) 사용자 검토(2026-05-21) 반영 — 4대항목 + 단계 분리 명확화 (PoC → 사전학습 → 본격 학습 → 통합 검증),
>  (b) 2·3차년도 "실차 1차 전이 시험" 중복 해소 — 2차 = 저정밀 가상모델 기반 샘플 시연 검증, 3차 = 정밀 모델 기반 1차 전이 시험으로 단계 분리,
>  (c) 외부 베드 단서 본문 유지 — 3차 (새만금 마사토·나포 자갈), 4차 (나포 자갈 ADT 협업 시연),
>  (d) 4차년도 4단계 캠페인 (Bench → 평탄지 → 다양 지형 → 야간·위험지) 키워드 §6-5 KPI 측정 절차와 본문 일치,
>  (e) Algoryx 단계 분리 — 1차 PoC·구축 / 2차 사전학습 환경 구축,
>  (f) 책임 경계 단서 유지 — Omniverse 인프라 운영·NTP/PTP·통신 정밀튜닝은 주관(심지), 한건연은 AI 학습 주체 + 통신 구성·검증 + 시험장 정비 + 실차 수집.
> 연계 : 본 문서는 가이드 v0.3 §6-2 1·2·3·4차년도를 4대항목 구조로 대체. v0.3의 짚어둘 점·재료비·KPI(§6-5)는 그대로 유효.
> 작성 : KOCETI 이민수 / 2026-05-21

## §6-2 한건연 1차년도 연구개발 내용 및 범위

### ▣ 1차년도 (9개월, 설계 중심 + 주관 간소화 모델 인수 IF 검토)

▪ 합성 학습데이터 생성 환경 구축

- 가상 환경 자율작업 시나리오 정의 (굴착·터파기·상차 등)

- 물리기반 시뮬레이션 플랫폼(NVIDIA Omniverse·Isaac Sim/Lab)을 활용한 환경 변화 무작위화(Domain Randomization) 파이프라인 구축

- 합성 데이터용 센서 사양 정의 (LiDAR·카메라·IMU·압력센서 등)

- 단계별 모델 통합을 위한 모델 연계 인터페이스(FMU·surrogate model) 사전 정의

▪ AI 정책 학습 환경 설계

- Isaac Lab 기반 AI 학습 환경 아키텍처 설계

- 굴착기 자율 작업용 강화학습(RL)·모방학습(IL) 알고리즘 후보 선정 및 학습 파이프라인 설계

- RL·IL을 위한 보상 함수·관측·행동·평가지표 설계

- Algoryx AGX 기반 저정밀 가상모델 구축

- 자율공정계획 모듈 (굴착·상차 경로계획) 개념설계

▪ Sim2Real 전이·간극 측정 체계 설계

- Sim2Real 전이 평가 프로토콜 및 핵심 평가지표 (작업별 성공률·정확도·사이클타임) 정의

- 자율작업 시나리오 ⨉ 환경 조건 (지형·조도·기상 등) 조합으로 구성한 전이 평가 시나리오 세트 설계

- 가상-실차 간극 측정 방법론 정의

▪ 실차 데이터 수집 체계 및 시험 환경 설계

- 무인화 장비 학습·평가 환경 구축을 위한 센서·온보드 GPU 선정

- 다중 센서 데이터 수집·저장 인프라 설계

- 테스트 베드 5G/Wi-Fi 6 통신 네트워크 구성 설계 및 시험장 정비 방안 검토

- 샘플 시연 데이터 수집 및 수집 체계 적합성 검토

## 🎤 평가위원 예상 질문·답변 (Q&A)

> 본 §6-2 본문을 보며 평가위원이 던질 가능성 높은 질문 15개와 한건연 측 1차 응답안. 답변은 가이드 v0.3·v0.4·§6-5 KPI 정의 기반 사실로만 구성. 표현은 짧고 정확하게.

### A. 책임 경계

**Q1. Omniverse·Isaac Sim/Lab 인프라 운영을 한건연이 안 하면 학습 환경 운영 책임은 누가?**

→ Omniverse·Isaac Sim·Isaac Lab·Replicator 인프라 운영은 주관(심지) 책임. 한건연은 AI 학습 주체로서 도구 활용 범위·DR 시나리오·RL 환경 설계·학습 파이프라인 결정을 담당. 즉 인프라(주관) ↔ 학습 콘텐츠(한건연) 로 R&R 분리.

**Q2. 토사 베드 조성이 한건연 일이 아니라면 실차 시험은 어디서?**

→ 본 사업의 토사 베드(모래·자갈·진흙) 조성은 한건연·주관 모두 책임 외. 실차 시험은 **외부 베드 활용** — 3차년도 새만금 마사토·나포 자갈, 4차년도 ADT 협업 시연 나포 자갈. 시험장 정비(작업영역·관제실·안전펜스·CCTV·통신)는 한건연 책임 (군산 시험장).

**Q3. NTP/PTP 데이터 동기화·통신 정밀 튜닝이 주관이라면, 한건연 데이터 품질 보장은 어떻게?**

→ 한건연은 5G/Wi-Fi 6 네트워크 **구성·검증**까지 담당. 데이터 동기화 IF는 주관 NTP/PTP 모듈과 연계하고, 통신 정밀 튜닝은 주관 책임 + 한건연 서포트. 데이터 품질 검증은 한건연이 수집 SW 단에서 다중 센서 동기화 결과를 측정·기록.

### B. 주관 모델 인수·일정 리스크

**Q4. 주관 정밀 모델 인수가 2차년도 중~말 예정인데, 지연되면 한건연 본격 학습 일정이 연쇄 지연 아닌가?**

→ 인수 지연 리스크 완화 장치 2개 — ① 1차년도부터 주관 간소화 모델 IF·변환·규약(USD/URDF/Simscape) 사전 검토 착수, ② Algoryx AGX 라이센스(1·2차년도 각 1,900만원/년)로 백업 물리 시뮬레이션 경로 확보. 주관과 정기 점검회의로 인수 일정 모니터링.

**Q5. 2차년도에 실차 1차 전이 시험을 안 하면 3차에 한 번에 시작하는 셈인데, 리스크 큰 것 아닌가?**

→ 2차년도 = 시험장 1차 정비·통신 인프라 구축 중인 시점이므로 본격 실차 전이 시험은 인프라적으로 불가. 단, **저정밀 가상모델 기반 Sim2Real 전이 샘플 시연 검증** (2차 ▪3) 으로 도구·파이프라인·SW 골격을 사전 시범 구동. 3차년도엔 인프라 완비된 상태에서 정밀 모델 기반 1차 전이 시험을 본격 수행.

**Q6. Algoryx 라이센스가 1·2차년도 한정인데, 3차년도에 백업 없이 가능한가?**

→ 3차년도부터는 주관 정밀 모델이 본격 활용되어 Algoryx 백업 필요성 자체가 감소. 단, 운영 여부는 별도 검토 (가이드 v0.3 짚어둘 점 3). 필요 시 연구활동비 재배분으로 연장 가능.

### C. 기술 흐름

**Q7. DR(도메인 무작위화) 시나리오의 학습용 확장 계수는 어떻게 결정?**

→ 시뮬·CAE(생기원)가 토사 nominal·σ 입력을 IF로 제공하고, 한건연이 **학습용 randomization 확장 계수 + 지형 기하 변동 라이브러리**를 결정. 1차년도 IF 협의 → 2차년도 코드화(Replicator·Lab) → 3차년도 실제 모델 기반 갱신.

**Q8. Sim2Real Gap 메트릭은 어떻게 측정?**

→ 3층 계층 메트릭 정의 — observation·dynamics·policy. 1차년도에 측정 절차·필요 데이터량·합격 기준 초안 수립, 2차년도에 측정 도구 1차 prototype 구현, 3차년도 본격 측정·보정 사이클 운영. SysID 2단계 구조 (Simscape→Lab + Lab→실차) + Fine-tuning 조합 적용.

**Q9. 굴착기-ADT 협업 사이클을 3차에 학습했는데 4차에 1회 시연만으로 검증이 충분한가?**

→ 4차 ▪4 ADT 협업 시연은 본 사업의 **최종 목표 시연** (가이드 v0.3 짚어둘 점 9). 협업 정책 학습 검증은 3차년도 ▪2·▪3에서 가상·실차 연동 검증으로 단계별 진행하고, 4차 시연은 그 정점. 단일 시연이 아니라 통합 정책 최종 학습·평가(4차 ▪2) 의 출구 단계.

**Q10. RL/IL 알고리즘 후보는 무엇이고 최종 선정은 언제?**

→ Marco Hutter (ETH RSL) 그룹 HEAP·ANYmal 작업 추종 — 1차년도 후보 선정·학습 파이프라인 설계 (1차 ▪2), 2차년도 저정밀 사전학습으로 최종 선정 검증, 3차년도부터 정밀 모델 기반 본격 학습.

### D. KPI

**Q11. KPI 1 성공률 90%, KPI 2 버킷 RMSE 10cm — 1차 목표인가 최종 목표인가?**

→ 1차 목표. 정량 수치는 1차년도 초안 (Hutter 그룹 HEAP·일반 굴착기 표준 참고), 2·3차년도 baseline 측정 후 4차년도에 최종 확정·입증. KPI 2는 도전 목표로 RMSE 5cm 옵션.

**Q12. 4단계 캠페인의 통계 신뢰도는?**

→ 단계당 N ≥ 20 cycle (4단계 × 20 = 80 cycle 최소). 통계 신뢰도 95% 기준 부족 시 추가 시험. 4차년도 4단계 캠페인 (Bench → 평탄지 → 다양 지형 → 야간·위험지) 에서 수행 (§6-5 KPI 측정 절차).

**Q13. KPI 임계값을 4차에 최종 확정하는데, 그 전에 측정 결과 미달 시 대응?**

→ 3차년도 ▪4 KPI baseline 측정 단계에서 임계값 부족 시 도메인 적응 자동화 (3차 ▪3) + Fine-tuning 파이프라인 보정 사이클로 4차 진입 전 보정. 4차 ▪3 도메인 적응 고도화·이상 상황 대응이 최종 안전망.

### E. 외부 베드·시험장

**Q14. 새만금 마사토·나포 자갈 외부 베드 확보 협조는 누구 책임? 협조 불발 시?**

→ OEM/시험기관 (🟨) 측과 컨소시엄 공동 협조 확보. 협조 불발 시 군산 시험장 자체 평탄지에서 1차 시연 가능한 수준으로 대체 운영 (단, 토사 다양성 일부 제약). 1차년도 ▪4에서 협조 가능성 사전 확인 필수.

**Q15. 3차에 마사토·자갈 둘 다, 4차에 자갈만 — 4차는 마사토는 안 하는가?**

→ 4차 ▪4 ADT 협업 시연이 나포 자갈 외부 베드에서 진행되는 최종 목표 시연이므로 자갈 베드를 명시. 4차 일반 통합 실증 (▪4 두 번째 sub-bullet, 4단계 캠페인) 은 다양 지형 포함하므로 마사토·자갈·평탄지 모두 활용. 즉 4차는 둘 다 사용, 시연만 자갈.
