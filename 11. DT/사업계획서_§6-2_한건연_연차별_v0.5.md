## §6-2 한건연 1차년도 연구개발 내용 및 범위

### ▣ 1차년도 (9개월, 설계 중심 + 주관 간소화 모델 인수 IF 검토)

▪ 합성 학습데이터 생성 환경 구축

- 가상 환경 자율작업 시나리오 정의 (굴착·터파기·상차 등)

  작업 단위(BFC: bucket fill cycle·dig-swing-dump·평탄화·다단 굴착)를 표준화하고, 각 시나리오에 대해 토양 물성(마찰계수·점착력·습도)·지형 기하·기상 변동 조건 매트릭스 구성. 시나리오 카탈로그 v1.0을 작성하고 컨소시엄(KIST·생기원) 검토를 거쳐 합성 데이터 생성 시 학습용 randomization 시드로 활용. 법면 작업·이형 토사 등 확장 시나리오는 2차년도에 단계적 추가.

- 물리기반 시뮬레이션 플랫폼(NVIDIA Omniverse·Isaac Sim/Lab)을 활용한 환경 변화 무작위화(Domain Randomization) 파이프라인 구축

  Replicator API로 조명·텍스처·기하·물리 파라미터 변동을 자동 샘플링하는 DR 파이프라인을 구축. 학습용 randomization 확장 계수는 시뮬·CAE(생기원) 제공 nominal·σ 값을 IF로 받아 결정하고, 한건연이 지형 기하 변동 라이브러리·랜덤 시드 정책을 수립. 파이프라인 v1.0은 1차년도 말 도구 동작 검증까지 완료하여 2차년도 본격 합성 데이터 생성에 활용.

- 합성 데이터용 센서 사양 정의 (LiDAR·카메라·IMU·압력센서 등)

  LiDAR(채널·FOV·해상도·노이즈 모델)·카메라(RGB/스테레오 해상도·FPS·왜곡)·IMU·압력/하중·RTK-GNSS 사양을 정의. 실차 탑재 후보 모델과 가상 센서 모델의 노이즈·왜곡·동기화 특성을 1:1 대응시켜 observation gap을 사전 최소화. 사양서 v1.0을 실차 발주 직전 확정하고, 실차 캘리브레이션 절차도 사양서에 포함.

- 단계별 모델 통합을 위한 모델 연계 인터페이스(FMU·surrogate model) 사전 정의

  주관(심지) 간소화 모델 인수 시점에 즉시 변환·통합 가능하도록 FMU(Functional Mock-up Unit)·surrogate model·USD/URDF/Simscape 표준 기반 변환 규약(좌표계·단위·물성 매핑)을 1차년도 후반에 합의. IF 명세서 v1.0을 작성한 뒤 인수 직후 PoC 변환 1회를 시범 수행하여 인수 일정 리스크(Q4) 완화.

▪ AI 정책 학습 환경 설계

- Isaac Lab 기반 AI 학습 환경 아키텍처 설계

  Isaac Lab의 환경(env) 추상화·작업(task) 인터페이스·학습 분산(distributed RL) 구성을 바탕으로 굴착기 도메인 학습 환경 아키텍처를 설계. 작업부 다관절·토사 상호작용 등 굴착기 특수성을 반영해 ETH RSL의 ANYmal·HEAP 표준 환경에 굴착기 확장 모듈을 추가. 아키텍처 다이어그램 v1.0을 1차년도 말까지 작성.

- 굴착기 자율 작업용 강화학습(RL)·모방학습(IL) 알고리즘 후보 선정 및 학습 파이프라인 설계

  Hutter 그룹(ETH RSL) HEAP·ANYmal 작업 추종을 기준선으로 PPO·SAC(RL) 및 BC·DAgger(IL) 후보를 비교하여 굴착기 자율 작업용 알고리즘을 1차 선정. 학습 파이프라인은 환경-에이전트-보상-평가 4단 구성으로 설계하고, 최종 알고리즘 선정은 2차년도 저정밀 사전학습 결과에 따라 확정.

- RL·IL을 위한 보상 함수·관측·행동·평가지표 설계

  보상 함수는 작업 완료(굴착 부피·정확도)·안전(전복·간섭 방지)·효율(사이클타임)의 다목적 가중 구성으로 설계. 관측은 다중 센서 융합(LiDAR·IMU·하중) + 작업부 자세, 행동은 관절 토크·속도 연속 공간으로 정의. 설계안 v1.0을 작성하고 2차년도 사전학습 단계에서 가중치 튜닝 사이클 운영.

- Algoryx AGX 기반 저정밀 가상모델 구축

  Algoryx AGX 물리엔진 기반 저정밀 가상모델을 PoC 수준으로 구축. 토사-버킷 상호작용 입자 모델과 간소화 굴착기 강체 모델로 1차 시뮬레이션 사이클(굴착-상차)을 검증하고, 학습 wall-clock 시간을 1차 측정. PoC 결과는 2차년도 저정밀 사전학습 환경 구축의 기준선으로 활용.

- 주관/협력기관 자율공정계획 모듈과의 IF 사전 조율 (단위작업 정책 ↔ 공정계획 연계)

  자율공정계획 모듈(Unified Planner) 개발은 주관/협력기관이 주관하며, 한건연은 단위작업 정책(RL·IL) 개발에 집중. 1차년도에 단위작업 정책 ↔ 공정계획 모듈 간 IF(작업 sequence·상태 transition·신호 규약)를 사전 협의하여 정책 학습 단계와 통합 단계의 불일치를 방지하고, IF 명세서에 한건연 측 입출력 사양을 명시.

▪ Sim2Real 전이·간극 측정 체계 설계

- Sim2Real 전이 평가 프로토콜 및 핵심 평가지표 (작업별 성공률·정확도·사이클타임) 정의

  Sim2Real 전이 평가 프로토콜과 핵심 평가지표(작업별 성공률·정확도·사이클타임)를 정의. 시뮬-실차 동일 시나리오 조건에서 측정·비교하는 절차를 표준화하고, 정량 임계값은 1차년도에 Hutter 그룹 HEAP·일반 굴착기 표준을 참고한 초안 수립 후 2·3차년도 baseline 측정으로 정련.

- 자율작업 시나리오 ⨉ 환경 조건 (지형·조도·기상 등) 조합으로 구성한 전이 평가 시나리오 세트 설계

  자율작업 시나리오(굴착·터파기·상차) ⨉ 환경 조건(지형·조도·기상·토양)의 직교 조합으로 전이 평가 시나리오 세트를 구성. 시나리오당 cycle 수·통계 신뢰도 기준(95%·N ≥ 20)을 명시하여 §6-5 KPI 측정 절차와 일치시키고, 시나리오 세트 v1.0을 1차년도 말까지 작성.

- 가상-실차 간극 측정 방법론 정의

  가상-실차 간극을 observation gap(센서 노이즈·왜곡)·dynamics gap(물리 응답)·policy gap(정책 출력 차이)의 3층 계층 메트릭으로 정의. 각 층별 측정 절차·필요 데이터량·합격 기준을 1차년도에 초안 수립하고, 2차년도 prototype 구현 → 3차년도 본격 측정·보정 사이클로 단계 확장.

▪ 실차 데이터 수집 체계 및 시험 환경 설계

- 무인화 장비 학습·평가 환경 구축을 위한 센서·온보드 GPU 선정

  센서는 합성 데이터 사양서(▪1)와 1:1 대응하도록 LiDAR·카메라·IMU·하중·RTK-GNSS를 통합 선정. 온보드 GPU는 NVIDIA Jetson Orin/Thor급으로 추론 지연 100ms 이내의 안전 supervisor 운용 가능 등급을 충족. 사양서 확정 후 1차년도 말 발주하여 2차년도 초 설치 가능.

- 다중 센서 데이터 수집·저장 인프라 설계

  센서 동기화(NTP/PTP 주관 모듈 IF 연계)·고처리량 저장(NVMe SSD, 분당 ~10GB 처리)·메타데이터 관리(작업 시나리오·환경·라벨)를 포괄하는 데이터 수집·저장 인프라를 설계. 인프라 설계도 v1.0을 1차년도 말까지 작성하고, 2차년도 실차 설치 단계에서 구현.

- 테스트 베드 5G/Wi-Fi 6 통신 네트워크 구성 설계 및 시험장 정비 방안 검토

  군산 시험장 작업영역·관제실·안전펜스·CCTV·통신 음영 분석을 바탕으로 5G 셀·Wi-Fi 6 AP 배치 시뮬레이션을 수행. 통신 정밀 튜닝은 주관 책임이며 한건연은 구성·검증과 시험장 정비를 담당. 정비·통신 계획서 v1.0을 작성하여 2차년도 본격 조성에 활용.

- 샘플 시연 데이터 수집 및 수집 체계 적합성 검토

  1차년도 말 시험 굴착기(임차 또는 OEM 협조)로 굴착 1 cycle 데이터 취득을 1회 수행하고 동기화·라벨·저장 파이프라인을 1차 검증. 발견된 결함은 2차년도 본격 설치 단계에 반영하여 인프라 시행착오를 사전 흡수.

## §6-2 한건연 2차년도 연구개발 내용 및 범위

### ▣ 2차년도 (10개월, 1차 조성 + 저정밀 사전학습 + Sim2Real 샘플 시연)

▪ 디지털 트윈 모델 기반 합성 데이터셋 생성 환경 조성

- Isaac Lab 가상 학습 환경 구축

  1차년도 아키텍처 다이어그램 v1.0을 바탕으로 Isaac Lab 가상 학습 환경을 구축. ANYmal·HEAP 표준 환경에 굴착기 도메인 확장 모듈을 통합하고, 학습 클러스터(GPU 노드·Job 스케줄러) 연계 검증과 학습 wall-clock 1차 측정을 완료. 환경 구축물 v1.0을 사전학습 직전 점검.

- 환경 변수 (지형·조도·기상 등) 를 고려한 합성 데이터 생성

  1차년도 DR 파이프라인 v1.0을 활용하여 지형·조도·기상·토양 변동 조건이 반영된 합성 데이터셋을 생성. 시나리오 카탈로그 v1.0의 작업 단위(BFC·dig-swing-dump·평탄화)별로 시나리오당 충분한 cycle 수를 확보하고, 데이터 다양성·균형을 위한 분포 모니터링을 병행.

- 합성 데이터 라벨 자동화 도구 구축

  합성 데이터의 인스턴스 분할(작업부·토사·차량)·작업 단계 라벨·환경 메타데이터를 자동 라벨링하는 도구를 구축. Isaac Sim Replicator의 ground truth 출력과 자체 후처리 스크립트를 결합하여 라벨 정확도·일관성을 확보하고, 합성·실차 라벨 스키마를 통일.

▪ 저정밀 가상모델 기반 AI 정책 사전학습

- Algoryx AGX 기반 저정밀 가상모델 사전학습 환경 구축

  1차년도 Algoryx AGX PoC 결과를 바탕으로 저정밀 가상모델 사전학습 환경을 구축. 학습 루프 가속을 위한 GPU 병렬화·시뮬레이션 step rate 최적화·체크포인트 관리 등 학습 운영 인프라를 구성하고, 학습 wall-clock·메모리 사용 프로파일을 측정하여 본격 사전학습 진입 조건을 확보.

- 저정밀 가상모델 기반 단위작업 RL/IL 정책 사전학습

  단위작업(굴착·상차·다단 굴착)별 RL/IL 정책을 저정밀 가상모델에서 사전학습. 1차년도 알고리즘 후보(PPO·SAC·BC·DAgger) 중 단위작업별 적합 알고리즘을 결정하고, 보상 함수·랜덤화 강도를 단계적 조정하며 학습 안정성·성공률을 확보.

- 단위작업 정책 ↔ 자율공정계획 IF 연동 1차 검증

  1차년도 합의된 IF에 따라 한건연 단위작업 정책 출력과 주관/협력기관 자율공정계획 모듈 입력의 연동을 시범 검증. 가상 환경에서 작업 sequence 전달·상태 동기화·예외 신호 처리를 점검하고, 발견된 IF 결함은 주관/협력기관과 협의하여 즉시 보정. 자율공정계획 알고리즘 자체 개발은 주관/협력기관 영역.

▪ Sim2Real 1차 전이 및 간극 기준치 측정

- 저정밀 가상모델 기반 Sim2Real 전이 샘플 시연 검증

  저정밀 가상모델에서 사전학습한 단위작업 정책을 실차에 1회 시범 적용하여 도구·파이프라인·SW 골격을 사전 검증. 시험장 1차 정비·통신 인프라 조성 중인 단계이므로 본격 전이 시험은 아닌 샘플 시연 수준이며, 결과는 3차년도 정밀 모델 기반 1차 전이 시험의 기준점으로 활용.

- 가상-실차 성능 간극 측정 도구 구현

  1차년도 방법론에 따라 observation·dynamics·policy gap 측정 도구를 prototype 수준으로 구현. 시뮬-실차 동일 시나리오에서 자동으로 메트릭을 산출·로깅하는 도구 chain을 구축하고, 측정 데이터의 일관성·재현성을 1차 검증.

- 도메인 적응 (fine-tuning) 파이프라인 설계 및 실차 소량 데이터 활용 시범 구동

  가상에서 사전학습한 정책을 실차 소량 데이터로 fine-tuning하는 도메인 적응 파이프라인을 설계하고 시범 구동. 사전학습 가중치 freeze·일부 layer만 갱신·전체 fine-tuning의 3가지 적응 전략을 비교하여 3차년도 본격 fine-tuning 파이프라인 구축으로 연계.

▪ 실차 데이터 수집 체계 및 시험 환경 구축

- 실증 굴착기 센서·온보드 GPU 설치 및 캘리브레이션

  1차년도 발주된 센서·온보드 GPU를 실증 굴착기에 설치하고 캘리브레이션을 수행. LiDAR·카메라 외부 캘리브레이션, IMU 내부 캘리브레이션, RTK-GNSS 정밀도 측정 등 표준 절차를 거치고, 설치·캘리브레이션 절차서를 작성하여 향후 정비·교체 시 활용.

- 센서 데이터 수집·동기화 기능 구현 및 검증

  센서 데이터 수집·동기화 기능을 구현하고 다중 센서 시간 동기화(NTP/PTP 주관 모듈 IF) 결과를 정량 검증. 분당 ~10GB 처리·저장 손실 0%·동기화 jitter 임계치 이하 등 데이터 품질 기준을 충족하는지 확인하고, 결함 발견 시 즉시 보정.

- 5G/Wi-Fi 6 통신 인프라·시나리오 시험장 조성

  1차년도 정비·통신 계획서 v1.0에 따라 군산 시험장의 5G/Wi-Fi 6 통신 인프라를 1차 조성. 5G 셀·Wi-Fi 6 AP 설치, 통신 음영 측정, 시나리오 작업영역(평탄지·고정 굴착 위치)·관제실·안전펜스·CCTV를 정비하고, 정밀 통신 튜닝은 주관과의 협업으로 진행.

## §6-2 한건연 3차년도 연구개발 내용 및 범위

### ▣ 3차년도 (12개월, 본격 구현·단계별 시험 + 주관 정밀 모델 본격 활용)

▪ 디지털 트윈 모델 기반 합성 데이터셋 생성 환경 확장

- 합성 데이터 생성 환경 정밀 모델 통합

  주관(심지)으로부터 2차년도 중~말에 인수한 정밀 굴착기·토사 모델을 IF 명세서 v1.0에 따라 합성 데이터 생성 환경에 통합. 정밀 모델 기반 작업 시뮬레이션의 정확도·실행 속도를 측정하고, 1차년도부터 누적된 변환 규약·캘리브레이션 절차를 갱신.

- 작업환경 변형 (지형·조도·기상) 시나리오 확장

  지형(평탄·경사·요철·다단 굴착면)·조도(주야·역광)·기상(우천·강풍) 변형 시나리오를 단계적 확장. 1차년도 시나리오 카탈로그 v1.0을 v2.0으로 갱신하고, 확장 시나리오별 합성 데이터의 모델 일반화 효과를 정량 검증.

- 생성형 모델 통합 적용을 통한 합성 영상 포토리얼 변환 검토

  합성 영상의 실차 도메인 격차를 줄이기 위해 생성형 모델(image-to-image translation)을 합성-실차 변환에 적용 검토. 합성 영상 → 포토리얼 영상 변환 정확도를 정량 측정하고, observation gap 축소 기여도를 평가하여 4차년도 통합 데이터셋 패키지화 단계에 반영 여부 결정.

▪ 정밀 가상모델 기반 학습

- 정밀 굴착기 모델 및 토사 모델 연동

  주관 제공 정밀 굴착기 모델과 토사 모델(생기원·CAE 연계)을 학습 환경에 연동. 모델 간 데이터 IF(FMU·surrogate model)·계산 단계 동기화·물성 매핑을 점검하고, 학습 루프에서의 모델 응답 안정성을 검증하여 본격 학습 단계 진입 조건을 충족.

- Isaac Sim 기반 모델 통합 및 가상 정책 본격 학습 (RL/IL)

  Isaac Sim 기반 통합 환경에서 정밀 가상모델을 활용한 RL/IL 정책을 본격 학습. 학습 PC + GPU 1세트 추가(3차년도 자원 보강)를 바탕으로 학습 분산을 확장하고, 단위작업 정책의 성공률·정확도·사이클타임을 3차년도 baseline 기준치로 측정.

- 굴착기 – 운반차량 (ADT) 협업 사이클 (굴착-선회-상차) 정책 학습

  굴착기-ADT 협업 사이클(굴착-선회-상차)을 정책 학습. 굴착기와 운반차량 간 위치·작업 타이밍 동기화, 상차 정확도, 사이클 시간을 보상에 반영하여 협업 정책의 안정성·반복성을 확보하고, 4차년도 ADT 협업 시연(나포 자갈 외부 베드)의 학습 출구로 연결.

- 자율공정계획 모듈과의 가상·실차 연동 IF 운용 검증

  주관/협력기관이 개발한 자율공정계획 모듈을 한건연 단위작업 정책·실차 환경과 연동하여 IF 운용을 검증. 가상·실차 양쪽에서 작업 sequence 전달·상태 동기화·이상 신호 처리를 점검하고, 본격 학습·시험 단계에서 IF 결함이 발생하지 않도록 안정성을 확보. 공정계획 고도화 자체는 주관/협력기관이 주도.

▪ Sim2Real 간극 축소·도메인 적응

- 정밀 모델 기반 학습 정책의 실차 1차 전이 시험

  정밀 모델 기반으로 학습된 정책을 실차에 1차 전이하여 시험. 시험장 인프라가 1차 조성 완료된 상태에서 본격적인 전이 시험을 수행하고, 실차 작업 성공률·정확도·사이클타임을 측정하여 가상-실차 간극의 정량 baseline을 확보.

- 도메인 적응 자동화 — 실차 데이터 활용 fine-tuning 파이프라인 구축

  2차년도 fine-tuning 파이프라인 설계를 기반으로 실차 데이터 활용 도메인 적응 자동화 파이프라인을 구축. 실차 수집 데이터로부터 자동 라벨·자동 fine-tuning·자동 평가의 닫힌 루프를 구성하여 적응 사이클 시간을 단축.

- 가상-실차 성능 간극 측정 및 보정 사이클 검토

  observation·dynamics·policy gap 3층 메트릭을 정밀 모델 기반에서 본격 측정하고, 측정 결과를 토대로 합성 데이터 분포·DR 강도·정밀 모델 파라미터를 보정하는 사이클을 운영. 보정 사이클의 효과를 정량 평가하여 4차년도 최종 검증의 준비 단계로 활용.

▪ 실차 데이터 수집 및 단계별 시험

- 실증 굴착기 실차 데이터 수집 및 자동/수동 라벨링

  실증 굴착기를 활용해 다양한 작업 시나리오·환경 조건의 실차 데이터를 본격 수집. 자동 라벨(GNSS·하중·작업부 자세 기반)과 수동 라벨(작업 단계·이상 이벤트)을 결합하여 라벨 품질을 확보하고, fine-tuning·간극 측정용 데이터셋으로 활용.

- 단위작업에 대한 실차 시연 검증 (새만금 마사토·나포 자갈 외부 베드 활용)

  굴착·터파기·상차 단위작업을 실차에서 시연 검증. 외부 베드(새만금 마사토·나포 자갈)를 활용하여 토사 다양성·작업 난이도를 확보하고, 단위작업별 성공률·정확도·사이클타임을 시연 평가.

- 적응 정책 실차 1차 검증 및 KPI baseline 측정

  도메인 적응 자동화 파이프라인을 거친 정책을 실차에서 1차 검증하고, §6-5 KPI 1·2(성공률·정확도)의 baseline을 측정. baseline 결과는 4차년도 4단계 캠페인·KPI 최종 입증의 출발점이며, 임계값 부족 시 4차 진입 전 보정 사이클을 추가.

## §6-2 한건연 4차년도 연구개발 내용 및 범위

### ▣ 4차년도 (12개월, 통합·검증 + ADT 협업 시연)

▪ 표준 데이터셋 구성 및 통합 시나리오 보완

- 굴착기 + ADT 통합 시나리오 합성 데이터 보강

  굴착기 + ADT 통합 협업 시나리오의 합성 데이터를 보강. 굴착-선회-상차 사이클·차량 간 위치 관계·상차 정확도 등 협업 특화 변동 조건을 반영하고, 4차년도 ADT 협업 시연(나포 자갈)·통합 실증의 학습 데이터로 활용.

- 3차년도 실증 피드백 반영 데이터 갱신

  3차년도 실차 시연·1차 전이·간극 측정 결과를 토대로 합성 데이터 분포를 보정. 측정된 observation/dynamics/policy gap이 큰 시나리오에 합성 데이터를 보강하고, 불필요한 분포는 정리하여 학습 효율성을 확보.

- 라벨·품질 재검증 및 학습·검증·실증용 표준 데이터셋 패키지화

  라벨·메타데이터·품질 메트릭을 재검증한 뒤 학습·검증·실증용 표준 데이터셋으로 패키지화. 데이터셋 버전 관리·접근 권한·외부 공유 정책을 정의하여 컨소시엄 공동 활용 기반을 마련.

▪ 통합 정책 최종 학습

- 가상 정책 최종 학습·평가

  3차년도까지 누적된 학습 자산과 보정된 합성 데이터·정밀 모델을 활용해 통합 정책을 최종 학습. 굴착기 단위작업 + ADT 협업 사이클을 포함한 통합 정책의 성공률·정확도·사이클타임을 가상에서 최종 평가하여 실차 최종 전이의 학습 기준선으로 확정.

- 통합 정책 ↔ 자율공정계획 모듈 통합 운용 IF 최종 점검

  최종 학습된 통합 정책과 주관/협력기관 자율공정계획 모듈의 통합 운용을 IF 관점에서 최종 점검. 단위작업 정책·공정계획 모듈·안전 supervisor 간 IF 안정성, 작업 흐름 전환의 매끄러움을 가상·실차 시나리오에서 확인하고, IF 운용 결과를 사업 종료 보고서에 정리.

▪ 통합 정책 Sim2Real 전이 최종 검증

- 통합 정책의 실차 전이 최종 검증

  최종 학습된 통합 정책을 실차에 전이하여 4단계 캠페인(▪4)의 모든 단계에 적용. 단계별로 발생하는 가상-실차 격차를 측정·분석하고, 필요 시 즉시 fine-tuning·정책 패치를 적용하여 최종 검증 사이클을 완성.

- 도메인 적응 고도화 및 이상 상황 대응

  도메인 적응 자동화 파이프라인을 최종 단계로 고도화하여 실차 환경 변동(이종 토사·기상·조도)에 대한 정책 강건성을 확보. 안전 supervisor와의 협조 하에 이상 상황(센서 오류·작업 실패·간섭 위험) 대응 시나리오를 점검.

- KPI 최종 입증 보고 (성공률·버킷 RMSE 등)

  §6-5 KPI 1(성공률) 및 KPI 2(버킷 RMSE) 등 핵심 지표를 4단계 캠페인 결과로 최종 입증하고, 통계 신뢰도(95%·N ≥ 20 cycle 기준)·임계값 충족 여부를 보고. 도전 목표(RMSE 5cm 옵션) 도달 여부도 부가 평가하여 사업 성과로 정리.

▪ 실차 데이터 최종 수집 및 통합 실증

- 굴착기 실차 시연 데이터 최종 수집

  4단계 캠페인 전·후 및 ADT 협업 시연을 포함한 모든 실차 시연 데이터를 최종 수집. 표준 데이터셋 패키지에 흡수하여 사업 종료 후 후속 연구·기술이전·OEM 활용을 위한 자산으로 정리.

- 4단계 캠페인 (Bench → 평탄지 → 다양 지형 → 야간·위험지) 통합 실증

  Bench(고정 굴착) → 평탄지(자유 굴착) → 다양 지형(경사·요철·이형 토사) → 야간·위험지(저조도·전복 위험)의 4단계 캠페인을 §6-5 KPI 측정 절차에 따라 통합 실증. 각 단계별 N ≥ 20 cycle을 수행하여 통계 신뢰도 95%의 KPI 측정 결과를 확보.

- 굴착기 - ADT 굴착·상차 협업 시연 (나포 자갈 외부 베드 활용)

  나포 자갈 외부 베드에서 굴착기-ADT 굴착·상차 협업 시연을 본 사업의 최종 목표 시연으로 수행. 협업 사이클의 정확도·반복성·사이클타임을 정량 평가하고, OEM·관계기관·평가위원이 참관 가능한 공개 시연 형식으로 진행하여 사업 성과를 가시화.

## 🎤 평가위원 예상 질문·답변 (Q&A)

> 본 §6-2 본문을 보며 평가위원이 던질 가능성 높은 질문 15개와 한건연 측 1차 응답안. 답변은 가이드 v0.3·v0.4·§6-5 KPI 정의 기반 사실로만 구성. 표현은 짧고 정확하게.

### A. 책임 경계

**Q1. Omniverse·Isaac Sim/Lab 인프라 운영을 한건연이 안 하면 학습 환경 운영 책임은 누가?**

→ Omniverse·Isaac Sim·Isaac Lab·Replicator 인프라 운영은 주관(심지) 책임. 한건연은 AI 학습 주체로서 도구 활용 범위·DR 시나리오·RL 환경 설계·학습 파이프라인 결정을 담당. 즉 인프라(주관) ↔ 학습 콘텐츠(한건연) 로 R&R 분리.

**Q2. 토사 베드 조성이 한건연 일이 아니라면 실차 시험은 어디서?**

→ 본 사업의 토사 베드(모래·자갈·진흙) 조성은 한건연·주관 모두 책임 외. 실차 시험은 **외부 베드 활용** — 3차년도 새만금 마사토·나포 자갈, 4차년도 ADT 협업 시연 나포 자갈. 시험장 정비(작업영역·관제실·안전펜스·CCTV·통신)는 한건연 책임 (군산 시험장).

**Q3. NTP/PTP 데이터 동기화·통신 정밀 튜닝이 주관이라면, 한건연 데이터 품질 보장은 어떻게?**

→ 한건연은 5G/Wi-Fi 6 네트워크 **구성·검증**까지 담당. 데이터 동기화 IF는 주관 NTP/PTP 모듈과 연계하고, 통신 정밀 튜닝은 주관 책임 + 한건연 서포트. 데이터 품질 검증은 한건연이 수집 SW 단에서 다중 센서 동기화 결과를 측정·기록.

### B. 주관 모델 인수·일정 리스크

**Q4. 주관 정밀 모델 인수가 2차년도 중~말 예정인데, 지연되면 한건연 본격 학습 일정이 연쇄 지연 아닌가?**

→ 인수 지연 리스크 완화 장치 2개 — ① 1차년도부터 주관 간소화 모델 IF·변환·규약(USD/URDF/Simscape) 사전 검토 착수, ② Algoryx AGX 라이센스(1·2차년도 각 1,900만원/년)로 백업 물리 시뮬레이션 경로 확보. 주관과 정기 점검회의로 인수 일정 모니터링.

**Q5. 2차년도에 실차 1차 전이 시험을 안 하면 3차에 한 번에 시작하는 셈인데, 리스크 큰 것 아닌가?**

→ 2차년도 = 시험장 1차 정비·통신 인프라 구축 중인 시점이므로 본격 실차 전이 시험은 인프라적으로 불가. 단, **저정밀 가상모델 기반 Sim2Real 전이 샘플 시연 검증** (2차 ▪3) 으로 도구·파이프라인·SW 골격을 사전 시범 구동. 3차년도엔 인프라 완비된 상태에서 정밀 모델 기반 1차 전이 시험을 본격 수행.

**Q6. Algoryx 라이센스가 1·2차년도 한정인데, 3차년도에 백업 없이 가능한가?**

→ 3차년도부터는 주관 정밀 모델이 본격 활용되어 Algoryx 백업 필요성 자체가 감소. 단, 운영 여부는 별도 검토 (가이드 v0.3 짚어둘 점 3). 필요 시 연구활동비 재배분으로 연장 가능.

### C. 기술 흐름

**Q7. DR(도메인 무작위화) 시나리오의 학습용 확장 계수는 어떻게 결정?**

→ 시뮬·CAE(생기원)가 토사 nominal·σ 입력을 IF로 제공하고, 한건연이 **학습용 randomization 확장 계수 + 지형 기하 변동 라이브러리**를 결정. 1차년도 IF 협의 → 2차년도 코드화(Replicator·Lab) → 3차년도 실제 모델 기반 갱신.

**Q8. Sim2Real Gap 메트릭은 어떻게 측정?**

→ 3층 계층 메트릭 정의 — observation·dynamics·policy. 1차년도에 측정 절차·필요 데이터량·합격 기준 초안 수립, 2차년도에 측정 도구 1차 prototype 구현, 3차년도 본격 측정·보정 사이클 운영. SysID 2단계 구조 (Simscape→Lab + Lab→실차) + Fine-tuning 조합 적용.

**Q9. 굴착기-ADT 협업 사이클을 3차에 학습했는데 4차에 1회 시연만으로 검증이 충분한가?**

→ 4차 ▪4 ADT 협업 시연은 본 사업의 **최종 목표 시연** (가이드 v0.3 짚어둘 점 9). 협업 정책 학습 검증은 3차년도 ▪2·▪3에서 가상·실차 연동 검증으로 단계별 진행하고, 4차 시연은 그 정점. 단일 시연이 아니라 통합 정책 최종 학습·평가(4차 ▪2) 의 출구 단계.

**Q10. RL/IL 알고리즘 후보는 무엇이고 최종 선정은 언제?**

→ Marco Hutter (ETH RSL) 그룹 HEAP·ANYmal 작업 추종 — 1차년도 후보 선정·학습 파이프라인 설계 (1차 ▪2), 2차년도 저정밀 사전학습으로 최종 선정 검증, 3차년도부터 정밀 모델 기반 본격 학습.

### D. KPI

**Q11. KPI 1 성공률 90%, KPI 2 버킷 RMSE 10cm — 1차 목표인가 최종 목표인가?**

→ 1차 목표. 정량 수치는 1차년도 초안 (Hutter 그룹 HEAP·일반 굴착기 표준 참고), 2·3차년도 baseline 측정 후 4차년도에 최종 확정·입증. KPI 2는 도전 목표로 RMSE 5cm 옵션.

**Q12. 4단계 캠페인의 통계 신뢰도는?**

→ 단계당 N ≥ 20 cycle (4단계 × 20 = 80 cycle 최소). 통계 신뢰도 95% 기준 부족 시 추가 시험. 4차년도 4단계 캠페인 (Bench → 평탄지 → 다양 지형 → 야간·위험지) 에서 수행 (§6-5 KPI 측정 절차).

**Q13. KPI 임계값을 4차에 최종 확정하는데, 그 전에 측정 결과 미달 시 대응?**

→ 3차년도 ▪4 KPI baseline 측정 단계에서 임계값 부족 시 도메인 적응 자동화 (3차 ▪3) + Fine-tuning 파이프라인 보정 사이클로 4차 진입 전 보정. 4차 ▪3 도메인 적응 고도화·이상 상황 대응이 최종 안전망.

### E. 외부 베드·시험장

**Q14. 새만금 마사토·나포 자갈 외부 베드 확보 협조는 누구 책임? 협조 불발 시?**

→ OEM/시험기관 (🟨) 측과 컨소시엄 공동 협조 확보. 협조 불발 시 군산 시험장 자체 평탄지에서 1차 시연 가능한 수준으로 대체 운영 (단, 토사 다양성 일부 제약). 1차년도 ▪4에서 협조 가능성 사전 확인 필수.

**Q15. 3차에 마사토·자갈 둘 다, 4차에 자갈만 — 4차는 마사토는 안 하는가?**

→ 4차 ▪4 ADT 협업 시연이 나포 자갈 외부 베드에서 진행되는 최종 목표 시연이므로 자갈 베드를 명시. 4차 일반 통합 실증 (▪4 두 번째 sub-bullet, 4단계 캠페인) 은 다양 지형 포함하므로 마사토·자갈·평탄지 모두 활용. 즉 4차는 둘 다 사용, 시연만 자갈.
