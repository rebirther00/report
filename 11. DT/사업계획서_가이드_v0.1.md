## 1. 사업 개요

### 1-1. 개발 대상 기술·제품의 개요

#### □ 연구개발기술(제품)의 정의 및 범위

**▣ 정의**

본 연구개발과제는 굴착기를 중심으로 한 건설기계의 **유압·전동·파워트레인·멀티바디 동역학(MBD)·토사 반력 등 도메인별 물리를 통합·파라미터화한 「초실감 디지털 트윈(DT) 플랫폼」**과, **동 플랫폼에서 학습된 인공지능(AI) 정책을 실차 무인 자율 작업으로 전이(Sim2Real)시키는 통합 시스템**을 개발하는 사업이다.

본 플랫폼은 *하나의 공통 자산*으로 다음 **두 기둥(Two-Pillar)의 가치**를 동시에 실현한다.

| 기둥 | 활용 가치 | 대응 RFP 활용분야 |
|---|---|---|
| **㉠ OEM 신제품·변형 모델 개발 가속** | 사양 파라미터(실린더경·유압 압력·관절 길이·토사 종류 등) 가변 multi-physics 모델로 *가상 검증 → 시작품 회차 감소* | RFP §3-② 장비 개발 플랫폼 |
| **㉡ AI 기반 실차 무인 자율 작업** | 단일 자율공정 모듈(Unified Planner)이 *가상 학습 → 실차 시연 → 실차 무인 실행* 3개 모드로 동작, Sim2Real 일관성 확보 | RFP §3-① 건설 현장 무인화 |

> **한 줄 비전** : *파라미터화 + 정밀도 가변 multi-physics 디지털 트윈으로 ㉠ OEM 신제품 개발을 가속하고, ㉡ 가상 학습 AI를 실차 무인 자율 작업으로 전이하는 플랫폼*

**▣ 기술 구성 (6대 모듈)**

```
① DT 통합 플랫폼 SW (정밀도 모드 관리자 포함)
② Multi-physics 도메인 모델  ─── MBD·유압·전동·파워트레인
③ 작업환경 모델           ─── 가상 작업장 + 토사 3종 (진흙·모래·자갈)
④ 가상 환경 AI 정책 학습 (RL/IL/Curriculum)
⑤ 실차–DT 통신·데이터 게이트웨이 + 디지털 섀도우
⑥ 실차 적응·안전 레이어 + 4단계 시험 캠페인
```

**▣ 개발 범위 (In Scope)**

| 영역 | 범위 |
|---|---|
| **모델 대상** | 굴착기(중대형 14톤·21톤급 포함) + 로더 + 1종 추가 — **총 ≥ 3종**, 종별 **≥ 2 변형 모델** (파라미터 가변) |
| **물리 도메인** | 멀티바디 동역학(MBD) 솔버 + 유압 + 전동 + 파워트레인 + 토사 반력 통합 |
| **토사** | 진흙·모래·자갈 ≥ 3종, DEM(입자) + SPH(점성토) + 실시간 surrogate 모델 |
| **AI 자율공정** | 시험장(TB) 환경 한정 — 작업 지형 분석, 터파기 경로·상차 경로 수립 |
| **실차 검증** | 4단계 캠페인 (Bench → 평탄지 → 다양 지형 → 야간·위험지) |
| **TRL** | 시작 3단계 → 종료 5단계 (43개월) |

**▣ 명시적 제외 (Out of Scope)**

본 과제는 TRL 3~5 수준의 *원천·핵심기술 확보*에 집중하며, 다음은 후속 사업·상용화 단계의 영역으로 본 사업 범위에서 제외한다.
- BIM/IFC 도면 임포트·드론 외부 측량 통합 등 *현장 사업화 인터페이스*
- 작업 계획에 대한 *DT 사전검증 루프* (계획안 사전 시뮬레이션)
- 다수 차량 fleet OTA 운영 인프라 (testbed 1~3대 규모로 한정 — LAN/SCP/SD 카드 swap 충분)
- 사업화용 상용 UI/UX 패키징

**▣ 최종 산출물**

| 분류 | 산출물 |
|---|---|
| **SW 자산** | DT 통합 플랫폼 (α→β→RC→정식), Unified Planner, 통신·게이트웨이 SW, 디지털 섀도우 대시보드 |
| **모델 자산** | 건설기계 DT 3종(변형 포함) · 토사 모델 3종 · 도메인 물리 라이브러리(정밀/실시간 2단계) |
| **데이터 자산** | 가상 학습 데이터셋 · 실차 시연·작업 데이터셋 · V&V 검증 데이터 |
| **검증 자산** | 2-stage V&V 보고서 (Stage 1 도메인 벤치 / Stage 2 시스템) · 4단계 시험 캠페인 결과 |
| **시연** | 야간·위험지 등 실차 무인 자율 작업 시연 (TRL 5 입증) |

### 1-2. 연구개발과제의 배경 및 필요성

#### □ 배경

**▣ 정책 환경 — 무인공장 미션과 미래모빌리티 초격차 로드맵**

정부는 *2026년도 기계장비산업기술개발사업(산업통상부 공고 2026-338호)*을 통해 **"무인공장 실현을 위한 제조장비의 지능화"** 미션을 제시하였으며, 그 핵심 프로젝트로 **"디지털 제조장비 및 부품 핵심기술 개발"** 및 세부기술 **"디지털트윈 기반 시뮬레이션 플랫폼 기술"**을 명시하였다. 본 과제(2026-기계장비-품목-07)는 **미래모빌리티(건설·농기계) 초격차 로드맵의 건설·농기계 디지털 전환 → 완전 무인화 미션 중 디지털 트윈 기반 시뮬레이션 플랫폼 기술** 확보를 위한 중점 과제로 지정되었다.

**▣ 기술 환경 — SDM 패러다임 전환과 글로벌 vir-sim 생태계의 부상**

건설기계 산업은 *개별 부품·기계 단위 개발*에서 *Software Defined Machine(SDM)* 플랫폼 기반의 **모델 기반 개발(Model-Based Development)** 체계로의 패러다임 전환에 직면해 있다. 동시에 **Nvidia Omniverse·Isaac Sim·Cosmos, Google Genie3, MuJoCo** 등 가상 시뮬레이션 환경과, **DEM·SPH·강화학습(RL)·도메인 랜덤화(Domain Randomization)** 등 가상-실차 전이(Sim2Real) 기술이 빠르게 발전하고 있다. 그러나 *건설기계 도메인 특유의 multi-physics 통합·토사 반력·실차 무인 자율 작업 전이*를 모두 포괄하는 **공통 자산형 DT 플랫폼**은 국내·외 모두 미성숙한 상태로, 원천기술 확보 시 글로벌 선도가 가능한 영역이다.

**▣ 산업·사회 환경 — 건설업 인력난·중대재해와 OEM의 모델 기반 개발 전환 수요**

국내 건설업은 종사자 고령화와 청년층 기피로 인한 만성적 인력난, 그리고 굴착기·토공 작업 등에서 빈발하는 *중대재해*와 *3D(Dirty·Difficult·Dangerous) 작업환경* 문제를 안고 있다. 한편 HD현대사이트솔루션(HDX) 등 국내 건설기계 OEM은 신차 개발 사이클 단축 및 다양한 변형 모델(5톤·14톤·21톤급 등) 대응을 위해 *가상 검증 기반 모델 기반 개발 체계*로의 전환을 요구하고 있다.

**▣ 수요 환경 — 수요기업(HDX) 직접 활용 채널 확보**

본 과제는 *수요기업으로 HDX(HD현대사이트솔루션)가 참여*하여 ㉠ 실차 자산 제공(DX240 굴착기 등), ㉡ 신제품 개발 가이드라인·사양 제공, ㉢ 개발된 파라미터 가변 DT 모델의 *신차·변형 모델 개발 활용 검증*을 수행한다. 즉 본 과제의 결과물이 *연구실 자산에 머무르지 않고 OEM 신제품 개발 라인에 직접 투입*되는 채널이 사업 개시 시점부터 확보되어 있다.

#### □ 필요성

**① (정책적 측면)** 본 과제는 *미래모빌리티 초격차 로드맵*의 건설·농기계 디지털 전환 → 완전 무인화 미션 중 **디지털 트윈 기반 시뮬레이션 플랫폼 기술** 확보를 위한 RFP 명시 핵심 과제이며, *제조AI 기술확보를 통한 기계·장비 산업 경쟁력 강화*라는 사업 목적과 정면 부합한다. *RFP §2 지원필요성-(정책적 측면)*에 명시된 바와 같이, 정부 차원의 집중 투자로만 확보 가능한 *원천기술 확보·생태계 구축*이 시급하다.

**② (기술적 측면)** 개별 부품 단위 개발에서 **DT 기반 SDM 플랫폼**으로의 기술 패러다임 전환에 대응하려면, ㉠ multi-physics(MBD·유압·전동·파워트레인·토사) **통합**, ㉡ 사양 파라미터 가변 **모델 라이브러리화**, ㉢ 도메인별 *정밀↔실시간 모드 가변* 솔버 운용, ㉣ 가상 학습 AI의 **실차 전이(Sim2Real) 자동화**라는 4대 원천기술이 동시 필요하다. 국내에는 이를 모두 포괄하는 통합 플랫폼이 부재하며, 해외 vir-sim 도구(Nvidia Omniverse/Isaac Sim, MuJoCo 등)에 대한 *국가적 활용 역량과 응용 원천기술* 확보가 시급하다. 본 과제 미수행 시 건설기계 무인화·SDM 전환 기술의 *해외 종속 심화*가 우려된다.

**③ (시장적 측면)** 스마트 건설장비 글로벌 시장은 *Caterpillar·Komatsu·HD현대건설기계* 등 주요 OEM이 무인화·자율화 기능을 차세대 핵심 경쟁력으로 추진 중이다. 차별화된 AI·DT 기술 없이는 단순 가격 경쟁에 함몰될 위험이 있으며, 본 과제로 *파라미터 가변 multi-physics DT + 실차 전이 AI* 원천기술을 확보 시 국내 OEM의 **신제품 개발 속도(time-to-market) 단축** 및 **자율화 차별화** 양면에서 시장 경쟁력 확보가 가능하다.

**④ (사회적 측면)** 건설업 종사자 고령화·청년층 기피로 인한 *구조적 인력난*은 단순 처우 개선으로 해결되지 않으며, **완전 무인화 기술의 도입이 불가피**하다. 본 과제는 *건설 현장 중대재해 감소·3D 작업환경 개선*을 통해 산업안전의 기반을 마련하며, 야간·위험지·재난 현장 등 *인간 작업이 곤란한 영역*에서의 무인 굴착기 운용으로 *국민 안전과 산업 지속가능성*에 직접 기여한다.

**▣ 정량적 도전 목표 — RFP 핵심 KPI 90% 달성**

본 과제의 필요성은 5대 정량 KPI(P1~P5, §2-3 참조)의 도전적 달성으로 구체화된다.

## 3. 기술개발 추진방법 및 전략

### 3-1. 추진방법 (6대)

#### (1) 공통 자산형 DT 플랫폼 *우선 구축* (Asset-First Approach)

RFP §3 활용분야 ①·②를 *서로 다른 사업*이 아닌 **단일 multi-physics 디지털 트윈 플랫폼을 공통 자산**으로 하여 *동시* 실현.
  - 1·2차년도 공통 자산 우선 확립 → 3·4차년도 두 기둥 병행 검증
  - 같은 모델·데이터·V&V가 두 기둥에 동시 기여 → 사업 자원 효율 극대화

#### (2) 정밀도 모드 가변 운용 (Fidelity-Variable Operation)

도메인별 ≥ 2 정밀도 모델(고차/surrogate) 등록, 시나리오별 자동 전환.
  - *정밀 모드* — 전 도메인 고차 솔버 → P1 측정
  - *실시간 모드* — 전 도메인 surrogate → P5 측정
  - *도메인 mix* — 검증 대상만 정밀

#### (3) 글로벌 Vir-Sim 생태계 활용 (Open-Source First)

NVIDIA Isaac Sim·Lab·Replicator, Omniverse, MuJoCo, Simscape 등 적극 활용 / 자체 개발은 *건설기계 도메인 특화*(토사 DEM/SPH, 정밀도 모드 관리자, Unified Planner)에 한정.

#### (4) 2-Stage V&V 체계 (Component → System)

  - **Stage 1** : 도메인 벤치 시험 → 도메인별 ≥ 90% 확보 (시험기관 측정 / CAE 분석)
  - **Stage 2** : 실차 캠페인 데이터 ↔ 시뮬 비교 → 시스템 일치도 (G1/P1)

#### (5) 4단계 시험 캠페인 (Curriculum Campaign)

Bench → 평탄지 → 다양 지형 → 야간·위험지 점진 확대 / 4단계 안전 레이어(L1~L4) 점진 적용.

#### (6) Sim2Real 전이 자동화 — Unified Planner

단일 자율공정 모듈이 *㈎ 가상 학습 데이터 생성 · ㈏ 실차 시연 지령 · ㈐ 실차 무인 실행* 3개 모드 담당 → 가상-실차 일관성 구조적 확보.

### 3-2. 추진전략 (6대)

#### (1) 컨소시엄 RnR 최적 분담 (Strength-Matched Allocation)

## 부록 A. 평가위원 관점 강조 팁 모음

### A-1. 사업 개요 (§1)

1. **두 기둥 구조를 처음부터 노출** — RFP §3 ①·②를 *한 플랫폼 공통 자산*으로 동시 대응
2. **"공통 자산" 언어 일관성** — *파라미터화 + 정밀도 가변 multi-physics 통합 DT* 표현 통일
3. **In/Out of Scope 명시** — TRL 3→5 적합 범위, 후속 사업 영역 분리
4. **필요성 4관점은 RFP §2 순서대로** — 정책·기술·시장·사회
5. **수요기업(HDX) 활용 채널을 배경에 명시** — 사전 확보된 채널 강조

### A-2. 목표·KPI (§2)

1. **5대 KPI 모두 RFP 명시 그대로 1:1** — 추가 KPI 욕심 자제
2. **설정 근거 = RFP 인용 + 글로벌 통념 + 수요기업 활용 기준 3종**
3. **평가 방법은 *재현 가능 수준*까지 구체** — 시나리오 수, 반복, 가중치, 계측 도구
4. **정밀도 모드 분리(P1 정밀 / P5 실시간) 명시**
5. **4단계 시험 캠페인 단계별 표** — 점진적 검증 경로

### A-3. 세부 목표 (§2-2)

1. **세부 목표 3개 = "공통 자산 → 기둥 A → 기둥 B" 흐름**
2. **KPI 책임 매트릭스(◎/○/–)** — 책임 공백 없음 시각화
3. **각 세부 목표의 RFP 활용분야 대응 명시**
4. **TRL 3→5 진척을 모든 세부 목표에 명시**

### A-4. 추진방법·전략 (§3)

1. **"Asset-First" 키워드로 본 과제 정체성 압축**
2. **(2) 정밀도 모드 가변은 본 사업 최대 차별화** — 가장 먼저 강조
3. **(4) 2-stage V&V + (5) 4단계 캠페인** — 단계적 검증 신뢰성
4. **(나)(2) 인터페이스 표준 1차년도 합의** — 통합형 사업 실패 1순위 원인 차단
5. **(나)(5) 수요기업 직접 활용 채널** — 사업화 가능성 가산점

### A-5. 활용·기대효과 (§4)

1. **수요기업 직접 활용 채널(HDX)을 첫머리** — 사업화 가능성 가산점
2. **RFP §3 활용분야 ①·②·③ 1:1 매핑 표** — 활용분야 누락 없음 확인
3. **정량 기대효과 = 합리적 범위로 명시** — "30~50% 단축", "5→3회", "80% ↓"
4. **사회적 효과에 건설업 인력난·중대재해 키워드** — RFP §2 (사회) 정합
5. **정책적 효과에 초격차 로드맵·무인공장·SDM 3 키워드 모두**

### A-6. 사회적 가치 (§5-5)

1. **개요에서 직·간접 구분 첫 줄에 명시** — 양식 요구사항 즉시 충족
2. **세부계획 1 = 직접 / 세부계획 2 = 간접** 명확 분리
3. **정량 목표를 세부계획 안에 명시** — 측정 가능해야 평가
4. **RFP §2 (사회) 키워드 그대로 인용**
5. **기대효과는 짧고 강한 단언** — "기대" 보다 "기여·강화"

### A-7. 한건연 1차년도 (§6)

1. **1차년도 = 기반 구축(Baseline) 연차** — KPI 본 평가는 2~4차년도
2. **"기존 자산 활용" 영역 3에 명시** — 군산 시험장 + DX240 강점
3. **In/Out of Scope 1차년도에 특히 중요** — 9개월 한도 신뢰도
4. **데이터 IP 거버넌스 합의 1차년도 명시** — 통합형 사업 disruption 차단
5. **Gantt 영역별 병렬 추진** — 과부하 없음 시각화
