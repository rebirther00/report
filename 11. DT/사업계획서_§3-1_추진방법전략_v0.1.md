## 3-1. 기술개발 추진방법·전략

  o 기술 개발 추진 방법

    - 한국건설기술연구원은 NVIDIA Omniverse 기반 AI 디지털 트윈 플랫폼의 인공지능 학습 영역과 군산 실증 시험장 운용 인프라(토사 베드 제외)를 전담하며, Domain Randomization 시나리오 설계·합성 데이터 생성·강화학습·모방학습 가상 정책 학습·Sim2Real 전이 학습·실차(DX240 굴착기) 적응을 수행함.

    - 기술적 노선은 ETH 취리히 Marco Hutter 연구 그룹의 HEAP(자율 굴착기)·ANYmal(다족 보행 로봇) 작업에서 검증된 표준 학습 레시피(대규모 Domain Randomization + 2단계 System Identification + 실차 demonstration 기반 Fine-tuning)를 추종함.

    - System Identification은 주관(심지) 정밀 DT 모델 동역학을 Isaac Lab actuator surrogate로 변환하는 Level 1과 Isaac Lab 시뮬 응답과 실차 응답 간 잔차를 보정하는 Level 2의 2단계 구조로 설계함.

    - 사업 추진은 4년에 걸쳐 단계적 성숙도 확보 방식으로 진행하며, 1차년도(설계 + 주관 간소화 모델 인수 IF 검토 + Algoryx PoC + GPU 발주) → 2차년도(GPU·PC 반입 + 환경 1차 구축 + 주관 정밀 모델 인수·변환 + Algoryx 백업 활용 + 시험장 1차 정비) → 3차년도(정밀 모델 본격 활용 + 학습 PC+GPU 1세트 추가 + 본격 학습 + 단계별 시험) → 4차년도(4단계 시험 캠페인 + ADT 활용 협업 시범 + KPI 최종 입증)의 흐름을 가짐.

    - 학습 환경은 1차년도 말 발주하는 GPU 학습 클러스터(RTX Pro 6000 Blackwell급 GPU 1매 + 헤드리스 서버 + 분석 PC) 기반 Isaac Lab 다중 환경 병렬 시뮬레이션으로 구성하며, 3차년도에 동급 1세트를 추가 발주하여 분산 학습·실차 적응 동시 운용 캐퍼시티를 확보함.

    - 주관(심지) 굴착기 DT 모델은 2단계로 인수함 — 1차년도 말 간소화 모델 인수(IF·변환·규약 사전 검토), 2차년도 중~말 정밀 모델 인수(Isaac Lab 본격 변환·적용). 인수 지연 위험에 대비하여 1·2차년도 Algoryx 라이센스(연구활동비, 각 1,900만원/년)로 백업 물리 시뮬레이션 경로를 확보함.

    - 통신 인프라(5G/Wi-Fi 6) 구성·검증 및 실차 다중 센서(LiDAR·IMU·카메라·관절 엔코더) 동기 수집 SW 스택 구축을 병행하며, 데이터 동기화 IF는 주관기관 NTP/PTP 모듈과 연계함.

    - 시험장은 군산 실증 시험장을 한건연이 정비(작업 영역·관제실·안전 펜스·CCTV·통신)하며, 토사 베드(모래·자갈·진흙)는 본 사업 외로 실차 시험은 새만금(마사토)·나포(자갈) 외부 베드를 활용함. 최종 목표 시연은 4차년도 나포 자갈 베드에서 ADT 자율 주행 + 굴착·상차 협업 작업으로 수행함.

    - 성능 검증은 두 가지 KPI로 수행함 — (1) 무인작업 성공률 ≥ 90%(4단계 캠페인 종합), (2) 버킷 끝점 경로 추종 RMSE ≤ 10 cm(Hutter 그룹 HEAP 표준 평가법 차용). 추가 성능 지표로 굴착량 버킷 체적 80~120%를 보고함.

  o 기술 개발 추진 전략

    - 컨소시엄 책임 분담 측면에서, 한건연은 AI 학습 핵심 역량에 집중하기 위해 Omniverse 인프라 운영·데이터 동기화·통신 정밀 튜닝은 주관기관(심지)에 위탁하고, 도메인 물리 모델의 nominal·σ는 시뮬·CAE 참여기관(생기원)으로부터 입력받으며, 토사 베드 조성은 새만금·나포 외부 베드를 활용하는 분업 구조를 채택함.

    - Domain Randomization은 over-randomization 원칙을 적용하여 시뮬·CAE 측이 제공하는 토사 파라미터의 측정 분산을 그대로 사용하지 않고 학습용 randomization 확장 계수를 곱하여 실 환경 분포 경계 너머까지 학습함(Hutter 그룹 ANYmal 검증 원칙).

    - Sim2Real 전이는 SysID Level 1(주관 정밀 모델 → Isaac Lab actuator surrogate)을 통해 RL 학습 throughput을 확보하고, Level 2(Isaac Lab → 실차 잔차 보정 NN, Hutter ANYmal Actuator Network 방식)와 Fine-tuning 파이프라인을 결합하여 최종 적응 정책을 생성함.

    - 학습 인프라는 GPU 1매 기반 단일 워크스테이션 분산 시뮬레이션 구성으로 1차년도 말 출발하되, 학습 서버는 PCIe 슬롯 2개·1.6 kW 이상 PSU·멀티 GPU 메인보드 사양으로 구성하여 후속 GPU 추가 확장 가능성을 확보하고, 3차년도에 동급 학습 PC+GPU 1세트를 추가 도입하여 분산 학습·실차 적응 동시 운용 환경을 완성함.

    - 위험 관리 측면에서, 주관(심지) 굴착기 DT 모델 인수 일정 지연 위험에 대비하여 1·2차년도 Algoryx 라이센스(연구활동비, 각 1,900만원/년)를 백업 물리 시뮬레이션 경로로 도입하며, 1차년도 말 간소화 모델 사전 인수와 2차년도 중~말 정밀 모델 본격 인수의 2단계 인수 흐름을 통해 점진적 위험 분산을 달성함.

    - 재료비 단가는 부가세 포함 2,000만원 미만으로 분할 발주하여 KEIT 별첨 자료 작성을 회피하는 양식을 채택함.

    - 시험장은 군산 정비(작업 영역·관제실·안전 펜스·CCTV·통신)와 외부 베드 활용(새만금 마사토·나포 자갈)의 이원 구조로 운영하며, 4차년도 ADT 활용 협업 시범은 나포 자갈 베드에서 자율 주행 + 굴착·상차의 최종 목표 시연으로 수행함.

    - 본격 학습·측정·검증은 주관 정밀 모델 본격 활용 후 3차년도부터 시작하는 단계별 진행 원칙을 유지하여, 1·2차년도 placeholder 자산 및 Algoryx 백업 학습 결과는 도구·SW 골격 검증 목적으로 제한함.
