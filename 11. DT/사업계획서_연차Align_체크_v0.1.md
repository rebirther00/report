## 4. 정합성 위험 지점 6건

### 위험 1. 1차년도 한건연 ↔ 생기원 IF 미명시 ★★

- **사실**: 한건연 1차 ① DR 시나리오 설계 시 토사 nominal·σ를 생기원으로부터 받아야 하나 본문에 IF 명시 없음
- **원인**: 생기원 1차는 "분석·검토" 수준으로 한건연 입력 데이터 산출 명확화 부족
- **권고**: 한건연 1차 ① 또는 생기원 1차 ③·④에 "한건연 DR 시나리오 입력용 토사 nominal·σ 데이터 IF 제공" 단서 1줄 추가

### 위험 2. Isaac Sim 환경 구축 R&R 중복 가능성 ★★★

- **사실**: 양쪽 본문 모두 "Isaac Sim 가상 학습 환경 **구축**"으로 표현
  - 심지 2차 ⑤ "Isaac Sim 가상 학습 환경 구축"
  - 한건연 2차 ① "가상 환경·합성 데이터셋 구축"
- **원인**: 한건연 [§6-2 v0.5](사업계획서_§6-2_한건연_연차별_v0.5.md) 에서 "심지=인프라 운영, 한건연=학습 주체로 도구 활용 범위 결정"으로 정리한 것이 본 과제 본문에 반영되지 않음
- **권고**: 어휘 분리 — 심지 2차 ⑤ "Isaac Sim **인프라 구축**" / 한건연 2차 ① "Isaac Sim **운영·콘텐츠 구축**"

### 위험 3. 자율공정계획 본문 ↔ §6-2 v0.5 정정 충돌 ★★★

- **사실**:
  - 본 과제 본문 1-1 line 110 "자율공정계획 수립 기술 적용" = "심지, 한건연" 공동
  - 그러나 한건연 1·2·3·4차 ①·②·③에 자율공정계획 키워드 0건
  - 한건연 §6-2 v0.5 정정 ([c07bf3b](../commit/c07bf3b))에서 "IF 협력 수준으로 약화"
- **원인**: 본문(1-1)과 한건연 §6-2 정정안 불일치
- **권고**: 본문 line 110 정정 — "심지 주관, 한건연 IF 협력" 또는 한건연 분담 단서 제거

### 위험 4. 전동시스템 본문 모순 ★★★

- **사실**:
  - 1-1 line 88 "유압시스템·파워트레인·**전동시스템** 등"
  - 그러나 5개 기관 × 4차년도 = 20셀 어디에도 "전동시스템" 키워드 0건
  - 심지 2차 ③ "**전기굴착기** FMU 빌드" 정도가 가장 가까움 (단, 전기굴착기 ≠ 전동시스템 모델)
- **원인**: RFP "유압·전동·동력 등" 표현을 1-1에 그대로 인용했으나 실제 개발 항목에 미반영
- **권고**: 1-1 line 88에서 "전동시스템" 제거하거나, 심지·생기원 차년도 항목에 "전동시스템 모델" 명시 추가. 직전 [전동시스템 RFP 대응 논리 v0.1](사업계획서_전동시스템_RFP대응_v0.1.md) 적용 가능

### 위험 5. 이중 트랙 명시 부족 — DT 모델 3종 vs AI 학습 1종 ★★

- **사실**:
  - 심지·생기원이 굴착기·휠로더·전기굴착기 3종 다물리 모델 개발 (P3 ≥ 3종)
  - 한건연 AI 학습은 **24톤급 굴착기(DX240) 1종 한정**
- **원인**: 두 기둥(Two-Pillar) 구조 — 정밀 트랙(3종 OEM 활용) + AI 학습 트랙(1종 자율작업) — 본문에 명시 부재
- **권고**: 1-1 정의 단락 또는 2-1 최종목표에 두 기둥 구조 명시 ([§2-1 최종목표 v0.1](사업계획서_§2-1_최종목표_v0.1.md) 옵션 B 채택)

### 위험 6. 4차 데이터셋 자산화 ↔ 협회 4차 분담 모호 ★

- **사실**:
  - 한건연 4차 ③ "데이터셋 자산화"
  - 협회 4차 "DT 상용화 제도 개선·성과 공유"
- **원인**: 자산화 = 한건연이 패키지화 → 협회가 산업계 확산? IF·시점 모호
- **권고**: "한건연 = 표준 데이터셋 패키지화 산출, 협회 = 산업계 확산·법제도 매핑 담당" 식으로 분담 단서 본문에 1줄 추가
