<1차년도>

▪ 합성 학습데이터 생성 환경 구축
- 가상 환경 자율작업 시나리오 정의 (굴착·터파기·상차 등) : 작업 단위를 표준화하고, 각 시나리오에 대해 지형 기하, 기상 변동 조건, 토양 물성 등을 검토하여 합성 데이터 생성 시 사용할 요소를 정의함.
- 물리기반 시뮬레이션 플랫폼(NVIDIA Omniverse·Isaac Sim/Lab)을 활용한 환경 변화 무작위화(Domain Randomization) 파이프라인 구축: 조도, 기하, 기타 파라미터 변동을 자동 조정하는 DR 파이프라인을 구축. 학습용 랜덤 계수(토사)는 관련 기관의 정보를 고려하여 랜덤 시드 정책을 수립. 
- 합성 데이터용 센서 사양 정의(LiDAR·카메라·IMU·압력센서 등): 굴착기 자율 작업에 적합한 실차 탑재 센서 후보 모델과 이에 대응되는 합성 데이터용 모델을 파악하여 관측 간극을 사전 최소화. 센서 캘리브레이션 전략 검토 필요.
- 단계별 모델 통합을 위한 모델 연계 인터페이스(FMUsurrogate model) 사전 정의
▪ AI 정책 학습 환경 설계
- Isaac Lab 기반 AI 학습 환경 아키텍처 설계: Isaac Lab의 환경 추상화, 작업 인터페이스, 학습 분산 구성을 바탕으로 궤도형 굴착기의 학습 환경 아키텍처를 설계. 작업부 다관절·토사 상호작용 등 굴착기 특수성을 반영하기 위한 모듈 개발.
- 굴착기 자율 작업용 강화학습(RL)·모방학습(IL) 알고리즘 후보 선정 및 학습 파이프라인 설계: 기존 선행 기술을 기준선으로 하여 PPO·SAC(RL) 및 BC(IL) 후보를 비교하여 굴착기 자율 작업용 알고리즘을 1차 선정. 학습 파이프라인은 환경-에이전트-보상-평가 4단 구성으로 설계함.
- RL·IL을 위한 보상 함수·관측·행동·평가지표 설계: 보상합수는 작업 완료(굴착 부피·경로 추종 정확도 등)·안전(작업영역 이탈, 충돌 등)·효율(작업 시간 등)의 다목적 가중 구성으로 설계. 관측은 다중 센서 융합(LiDAR, IMU, 압력 등), 행동은 관절 속도 또는 그에 준하는 제어 입력(조이스틱 등) 등 다각도로 검토하여 설계함.
- Algoryx AGX 기반 저정밀 가상모델 구축: AGX 물리엔진 기반 저정밀 가상모델을 PoC 수준으로 구축. 토사-버킷 상호작용 입자 모델과 간소화 굴착기 강체 모델로 1차 시뮬레이션 사이클(굴착)을 검증하여 추후 환경 구축의 기준선으로 활용.

▪ Sim2Real 전이·간극 측정 체계 설계
- Sim2Real 전이 평가 프로토콜 및 핵심 평가지표(작업별 성공률·정확도·사이클타임) 정의: 시뮬-실차 동일 시나리오 조건에서 측정 비교하는 절차를 표준화하여 초안 수립.
- 자율작업 시나리오⨉환경 조건(지형·조도·기상 등) 조합으로 구성한 전이 평가 시나리오 세트 설계
- 가상-실차 간극 측정 방법론 정의: 가상-실차 간극을 센서 노이즈왜곡, 물리 응답, 정책 출력 차이의 계층 매트릭으로 정의, 각 층별 측정 절차합격 기준의 초안을 수립.

▪ 실차 데이터 수집 체계 및 시험 환경 설계
- 무인화 장비 학습·평가 환경 구축을 위한 센서·온보드 GPU 선정: 합성 데이터용 사양서와 대응되는 센서(LiDAR, 카메라, IMU 등)을 통합 선정. 온보드 GPU는 추론지연 속도를 고려하여 운용 가능 한 모델을 선정.
- 다중 센서 데이터 수집·저장 인프라 설계
- 테스트 베드 5G/Wi-Fi6 통신 네트워크 구성 설계 및 시험장 정비 방안 검토
- 샘플 시연 데이터 수집 및 수집 체계 적합성 검토: 보유 굴착기로 굴착 1 사이클 데이터 취득을 수행. 센서 동기화라벨저장 파이프라인을 1차 검증.

<2차년도>

▪ 디지털 트윈 모델 기반 합성 데이터셋 생성 환경 조성
- Isaac Lab 가상 학습 환경 구축: 1차년도 아키텍처를 바탕으로 Iassc Lab 가상 학습 환경을 구축. 작업 관리자 동작 확인. 학습 wall-clock 측정으로 학습 속도 확인.
- 환경 변수(지형·조도·기상 등)를 고려한 합성 데이터 생성: 1차년도 DR 파이프라인을 활용하여 다양한 환경 변수 조건이 반영된 합성 데이터셋을 생성. 시나리오의 작업 단위별(굴착, 선회, 상차 등)로 충분한 사이클 수를 확보함.
- 합성 데이터 라벨 자동화 도구 구축: 합성 데이터의 인스턴스 분할(작업부, 토사, 차량 등), 작업 단계 라벨, 환경 메타데이터를 자동 라벨링하는 도구를 구축. 라벨 정확도일관성을 확보하고, 합성실차 라벨 스키마를 통일.

▪ 저정밀 가상모델 기반 AI 정책 사전학습
- Algoryx AGX 기반 저정밀 가상모델 사전학습 환경 구축: 1차년도 AGX PoC를 바탕으로 저정밀 가상모델 사전학습 환경을 구축. 학습 가속을 위한 시뮬레이션 step rate 최적화, 학습 wall-clock메모리 사용 프로파일 측정하여 사전학습 조건을 확인
- 저정밀 가상모델 기반 단위작업 RL/IL 정책 사전학습: 단위작업 별 RL/IL 정책을 가상모델에서 사전학습하고 적합 알고리즘을 결정함. 보상 함수랜덤화 강도의 조정을 통해 학습 안정성성공률을 확보.

▪ Sim2Real 전이 및 간극 기준치 측정
- 저정밀 가상 모델 기반 Sim2Real 전이 샘플 시연 검증: 저정밀 가상모델에서 사전학습한 단위작업 정책을 실차에 1회 시범적용하여 도구파이프라인SW 등을 사전 검증. 
- 가상-실차 성능 간극 측정 도구 구현: 1차년도 정립한 측정물리정책 간극 측정도구를 시제품 수준으로 구현. 시뮬-실차 동일 시나리오에서 매트릭을 산출로깅하는 도구 체인을 구축하고, 측정 데이터의 일관성재현성을 검증.
- 도메인 적응(fine-tuning) 파이프라인 설계 및 실차 소량 데이터 활용 시범 구동: 가상에서 사전학습한 정책을 실차 소량 데이터로 fine-tuning하는 도메인 적응 파이프라인을 설계하고 시범 구동. 사전 학습 가중치 고정일부 레이어만 갱신전체 fine-tuning 등의 적응 전략을 비교하여 fine-tuning 파이프라인 구축 연계를 준비.

▪ 실차 데이터 수집 체계 및 시험 환경 구축
- 실증 굴착기 센서·온보드 GPU 설치 및 캘리브레이션: LiDAR카메라IMU 등 캘리브레이션 절차를 수립하고 수행함. 
- 센서 데이터 수집·동기화 기능 구현 및 검증
- 5G/Wi-Fi 6 통신 인프라·시나리오 시험장 조성: 시나리오 작업영역위험지역 등을 정비하여 구분함.

<3차년도>

▪ 디지털 트윈 모델 기반 합성 데이터셋 생성 환경 확장
- 합성 데이터 생성 환경 정밀 모델 통합: 주관 제공 정밀 굴착기토사 모델을 인터페이스 명세에 따라 합성 데이터 생성 환경에 통합. 정밀 모델 기반 작업 시뮬레이션의 정확도실행 속도를 측정함.
- 작업환경 변형(지형·조도·기상) 시나리오 확장: 지형(평단경사험지)조도(주야) 등 변형 시나리오를 단계적으로 확장. 확장 시나리오별 합성 데이터의 모델 일반화 효과를 검증.
- 생성형 모델 통합 적용을 통한 합성 영상 포토리얼 변환 검토: 합성 영상의 실차 도메인 격차를 줄이기 위해 생성형 모델을 합성-실차 변환에 적용 검토. 해당 변환을 통한 관측 간극 축소 기여도를 평가하여 실사화를 반영할지 여부 결정. 

▪ 정밀 가상모델 기반 학습
- 정밀 굴착기 모델 및 토사 모델 연동: 주관 제공 정밀 굴착기 모델과 토사 모델을 학습 환경에 연동. 모델 간 데이터 인터페이스계산 단계물성 매핑을 점검하고 학습 루프에서 모델 안정성을 검증함.
- Isaac Sim 기반 모델 통합 및 가상 정책 본격 학습(RL/IL): 학습 분산을 확장하고, 단위 작업 정책의 성공률정확도사이클타임을 측정.
- 굴착기–운반차량(ADT) 협업 사이클(굴착-선회-상차) 정책 학습: 굴착기-ADT 협업 사이클(굴착-선회-상차)을 정책 학습. 굴착기와 운반차량 간 위치작업 타이밍 동기화, 상차 정확도, 사이클 시간을 보상에 반영하여 협업 정책의 안정성반복성을 확보.

▪ Sim2Real 간극 축소·도메인 적응
- 정밀 모델 기반 학습 정책의 실차 1차 전이 시험: 정밀 모델 기반으로 학습된 정책을 실차에 1차 전이하여 본격적인 전이 시험을 수행하고, 실차 작업 성공률정확도 등을 측정하여 가상-실차 간극의 정량 baseline을 확보.
- 도메인 적응 자동화 – 실차 데이터 활용 fine-tuning 파이프라인 구축: 2차년도 fine-tuning 파이프라인 설계를 기반으로 실차 데이터 활용 도메인 적응 자동화 파이프라인을 구축. 실차 수집 데이터로부터 자동 라벨fine-tuning평가의 루프를 구성하여 구동함.
- 가상-실차 성능 간극 측정 및 보정 사이클 검토: 정밀 모델 기반에서 본격 측정하고, 측정 결과를 토대로 정밀 모델 파라미터를 보정하는 사이클을 운영. 
▪ 실차 데이터 수집 및 단계별 시험
- 실증 굴착기 실차 데이터 수집 및 자동/수동 라벨링: 실증 굴착기를 활용해 다양한 작업 시나리오환경 조건에서 데이터를 본격 수집. 자동 라벨과 수동 라벨(작업 단계이상 이벤트 등)을 결합하여 라벨 품질을 확보하고 fine-tuning간극 측정용 데이터셋으로 활용
- 단위작업에 대한 실차 시연 검증 (새만금 마사토 베드 활용): 굴착상차 등 단위 작업을 실차에서 시현 검증. 단위작업별 성공률정확도를 시연 평가.
- 적응 정책 실차 1차 검증 및 KPI baseline 측정

<4차년도>

▪표준 데이터 셋 구성 및 통합 시나리오 보완
- 굴착기+ADT 통합 시나리오 합성 데이터 보강: 굴착기+ADT 협업 시나리오의 합성 데이터를 보강. 굴착-선회-상차 사이클차량 간 위치 관계상차 정확도 등 협업 특성 변동 조건을 반영함. 
- 3차년도 실증 피드백 반영 데이터 갱신: 1차 전이간극 측정 결과를 토대로 합성 데이터 분포를 보정. 측정된 간극이 큰 시나리오에 합성 데이터를 보강하고, 불필요한 분포는 정리하여 합성 효율성을 확보.
- 라벨·품질 재검증 및 학습·검증·실증용 표준 데이터셋 패키지화 
▪통합 정책 최종 학습
- 가상 정책 최종 학습평가: 축적된 학습 자산과 보정된 합성 데이터정밀 모델을 활용해 통합 정책을 최종 학습. 굴착기 단위작업+ADT 협업 사이클을 포함한 통합 정책의 성공률정확도 등을 가상에서 최종 평가하여 실차 최종 전이의 학습 기준선으로 확정.
