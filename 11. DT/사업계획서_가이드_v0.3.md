>  (a) 도메인 벤치 V&V 항목 삭제 (예산 축소),
>  (b) Omniverse 인프라 운영 책임 주관(심지) 이관 (단, AI 학습 주체로서 GPU·도구 활용 범위는 한건연 결정),

> 연계 : 본 문서는 v0.2의 §6-2 1·2·3차년도를 본 문서가 대체. 4차년도·§7·기타 섹션은 후속 버전에서 순차 갱신.

## §6-2 한건연 1차년도 연구개발 내용 및 범위 (확정)

> 형식 규칙 : 대항목 3개(A·B·C), 각 sub-bullet 3~5개.
> 흐름 : A(가상 학습 환경 + DR PoC + 주관 간소화 모델 IF 검토 + 발주 검토) → B(Sim2Real 전이 설계) → C(실차 수집·통신·시험장 설계, 토사 베드 제외)

### ▣ 1차년도 (9개월, 설계 중심 + 주관 간소화 모델 인수 IF 검토)

  o A. NVIDIA Omniverse 기반 AI DT 플랫폼 운용 환경 설계 및 시각 DR PoC

    - 인프라 운영은 주관(심지) 담당을 전제로, AI 학습 주체로서 한건연 측 GPU 학습 클러스터(RTX Pro 6000 Blackwell 등) 및 분석 PC 사양 정의, Isaac Sim·Isaac Lab·Isaac Replicator 도구별 활용 범위 결정

    - 가상 작업 태스크 정의(터파기·상차·평탄화 등), RL 학습 환경 요구사항 정의(관측·행동·보상 함수 등) 및 선행 기술(논문) 조사를 통한 적용성 분석

    - Domain Randomization 시나리오 설계 — 시뮬·CAE(생기원) 측 토사 nominal·σ 입력 IF 협의 및 학습용 randomization 확장 계수·지형 기하 변동 라이브러리 결정

    - 주관(심지) 굴착기 간소화 DT 모델(1차년도 말 인수 예정)에 대한 인터페이스·변환·규약 사전 검토 — Simscape/USD/URDF 변환 경로·관절 좌표계·단위계 일치성 점검

    - Algoryx 기반 굴착기·토사 상호작용 1차 PoC 검토 — 주관 모델 인수 지연 대비 백업 물리 시뮬레이션 경로 확보 (HEAP open URDF·heightfield 지형 기반 DR PoC와 병행)

    - 1차년도 말 GPU 학습 클러스터·분석 PC 발주를 위한 주요 재료비 산정·구매 검토 (실 반입·구성 검증은 2차년도 초)

  o B. Sim2Real 전이 학습 및 실차 적응 알고리즘 설계

    - Sim2Real Gap 메트릭 계층 정의(observation·dynamics·policy) 및 측정 절차·필요 데이터량·합격 기준 초안 수립

    - 전이 사례 벤치마킹(Hutter 그룹 HEAP·ANYmal 등)을 통한 Sim2Real 전이 전략 선정 — DR + SysID(Simscape→Isaac Lab Level 1 + Isaac Lab→실차 Level 2 2단계 구조) + 실차 Fine-tuning 조합 적용성 분석

    - 실차 시연 데이터 정의(작업 단계 phase 라벨·IP 거버넌스) 및 시연 시나리오 선정(평지·터파기·상차·안전 영역 내 작업 등)

  o C. 실차 데이터 수집 체계 및 시험 환경(통신·시험장) 설계

    - 다중 센서(LiDAR·IMU·카메라·관절 엔코더) 수집 SW 스택 설계 — 센서 사양·위치는 기정의, 데이터 동기화 IF는 주관(심지) NTP/PTP 모듈 연계

    - 5G/Wi-Fi 6 통신 네트워크 구성 설계와 군산 시험장 정비 조성 검토(작업 영역·관제실·안전 펜스·CCTV) — 토사 베드 조성은 본 사업 외 (실차는 새만금 마사토·나포 자갈 외부 베드 활용)

    - 샘플 시연 데이터 1회 수집(평지 굴착) 및 수집 체계 적합성 검토

    - DR 시나리오 실제 모델 기반 갱신 및 합성 데이터 생성

    - Isaac Lab Headless 분산 학습 클러스터 가동 — 가상 정책 학습 (RL/IL)

    - Sim2Real Gap 1차 측정 및 보정 사이클 검토·운영

## 짚어둘 점 (1·2·3·4차년도 횡단)

1. GPU·PC 회계 처리 : 1차년도 말 계약·발주는 회계상 1차년도 예산. 조달 지연 시 2차년도 초로 슬립되면 2차년도 재료비 편입 가능 → 회계 담당자와 사전 협의. 3차년도 학습 PC+GPU 1세트 추가 발주도 동일 원칙.

2. 주관 모델 인수 의존성 : 1차년도 말 간소화 모델·2차년도 중~말 정밀 모델 인수가 지연되면 본격 학습 일정 연쇄 지연. 1차년도 A의 사전 IF 검토와 Algoryx 백업 경로가 이 리스크 완화 장치 — 주관과 정기 점검 권장.

3. Algoryx 운용 범위 : 1·2차년도 한정. 주관 정밀 모델 본격 활용 시점인 3차년도부터는 운영 여부 별도 검토. 1차년도엔 PoC 수준, 2차년도엔 prototype 학습 보조.

4. 토사 베드 책임 : 토사 베드 조성(모래·자갈·진흙)은 한건연 일 아님. 실차 시험은 새만금(마사토)·나포(자갈) 외부 베드 활용. 시험장 정비(작업영역·관제실·안전펜스·CCTV·통신)는 한건연 유지. 평가자 질문 대비해 "외부 베드 활용" 단서 본문 유지.

5. SysID·Fine-tuning 시점 : 2차년도엔 도구·프레임워크·SW 골격 중심 (주관 정밀 모델 인수·변환 적용까지). 본격 학습은 3차년도. 평가자 질문 대비해 "3차년도 본격 학습" 단서 본문 유지.

6. 안전 레이어 : 본 사업 스코프 외. KPI(성공률) 보조 개념으로만 다루고, 인증·규제 대응은 후속 사업 주제로 분리. 평가자가 "안전은?"이라 물을 경우 "본 사업은 TRL 3~5 단계, 안전 인증은 후속 사업 영역"으로 답변 가능.

7. 통신 정밀 튜닝 : 주관(심지) 담당. 한건연은 5G/Wi-Fi 6 네트워크 구성·검증까지만, 데이터 동기화 성능 튜닝은 주관 일. §6-2 본문에서 "통신 정밀 튜닝" 표현 사용 안 함.

8. 단계별 시험 vs 검증 : 3차년도 = 단계별 시험(터파기·상차·정지 단계별 합격 판정 + KPI baseline 측정), 4차년도 = 4단계 캠페인 검증 + ADT 활용 협업 시범 + KPI 최종 입증. 두 차년도 역할 분리 명확화.

9. ADT 활용 협업 : 4차년도 B-3에 1줄 sub-bullet으로 압축 (자율 주행 + 굴착·상차 협업 작업 1회 시범, 나포 자갈 베드 최종 목표 시연). 별도 대항목으로 두지 않음.

## §6-5 한건연 KPI 정의·측정 방법 (확정)

> 4차년도 최종 입증 대상 KPI 2개. §6-2 본문에서는 정성어로만 명시하고, 정량 수치·측정 방법은 본 장에 일괄 정리. KPI 1은 거시(작업 완수), KPI 2는 미시(작업 품질) 지표로 상호 보완.

### KPI 1 — 무인작업 성공률 ≥ 90%

#### 정의

| 항목 | 내용 |
|---|---|
| 무인작업 | 시작·중단 신호 외 인간 개입 없이 1회 작업 cycle 완수 |
| 1 cycle | 사전 정의 작업 단위 (예: 1회 굴착 → 상차 → 정지) |
| 성공 cycle | 합격 기준 모두 충족 |

#### 합격 기준 (cycle 1회 성공 판정)

1. 작업 sequence 완수 — 목표 동작 단계(굴착·상차·정지 등) 모두 수행
2. 안전 정지·인간 개입·외부 중단 없음
3. 작업 결과 정량 지표 충족
   - 상차 토사량: 목표 부피의 ±20% 이내 (또는 Bucket fill factor ≥ 80%)
   - 버킷 끝점 최종 도달 위치 오차: ±20 cm 이내
4. 1 cycle 120초 이내 완료 (timeout)

> 위 수치는 1차년도 초안 (Hutter 그룹 HEAP·일반 굴착기 표준 참고). 2~3차년도 baseline 측정 후 4차년도에 최종 확정.
> 참고 — KPI 2(RMSE ≤ 10 cm)는 trajectory 전체의 평균 오차, 위 "최종 도달 위치 오차 ±20 cm"는 1 cycle 종점의 단일 위치 오차. 둘은 다른 지표 (RMSE 10 cm일 때 종점 ±20 cm가 자연스러운 수준).

#### 측정 절차

1. 4단계 캠페인 (Bench → 평탄지 → 다양 지형 → 야간·위험지) 각 N cycle 시험
2. cycle별 합격/불합격 자동 판정 (수집 SW + 검증자 확인)
3. 종합 성공률 = (성공 cycle 합) / (전체 cycle 합) × 100
4. KPI 달성 = 종합 성공률 ≥ 90%

#### 표본 수

- 단계당 N ≥ 20 cycle (4단계 × 20 = 80 cycle 최소)
- 통계 신뢰도 95% 기준 부족 시 추가 시험

#### 평가 환경·도구

- 4차년도 4단계 캠페인 (§6-2 4차년도 B-2)에서 수행
- 자동 로깅 (3차년도 C-1 수집 SW 활용)
- 합격 판정 자동화 도구 (2차년도 B-1 Sim2Real Gap 측정 도구 확장)

---

### KPI 2 — 버킷 끝점 경로 추종 RMSE ≤ 10 cm (1차 목표)

#### 정의

| 항목 | 내용 |
|---|---|
| 측정 대상 | 굴착 작업 중 버킷 끝점(Tip)의 3D 위치 궤적 |
| 기준 | 사전 정의 목표 trajectory (작업 시나리오별 사전 설계) |
| 메트릭 | 시간 정렬 후 점별 위치 차이 RMSE (3D 공간, cm 단위) |
| 학술 근거 | Hutter 그룹 HEAP 평가 표준 (Jud et al. 2021 "HEAP", Egli et al. 2022 "Soil-Adaptive Excavation" 등) |

수식:

```
RMSE = sqrt( mean( (x_target(t) - x_actual(t))² + (y_target(t) - y_actual(t))² + (z_target(t) - z_actual(t))² ) )
```

#### 목표

- 1차 목표: 평균 RMSE ≤ 10 cm
- 도전 목표: 평균 RMSE ≤ 5 cm (옵션)

#### 측정 절차

1. 목표 trajectory 정의 — 작업 시나리오별 사전 설계 (평탄 굴착·경사 굴착·상차 등)
2. 자율 정책 실행 — 실차에서 N cycle 수행
3. 버킷 끝점 3D 궤적 측정 — 관절 엔코더 + forward kinematics 계산, 또는 LiDAR/IMU 보조 측정
4. 시간 정렬 후 RMSE 계산 — Dynamic Time Warping(DTW) 또는 시간 동기 보간
5. N cycle 평균 RMSE + 시나리오별 평균 산출
6. KPI 달성 = 평균 RMSE ≤ 10 cm

#### 평가 환경·도구

- 4차년도 4단계 캠페인 (§6-2 4차년도 B-2)에서 성공률(KPI 1)과 동시 측정
- 자동 로깅 (3차년도 C-1 수집 SW)
- 분석 도구 — 2차년도 B-1 Sim2Real Gap 측정 도구 확장 (trajectory 비교 모듈 추가)

#### 보조 측정 (KPI는 아니나 보고서 첨부 권장)

- Cycle Time (s)
- Volume per Cycle (m³ 또는 kg)
- Joint Tracking RMSE (°)
- Force/Torque Profile (정성 비교)

---

### KPI 1·2 상호 보완

| 지표 | 의미 |
|---|---|
| KPI 1 (성공률 ≥ 90%) | 거시 — 작업 완수 여부 |
| KPI 2 (RMSE ≤ 10 cm) | 미시 — 작업 품질·정밀도 |
| 둘 동시 달성 | 정밀한 무인작업 입증 |

성공률만으로는 "겨우 완수"와 "정밀 완수"가 구분 안 되므로 RMSE가 이를 보완.

### 임계값 확정 흐름

| 시점 | 활동 |
|---|---|
| 1차년도 | KPI 정의·측정 방법 초안 수립 (본 장) |
| 2~3차년도 | placeholder·실제 모델 baseline 측정·반복 |
| 4차년도 | baseline 기반 임계값 최종 확정·KPI 최종 입증 |
