## 2. 시점 게이트 Gap 8건

### Gate 1. 1차년도 — 생기원 토사 분석 결과 → 한건연 DR 시나리오 입력 ★★

| 항목 | 내용 |
|---|---|
| **의존 관계** | 한건연 1차 ① DR 시나리오 정의 시 토사 nominal·σ 입력 필요 ← 생기원 1차 ①·②·③ 토사 물성·반력 분석 |
| **시점 위험** | 생기원 1차 ①~③은 "분석·검토" 수준 (모델링 기법 검토)이라 정량 nominal·σ 데이터 산출 시점 불명. 한건연 1차 ① 개념 설계 단계에서 입력으로 받을 수 있는지 불명확 |
| **빠듯도** | 9개월 — 생기원 분석 7~8개월 + 한건연 시나리오 정의 입력 가능 시점 1~2개월. **빠듯** |
| **권고** | (a) 생기원 1차 ③·④에 "한건연 DR 시나리오 입력용 토사 파라미터 IF 1차 산출" 단서 명시<br>(b) 한건연 1차 ① 시나리오 정의는 토사 nominal·σ가 미확정인 경우에도 시작 가능한 **placeholder 시나리오 + 후속 보정** 구조 명시 |

### Gate 2. 2차년도 — 심지 Isaac Sim 환경 구축 → 한건연 합성 데이터셋 생성 ★★★

| 항목 | 내용 |
|---|---|
| **의존 관계** | 한건연 2차 ① 가상 환경·합성 데이터셋 구축은 심지 2차 ⑤ Isaac Sim 가상 학습 환경 구축이 선행되어야 |
| **시점 위험** | 본문에 심지 2차 ⑤ 완료 시점 명시 없음. 2차 = 10개월. 심지 ⑤가 2차 말에 완료되면 한건연 ①은 거의 시작도 못 함 |
| **빠듯도** | 매우 빠듯. 심지 ⑤를 2차 상반기(5개월) 안에 완료해야 한건연 ①이 5개월 안에 진행 가능 |
| **권고** | (a) 심지 2차 ⑤를 **2차 6개월 내 완료** 단서 명시<br>(b) 한건연 2차 ①은 1차 ① 개념 설계 단계에서 환경 사양·아키텍처 사전 확정으로 2차 진입 즉시 작업 시작<br>(c) 위험 2(어휘 분리) 적용 — 심지 인프라 vs 한건연 콘텐츠 명확 분리하여 2차 초반 병행 가능 구조 |

### Gate 3. 2차년도 — 심지 정밀 모델 인수 시점 ★★★

| 항목 | 내용 |
|---|---|
| **의존 관계** | 한건연 3차 ① 고정밀 모델 기반 학습 환경 고도화는 심지가 정밀 굴착기 모델을 2차 중~말에 인수 완료해야 진입 가능 |
| **시점 위험** | 한건연 [§6-2 v0.5](사업계획서_§6-2_한건연_연차별_v0.5.md) 에 "주관 정밀 모델 2차 중~말 인수" 명시되어 있으나 본 과제 본문에는 정밀 모델 인수 시점 단서 부재 |
| **빠듯도** | 정밀 모델 인수가 2차 말 (10개월차) 지연 시 한건연 3차 ① 진입 시점이 3차 초반 → 한건연 3차 12개월 일정 빠듯 |
| **권고** | (a) 본 과제 본문 심지 2차 ②·③ "DX240 다물리 모델 + FMU 빌드"의 한건연 인수 시점을 **2차 8개월차** 명시<br>(b) 한건연 §6-2 v0.5의 "간소화 모델 1차 말 인수 + 정밀 모델 2차 중~말 인수" 2단계 인수 구조를 본문에 통합<br>(c) Algoryx AGX 백업 경로 (1·2차 라이센스) 단서를 본문에도 명시하여 인수 지연 위험 완화 |

### Gate 4. 2차년도 — 생기원 작업반력 계측 모듈 제작·장착 → 한건연 데이터 수집 ★★★

| 항목 | 내용 |
|---|---|
| **의존 관계** | 한건연 2차 ③ 실차 작업 데이터 수집은 생기원 2차 ① 작업반력 계측시스템 모듈을 한건연 실차에 통합 장착해야 가능 |
| **시점 위험** | 생기원 2차 ①: 모듈 설계 → 제작 → 한건연 실차 장착 → 캘리브레이션 → 검증의 5단계가 2차 10개월 안에 완료되어야. 그 후 한건연이 데이터 수집 |
| **빠듯도** | 매우 빠듯. 생기원 모듈 작업 7~8개월 + 한건연 데이터 수집 2~3개월 |
| **권고** | (a) 생기원 2차 ①에 "한건연 실차 통합 장착은 2차 6~8개월차 완료" 시점 단서 명시<br>(b) 한건연 2차 ③ 데이터 수집은 2차 6개월차부터 단계적 시작 — 생기원 모듈 일부 장착 시점부터 부분 데이터 수집 병행 구조<br>(c) 한건연 1차 ③에서 사전 발주된 다중 센서 시스템(LiDAR·Camera·IMU 등)으로 생기원 모듈 외에 일반 작업 데이터 선행 수집 가능 |

### Gate 5. 3차년도 — 생기원 DT 플랫폼 토사 IF → 한건연 학습 환경 고도화 ★★

| 항목 | 내용 |
|---|---|
| **의존 관계** | 한건연 3차 ① 고도화에 토사 모델 통합 필요 ← 생기원 3차 ⑤ DT 플랫폼 연계용 토사 물리모델 인터페이스 구현 |
| **시점 위험** | 생기원 3차 ⑤ 시점 불명. 3차 말에 완료되면 한건연 3차 ① 고도화·② 본격 학습 일정 영향 |
| **빠듯도** | 중간. 12개월이라 어느 정도 여유 있음 |
| **권고** | (a) 생기원 3차 ⑤에 "3차 6개월차 1차 IF 산출, 3차 말 본격 통합" 단계 단서 명시<br>(b) 한건연 3차 ① 고도화는 토사 IF 미통합 단계에서도 정밀 굴착기 모델만으로 1차 진행 가능한 구조 |

## 5. 보강 — 한건연 측 위험 완화 장치

본 게이트 Gap이 본문에 정정되지 않더라도 한건연 측에서 다음 위험 완화 장치를 §6-2 v0.5에 명시함:

| 위험 | 완화 장치 (§6-2 v0.5 명시) |
|---|---|
| Gate 2·3·6 — 심지 인프라·모델 인수 지연 | Algoryx AGX 라이센스 (1·2차 각 1,900만원/년) 백업 물리 시뮬레이션 경로 |
| Gate 4 — 생기원 모듈 장착 지연 | 한건연 1차 ③에서 사전 발주된 다중 센서로 일반 작업 데이터 선행 수집 가능 |
| Gate 7 — 심지 통합 테스트 ↔ 한건연 실증 분담 모호 | 한건연 4차 4단계 캠페인(Bench→평탄지→다양 지형→야간·위험지) 자체 절차로 독립 운영 가능 |

→ 본 과제 본문이 시점 단서 미명시 상태로 통과되어도 한건연 측 위험은 §6-2 v0.5의 완화 장치로 일정 부분 흡수됨.
