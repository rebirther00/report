# 기관별 RnR 및 예산안

## 1. 기관별 부여 항목

블록 색상에 따라 기관이 부여됨.

### 🟢 심지 (주관, 17억)

**Domain 물리 모델 (Simscape)**
- Multibody / Fluids / Driveline

**DT platform – 실시간 가시화 (Unity)**
- 가시화 플랫폼 구축·운용

**연계**
- FMU 등 co-simulation I/F → Isaac Sim
- ML Surrogate → Isaac Lab

**Isaac Sim 운용**
- 센서 / 렌더링

**모델 검증**
- 시험 데이터 / 성능 곡선

**통신 연동**
- 통신 인프라
- 데이터 동기화

### 🔵 한국건설기계연구원 (한건연, 공동, 16억)

**NVIDIA Omniverse (AI DT platform) 운용**
- Isaac Replicator — Domain Randomization, 합성 데이터 라벨링
- Isaac Lab — RL / IL 학습 (headless)

**모델 검증 (벤치 시험)**
- MCV / pump / motor

**실차 운용 (군산, DX240)** — *기존 자산·시설 최대한 활용*
- 실차 환경 구축 (센서, 제어기 등)
- 시험 환경 구축 (토사, 지형)
- 학습 데이터 수집 (실차)
- 실차 무인 작업 및 검증

**모델 전이 학습 (Fine tuning)**
- 실차 ↔ 가상 모델 적응

### 🟠 한국생산기술연구원 (공동, 8.5억)

**장비 모델**
- Domain 물리 모델 → 장비 모델 통합

**Domain 물리 모델 — 토사 모델 (정밀 트랙 / AI 학습 트랙)** *— 확정*
- 토사 반력
- 표면 변형
- 채취량, 적재량

### 🩷 HD한국조선해양 (공동·수요, 3.5억)

**Domain 물리 모델 (Simscape)**
- Electrical — 전기식 시스템

### ⬜ HD현대사이트솔루션 (수요, –)

**Domain 물리 모델 (Simscape)**
- 제어기

**가이드라인 및 데이터 제공**
