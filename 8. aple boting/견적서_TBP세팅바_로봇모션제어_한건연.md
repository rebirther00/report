| 수행기관 | 한건연 (에이플 + 한건연 공동 수행, 2안) |
| 개발기간 | 6개월 |
| 작성일 | 2026.03.18 |

---

## 1. 업무 범위 (한건연 Scope)

### 로봇 1 - 세팅바 핸들링 로봇
- 세팅바 인식 비전 시스템 개발 (위치, 자세 추정)
- 벽면 홀 인식 비전 시스템 개발
- 비전-로봇 좌표계 캘리브레이션
- 세팅바 그리핑 → 홀 얼라인 → 홀딩 모션 제어
- 비전 제어기 → 로봇 제어기 TCP 통신 인터페이스 개발

### 로봇 2 - 핀 삽입 로봇 (1단계: 볼팅 대신 핀 삽입)
- 핀 인식 비전 시스템 개발
- 얼라인된 홀 인식 비전 시스템 개발
- 비전-로봇 좌표계 캘리브레이션
- 핀 그리핑 → 홀 인식 → 핀 삽입 모션 제어
- 비전 제어기 → 로봇 제어기 TCP 통신 인터페이스 개발

### 공통
- 그리퍼/피더 상용품 선정 가이드 (상용품 없을 시 설계, 제작은 에이플)
- 현장 시운전 및 기술 지원
