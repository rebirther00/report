# 견적서 (가견적)

## LNG 화물창 자율 작업 로봇 - TBP 세팅바 설치 로봇 비전/모션 제어 개발

| 항목 | 내용 |
|------|------|
| 발주처 | 삼성중공업 → 에이플 |
| 수행기관 | 에이플 + 한건연 공동 수행 |
| 개발 예상 기간 | 6개월 |
| 작성일 | 2026.03.18 |

---

## 1. 업무 범위 (한건연 범위)

### 세팅바 핸들링 로봇
- 벽면 홀 인식 비전 시스템
- 비전–로봇 좌표계 캘리브레이션
- 세팅바 그리핑 → 홀 정렬 → 홀딩 모션 제어
- 비전 제어기 → 로봇 제어기 TCP 통신 I/F

### 핀 삽입 로봇 (볼팅 대신 핀 삽입)
- 얼라인된 홀 인식 비전 시스템
- 비전-로봇 좌표계 캘리브레이션
- 핀 그리핑 → 홀 인식 → 핀 삽입 모션 제어
- 비전 제어기 → 로봇 제어기 TCP 통신 I/F

---

## 2. 공통 (협업)

- 그리퍼/피더 상용품 선정 가이드 제공
- 상용품 없을 시 설계 지원(한건연), 제작(에이플)

---

## 3. 에이플 범위 (협의 필요)

- 매니퓰레이터(로봇 제어기 포함), 스테이션 구매 및 확보
- 세팅바/볼트 적재, 공급 장치 설계/제작 또는 상용품
- 그리퍼/피더 제작 또는 상용품
- 시험 TB 구축
