# 특허 출원 설명 자료

## 굴절식 건설장비의 카메라 영상 기반 AI 조향각 추정 방법 및 시스템

작성일: 2026.03.18

---

## 1. 기술 분야

본 발명은 굴절식(articulated) 건설장비의 자율주행 시스템에 관한 것으로, 보다 상세하게는 카메라 영상과 인공지능 모델을 이용하여 굴절 관절부의 조향각을 비접촉·비분해 방식으로 실시간 측정하는 방법 및 시스템에 관한 것이다.

---

## 2. 배경 기술 및 종래 기술의 문제점

### 2.1 기술 배경

굴절식 덤프트럭(ADT, Articulated Dump Truck), 진동 롤러(Vibratory Roller) 등 건설장비의 자율주행을 구현하기 위해서는 전방 차체와 후방 차체를 연결하는 굴절 관절(articulated joint)의 조향각을 실시간으로 정확하게 측정하는 것이 필수적이다.

### 2.2 종래 기술의 한계

현재 조향각 측정을 위한 기존 방법들은 다음과 같은 한계를 가진다.

| 종래 방식 | 문제점 |
|-----------|--------|
| 엔코더(로터리/앱솔루트) 직접 설치 | 관절부 분해, 축 가공, 브라켓 제작 등 대규모 개조 필요 |
| 유압 실린더 변위 센서 | 유압 라인 개조, 장비별 캘리브레이션 필요 |
| IMU 기반 추정 | 진동·충격이 심한 건설 현장에서 누적 오차 발생 |
| GPS/GNSS 듀얼 안테나 | 정밀도 한계(±2~5°), 터널·건물 그림자 영역에서 불가 |

특히, **장비 대수가 많은 건설 현장**에서 모든 장비에 엔코더를 설치하는 것은 비용과 공기(工期) 측면에서 비현실적이며, 기존 운영 중인 장비를 분해·개조하는 것은 안전 및 보증(warranty) 문제를 야기한다.

---

## 3. 발명의 목적

본 발명은 다음을 목적으로 한다.

1. 굴절식 건설장비의 관절부에 **카메라만 설치**하여 조향각을 측정하는 방법 제공
2. **기준 장비(reference machine) 1대**에서 엔코더+카메라로 학습 데이터를 수집하고, AI 모델을 학습시킨 후, **동일 모델의 다른 장비에는 카메라만 설치**하여 조향각을 추정하는 확장 가능한(scalable) 시스템 제공
3. 장비의 분해·가공 없이 **비접촉·비분해 방식**으로 조향각을 획득하여 자율주행 시스템에 활용

---

## 4. 발명의 핵심 구성

### 4.1 시스템 개요

본 발명의 시스템은 크게 **학습 단계(Training Phase)**와 **추론 단계(Inference Phase)**로 구분된다.

```
[학습 단계 - 기준 장비 1대]

  ┌─────────────┐     ┌──────────────┐
  │  카메라      │     │  엔코더       │
  │ (관절부 촬영) │     │ (조향각 측정)  │
  └──────┬──────┘     └──────┬───────┘
         │                    │
         ▼                    ▼
  ┌──────────────────────────────────┐
  │   데이터 수집 (이미지 + 조향각)     │
  │   시간 동기화된 페어 데이터셋 구축   │
  └──────────────┬───────────────────┘
                 │
                 ▼
  ┌──────────────────────────────────┐
  │   AI 모델 학습                    │
  │   입력: 관절부 이미지              │
  │   출력: 조향각(°)                 │
  └──────────────────────────────────┘
```

```
[추론 단계 - 동일 모델 다른 장비 N대]

  ┌─────────────┐
  │  카메라      │  ← 카메라만 설치 (엔코더 불필요)
  │ (관절부 촬영) │
  └──────┬──────┘
         │
         ▼
  ┌──────────────────────────────────┐
  │   학습된 AI 모델 (추론)            │
  │   입력: 관절부 이미지              │
  │   출력: 조향각(°)                 │
  └──────────────┬───────────────────┘
                 │
                 ▼
  ┌──────────────────────────────────┐
  │   자율주행 제어기                  │
  │   (조향 피드백 제어에 활용)         │
  └──────────────────────────────────┘
```

### 4.2 카메라 설치 및 촬영 대상

- **설치 위치**: 굴절 관절부 근방의 차체 프레임에 고정 장착
- **촬영 대상**: 관절부의 프레임 경계선, 볼트 패턴, 유압 실린더 위치 변화 등 관절부 전체 영상
- **카메라 종류**: 다음 중 하나 이상 사용 가능
  - 단안(monocular) 카메라: 경제적, 경량
  - 스테레오 카메라: 깊이 정보 활용 가능
  - 깊이(depth) 카메라: 3D 구조 변화 감지 가능

### 4.3 학습 데이터 수집 (학습 단계)

1. **기준 장비 1대**에 엔코더(로터리 엔코더 또는 앱솔루트 엔코더)와 카메라를 동시 설치
2. 장비를 다양한 조향각(좌·우 최대 조향각 범위)으로 운전하며 데이터 수집
3. 각 프레임에 대해 **카메라 이미지**와 **엔코더 조향각 측정값**을 시간 동기화하여 페어(pair) 데이터셋 구축
4. 다양한 조건에서 데이터 수집:
   - 조향 속도: 저속/중속/고속 조향
   - 환경 조건: 주간/야간, 맑음/흐림/우천, 분진 유무
   - 하중 조건: 공차/적재

### 4.4 AI 모델 구성

- **입력**: 관절부 영상 (단일 프레임 또는 연속 프레임)
- **출력**: 조향각 (연속값, 단위: °)
- **모델 구조**: 회귀(regression) 기반 심층 신경망
  - CNN(Convolutional Neural Network) 기반 특징 추출
  - 시계열 안정화를 위한 시간적 모델링 (LSTM, Temporal CNN 등) 선택 적용
- **학습 방법**: 지도 학습 (supervised learning)
  - 손실 함수: MSE(Mean Squared Error) 또는 Smooth L1 Loss
  - 목표 정확도: ±1° 이내

### 4.5 추론 및 배포 (추론 단계)

1. 학습 완료된 모델을 **엣지 디바이스**(임베디드 GPU, NPU 등)에 탑재
2. 동일 모델의 다른 장비에는 **카메라만 설치** (엔코더 불필요)
3. 실시간 영상 입력 → 조향각 추론 → 자율주행 제어기에 전달
4. 선택적으로 소량의 캘리브레이션 데이터로 미세 조정(fine-tuning) 가능

### 5.2 본 발명의 핵심 차별점

1. **적용 대상의 신규성**: 굴절식 건설장비(ADT, 진동 롤러 등)의 굴절 관절 조향각을 카메라+AI로 측정하는 최초의 접근
2. **관절부 직접 관찰**: 도로나 트레일러 외형이 아닌, **굴절 관절부의 기하학적 형상 변화**를 직접 촬영하여 조향각 추정
3. **기준 장비 학습 → 동일 모델 전이 배포**: 1대에서 학습하여 N대에 적용하는 확장 가능한(scalable) 배포 전략
4. **비분해·비접촉**: 장비 분해, 축 가공, 유압 라인 개조 없이 카메라 장착만으로 적용
5. **자율주행 통합**: 건설장비 자율주행 시스템의 조향 피드백 센서로서의 활용

## 6. 보완 실시예 (추가 청구항 검토용)

### 6.1 시각적 마커 부착 방식

관절부에 AR 마커, 컬러 마커, 또는 반사 패턴 등 인공 시각적 기준점을 부착하여 인식 정확도를 향상시키는 실시예. 분진, 오염, 저조도 환경에서 자연 특징점 대비 강건성 확보.

### 6.2 시계열 기반 추론 안정화

단일 프레임이 아닌 연속 프레임(영상 시퀀스)을 입력으로 사용하여 시간적 평활화(temporal smoothing)를 수행. LSTM, Transformer 등의 시계열 모델로 노이즈 및 순간 가림(occlusion)에 대한 강건성 확보.

### 6.3 신뢰도 기반 안전 전환

AI 모델 출력에 **신뢰도 점수(confidence score)**를 함께 산출하고, 신뢰도가 임계값 미만일 때 운전자에게 경고하거나 안전 모드(감속/정지)로 전환하는 안전 메커니즘.

### 6.4 개체별 미세 조정(Fine-tuning)

동일 모델이라도 개체별 마모, 도장 상태 등 차이가 있을 수 있으므로, 배포 시 소량의 캘리브레이션 데이터(수십~수백 프레임)로 기학습 모델을 미세 조정하는 방법. 전이 학습(transfer learning) 기법 활용.

### 6.5 다중 카메라 융합

2대 이상의 카메라를 서로 다른 각도에서 관절부를 촬영하도록 배치하고, 각 카메라의 추론 결과를 융합(fusion)하여 정확도 및 가용성(availability) 향상. 1대 카메라 고장 시에도 동작 가능한 이중화(redundancy) 구성.

### 6.6 환경 적응형 데이터 증강

학습 데이터에 건설 현장 특유의 환경 변동(분진, 진흙 비산, 우천, 야간 조명, 직사광 등)을 시뮬레이션하는 데이터 증강(data augmentation)을 적용하여 모델의 환경 강건성 확보.

## 7. 청구항 구성안 (변리사 협의용)

### 독립 청구항 1 - 방법 청구항

> 굴절식 건설장비의 굴절 관절 조향각을 추정하는 방법에 있어서,
>
> (a) 기준 장비의 굴절 관절부에 카메라와 조향각 측정 센서를 설치하는 단계;
>
> (b) 상기 기준 장비를 다양한 조향각으로 운전하면서, 상기 카메라로 촬영한 관절부 영상과 상기 조향각 측정 센서의 측정값을 시간 동기화하여 학습 데이터셋을 구축하는 단계;
>
> (c) 상기 학습 데이터셋을 이용하여, 관절부 영상을 입력으로 받아 조향각을 출력하는 인공지능 모델을 학습시키는 단계;
>
> (d) 상기 기준 장비와 동일 모델의 대상 장비의 굴절 관절부에 카메라를 설치하고, 상기 학습된 인공지능 모델을 이용하여 상기 카메라 영상으로부터 조향각을 추정하는 단계;
>
> 를 포함하는 것을 특징으로 하는, 굴절식 건설장비의 카메라 영상 기반 조향각 추정 방법.

### 독립 청구항 2 - 시스템 청구항

> 굴절식 건설장비의 굴절 관절 조향각 추정 시스템에 있어서,
>
> 상기 건설장비의 굴절 관절부를 촬영하도록 설치된 카메라;
>
> 상기 카메라로부터 영상을 수신하고, 기준 장비에서 조향각 측정 센서와 카메라 영상의 페어 데이터로 학습된 인공지능 모델을 실행하여 조향각을 추정하는 연산 장치;
>
> 를 포함하며, 상기 대상 장비에는 조향각 측정 센서의 설치 없이 카메라 영상만으로 조향각을 추정하는 것을 특징으로 하는, 조향각 추정 시스템.

### 종속 청구항 (예시)

- 상기 카메라는 단안 카메라, 스테레오 카메라, 또는 깊이 카메라 중 하나 이상인 것을 특징으로 하는...
- 상기 관절부 영상은 프레임 경계선, 볼트 패턴, 유압 실린더의 위치 변화를 포함하는 것을 특징으로 하는...
- 상기 인공지능 모델은 CNN 기반 특징 추출부와 회귀 출력부를 포함하는 것을 특징으로 하는...
- 상기 인공지능 모델의 출력에 신뢰도 점수를 함께 산출하고, 신뢰도가 임계값 미만일 때 안전 모드로 전환하는 단계를 더 포함하는...
- 상기 관절부에 시각적 마커를 부착하여 인식 정확도를 향상시키는 단계를 더 포함하는...
- 상기 (d) 단계에서 대상 장비의 소량 캘리브레이션 데이터로 상기 학습된 모델을 미세 조정하는 단계를 더 포함하는...
- 상기 학습 데이터셋 구축 시 건설 현장 환경 변동을 반영한 데이터 증강을 수행하는 단계를 더 포함하는...
- 상기 추정된 조향각을 자율주행 제어기의 조향 피드백 신호로 사용하는 것을 특징으로 하는...

## 8. 발명의 효과

1. **설치 용이성**: 카메라 장착만으로 조향각 측정 가능, 장비 분해·가공 불필요
2. **비용 절감**: 기준 장비 1대만 엔코더 설치, 나머지 N대는 카메라만 설치하여 대규모 현장 적용 시 비용 대폭 절감
3. **확장성**: 동일 모델에 대해 한 번 학습한 모델을 다수 장비에 반복 적용 가능
4. **보증 유지**: 장비 원형을 훼손하지 않으므로 제조사 보증(warranty) 유지 가능
5. **유지보수 간편**: 엔코더 대비 기계적 마모 없음, 카메라 교체만으로 유지보수 완료
6. **자율주행 통합**: 건설장비 자율주행 시스템의 핵심 센서로 즉시 활용 가능

## 10. 특허 출원 가능성 평가

### 신규성(Novelty): ✅ 높음
- 굴절식 건설장비 관절부를 카메라로 직접 촬영하여 AI로 조향각을 추정하는 선행 기술 미발견
- 기존 선행 기술은 트럭-트레일러(도로 차량), 전통 CV, 또는 기계식 센서 방식

### 진보성(Inventive Step): ✅ 양호
- 단순히 카메라+AI 조합이 아닌, "기준 장비 학습 → 동일 모델 전이 배포"라는 구체적 방법론
- 건설장비 특유의 환경적 제약(분진, 진동, 가혹 조건)을 고려한 실용적 해결책
- 장비 비분해·비접촉이라는 실무적 효과

### 산업상 이용 가능성: ✅ 높음
- 건설장비 자율주행 시장의 빠른 성장
- ADT, 진동 롤러 등 다수 장비에 즉시 적용 가능
