# 특허 출원 설명 자료 (통합본)

## 굴절식 건설장비의 카메라 영상 기반 AI 조향각 비접촉 추정 방법 및 시스템

*Non-contact Measurement System for Articulated Steering Angle of Construction Machinery Using Camera Vision and AI*

**작성일:** 2026.03.18  
**작성:** 한국건설기계연구원 지능제어연구실

---

## 1. 기술 분야

본 발명은 굴절식(articulated) 건설장비의 자율주행 시스템에 관한 것으로, 보다 상세하게는 카메라 영상과 인공지능 모델을 이용하여 굴절 관절부의 조향각을 비접촉·비분해 방식으로 실시간 측정하는 방법 및 시스템에 관한 것이다.

---

## 2. 배경 기술 및 종래 기술의 문제점

### 2.1 기술 배경

ADT(Articulated Dump Truck), 진동 롤러(Vibratory Roller) 등 굴절 조향(Articulated Steering) 방식의 건설기계는 전방부와 후방부가 굴절 조인트(Articulated Joint)로 연결되어 있으며, 이 조인트의 각도 변화를 통해 조향을 수행한다. 자율주행 또는 반자율주행 시스템을 구축하기 위해서는 이 굴절 조향각(Articulation Angle)의 실시간 정밀 측정이 필수적이다.

조향각은 경로 추종, 자세 제어, 안전 제어, 작업 계획 등에 핵심 입력값으로 사용되며, ±1° 이내의 정밀도가 요구된다.

### 2.2 종래 기술의 한계

| 종래 방식 | 문제점 |
|-----------|--------|
| 엔코더(로터리/앱솔루트) 직접 설치 | 관절부 분해, 축 가공, 브라켓 제작 등 대규모 개조 필요. 장비 모델별 별도 설계 필요. |
| 유압 실린더 변위 센서 | 비선형 기구학적 변환 필요. 유압 라인 개조 수반. 센서 고장 시 유압 손상 위험. |
| IMU 기반 추정 | 진동·충격이 심한 건설 현장에서 누적 오차 발생 |
| GPS/GNSS 듀얼 안테나 | 정밀도 한계(±2~5°). 터널·건물 그림자 영역 불가. 고가 장비(RTK-GNSS 4대). 초기 수렴 시간 문제. |

특히, **장비 대수가 많은 건설 현장**에서 모든 장비에 엔코더를 설치하는 것은 비용과 공기(工期) 측면에서 비현실적이며, 기존 운영 중인 장비를 분해·개조하는 것은 안전 및 보증(warranty) 문제를 야기한다. 또한 건설기계는 진동, 충격, 흙먼지, 진흙, 수분, 역광, 가림 현상 등이 심하여 센서 설치와 유지관리 비용이 크고, 조인트 근처 접근 자체가 쉽지 않은 경우가 많다.

---

## 3. 발명의 목적

본 발명이 해결하려는 과제는 다음과 같다.

1. 굴절 관절부에 엔코더 또는 별도 각도 센서를 상시 설치하지 않고도 **카메라만으로** 실시간 조향각을 획득할 것
2. 장비 분해, 구조물 가공, 별도 브라켓 제작 없이 기존 장비에 **retrofit 가능**하도록 할 것
3. **샘플 장비 1대**에서만 기준각을 수집하고, 동일 모델의 다른 장비에는 카메라만 설치하여 조향각을 얻을 수 있는 **확장 가능한(scalable) 시스템**을 제공할 것
4. 건설 현장의 진동, 오염, 가림, 조명 변화 등 **열악한 환경에서도 사용 가능**한 구조를 마련할 것
5. ADT, 진동 롤러 등 다양한 굴절식 건설장비에 **공통 적용 가능**한 기술 구조를 제시할 것

## 4. 발명의 상세 구성

### 4.1 시스템 개요

본 발명의 시스템은 크게 **학습 단계(Training Phase)**와 **추론 단계(Inference/Deployment Phase)**로 구분된다.

```
[학습 단계 - 샘플(기준) 장비 1대]

  ┌─────────────┐     ┌──────────────────────┐
  │  카메라      │     │  기준 측정 장치        │
  │ (관절부 촬영) │     │ (엔코더/IMU/GNSS 등)  │
  └──────┬──────┘     └──────────┬───────────┘
         │                       │
         ▼                       ▼
  ┌──────────────────────────────────────────┐
  │   데이터 수집 (이미지 + 조향각)              │
  │   시간 동기화된 페어 데이터셋 구축            │
  │   (다양한 조향각, 속도, 하중, 환경 조건)      │
  └──────────────────┬───────────────────────┘
                     │
                     ▼
  ┌──────────────────────────────────────────┐
  │   AI 모델 학습 (CNN + 회귀)                │
  │   입력: 관절부 이미지                       │
  │   출력: 조향각(°) + 신뢰도(confidence)      │
  └──────────────────────────────────────────┘
```

```
[추론 단계 - 동일 모델 대상 장비 N대]

  ┌─────────────┐
  │  카메라      │  ← 카메라만 설치 (엔코더 불필요)
  │ (관절부 촬영) │
  └──────┬──────┘
         │
         ▼
  ┌──────────────────────────────────────────┐
  │   엣지 디바이스 (Jetson, RK3588 등)        │
  │   학습된 AI 모델 실시간 추론                │
  │   입력: 관절부 이미지                       │
  │   출력: 조향각(°) + 신뢰도                  │
  └──────────────────┬───────────────────────┘
                     │
                     ▼
  ┌──────────────────────────────────────────┐
  │   자율주행 제어기                           │
  │   (조향 피드백 제어에 활용)                  │
  │   신뢰도 저하 시 안전 모드 전환              │
  └──────────────────────────────────────────┘
```

### 4.2 카메라 설치 및 촬영 대상

- **설치 위치**: 굴절 조인트 부위의 외관 변형을 촬영 가능한 위치에 차체 프레임에 고정 장착
- **촬영 대상**: 관절부의 프레임 경계선, 볼트 패턴, 유압 실린더 연결부 등 조향각 변화에 따라 상대 위치가 달라지는 시각적 특징을 포함하는 관절부 전체 영상
- **카메라 종류**: 다음 중 하나 이상 사용 가능
  - 단안(monocular) RGB 카메라: 경제적, 경량
  - 스테레오 카메라: 깊이 정보 활용 가능
  - RGBD(깊이) 카메라: 3D 구조 변화 감지 가능

### 4.3 학습 데이터 수집 (학습 단계)

1. **샘플 장비 1대**에 기준 측정 장치(로터리 엔코더, 앱솔루트 엔코더, IMU, 외부 계측기 등)와 카메라를 동시 설치
2. 장비를 다양한 조건에서 운전하며 데이터 수집:
   - 조향 범위: 좌·우 최대 조향각 전 범위
   - 조향 속도: 저속/중속/고속 조향
   - 환경 조건: 주간/야간, 맑음/흐림/우천, 분진 유무
   - 하중 조건: 공차/적재
   - 노면 조건: 포장/비포장
3. 각 프레임에 대해 **카메라 이미지**와 **기준 조향각 측정값**을 시간 동기화하여 페어(pair) 데이터셋 구축
4. 필요에 따라 차량 속도, 조향 명령, 유압 관련 정보, IMU 정보 등을 추가 취득하여 보조 입력으로 사용 가능

### 4.4 AI 모델 구성

- **입력**: 관절부 영상 (단일 프레임 또는 연속 프레임)
- **출력**: 조향각 (연속값, 회귀 문제, 단위: °) + 신뢰도(confidence) 또는 유효성(validity flag)
- **모델 구조**:
  - CNN 백본(ResNet, EfficientNet 등) 기반 특징 추출
  - 회귀 헤드(Regression Head)로 조향각 출력
  - 시계열 의존성 반영 시 LSTM, Temporal Convolution, Transformer 등 선택 적용
- **학습 방법**: 지도 학습 (supervised learning)
  - 손실 함수: MSE(Mean Squared Error) 또는 Smooth L1 Loss
  - 필요 시 기구학 제약, 최대 조향속도 제한, 시계열 연속성 조건을 반영하여 비현실적인 추정값 억제
  - 목표 정확도: ±1° 이내
- **추론 환경**: INT8 양자화 후 NPU/GPU 기반 엣지 디바이스에서 실시간 추론 (목표: 30fps 이상)

### 4.5 기종 간 전이 적용 방법 (핵심 차별점)

본 발명의 핵심 차별점은 샘플 장비에서 학습된 모델을 다른 장비에 전이(Transfer)하는 방법론에 있다.

| 전이 단계 | 적용 대상 | 방법 | 추가 데이터 |
|-----------|-----------|------|------------|
| **직접 전이** | 동일 기종 (예: 같은 모델 ADT) | 카메라 설치 위치와 조인트 외관이 동일하므로 학습된 모델을 그대로 적용 | 불필요 |
| **파인튜닝 전이** | 유사 기종 (예: 다른 톤수의 ADT) | 소량의 보정 데이터(수백 프레임)로 모델 마지막 레이어를 파인튜닝 | 소량 (수백 프레임) |
| **도메인 적응** | 이종 장비 (예: ADT → 진동 롤러) | 비지도 도메인 적응(Unsupervised Domain Adaptation) 기법 활용 | 비지도 데이터 |

### 4.6 추론 및 배포 (추론 단계)

1. 학습 완료된 모델을 **엣지 디바이스**(NVIDIA Jetson, Rockchip RK3588 등)에 탑재
2. 대상 장비에는 **카메라만 설치** (기준 측정 장치 불필요)
3. 초기 설치 시 카메라 장착 위치, 화각, 조인트 기준 위치 등을 자동 또는 반자동으로 보정
4. 실시간 영상 입력 → 조향각 + 신뢰도 추론 → 자율주행 제어기에 전달

### 4.7 운용 및 안전

- 영상 가림, 오염, 야간, 역광, 진동 블러 등의 상황에서 **신뢰도가 낮아지면 추정값 사용을 제한**
- 신뢰도가 기준 이하일 경우:
  - 감속 또는 정지
  - 운전자 경고
  - 수동 전환
  - 이전 추정값 유지
  - 보조 알고리즘(IMU 등) 전환
- 필요 시 복수 카메라를 사용하여 한 카메라의 시야가 제한될 때 다른 카메라로 전환하는 이중화 구성

### 5.2 선행기술 분석 종합

기존 선행기술들은 (1) 자동차 트레일러에 특화되어 건설기계 환경을 고려하지 않았거나, (2) GNSS 등 고가 센서를 사용하거나, (3) 마커/교정판 부착이 필요하거나, (4) 전통 CV(비 AI) 방식이거나, (5) 한 장비에서 학습한 모델을 다른 동종 장비에 전이하는 개념이 부재하다.

따라서 본 발명은 선행기술 대비 차별적 요소를 충분히 보유하고 있다고 판단된다.

| 항목 | 기존 기술 | 본 발명 |

| 카메라 위치 | 후방 카메라(트레일러 전면) 또는 파노라마 | **굴절 조인트 부위를 직접 촬영하는 근접 카메라** |

| 학습 데이터 수집 | 각 차량별 개별 학습 필요 | **샘플 1대에만 센서 설치. 나머지는 카메라만** |
| 기종 간 전이 | 미제시 또는 미고려 | **직접 전이 / 파인튜닝 전이 / 도메인 적응 3단계** |
| 운용 환경 | 도로 주행 환경 | **건설 현장 (분진, 진동, 야외 조도 변화 등) 대응** |
| 설치 편의성 | 장비 분해/가공 또는 다중 GNSS 필요 | **카메라 1대 + 엣지 컴퓨터만 설치. 비분해, 비가공** |
| 안전 메커니즘 | 미제시 | **신뢰도 기반 안전 모드 전환 포함** |

### 본 발명의 5대 핵심 차별점

1. **적용 대상의 신규성**: 굴절식 건설장비(ADT, 진동 롤러 등)의 굴절 관절 조향각을 카메라+AI로 측정하는 최초의 접근
2. **관절부 직접 관찰**: 도로, 트레일러 외형이 아닌, 굴절 관절부의 기하학적 형상 변화를 직접 촬영하여 조향각 추정
3. **샘플 장비 학습 → 전이 배포**: 1대에서 학습하여 N대에 적용하는 확장 가능한 배포 전략 (3단계 전이 방법론)
4. **비분해·비접촉·비침습**: 장비 분해, 축 가공, 유압 라인 개조 없이 카메라 장착만으로 적용
5. **건설 현장 특화**: 분진, 진동, 가혹 환경 대응 + 신뢰도 기반 안전 로직

## 7. 특허성 종합 평가

### 7.1 신규성(Novelty): ✅ 높음

건설기계의 굴절 조인트 부위를 근접 촬영하는 카메라 + AI 회귀 모델의 조합, 그리고 샘플 장비 학습 후 타 장비 전이 적용이라는 구체적 구성은 선행기술에서 확인되지 않는다. 자동차 트레일러 분야의 비전 기반 조향각 추정 기술이 존재하나, 건설기계 환경 특화 및 기종 간 전이학습 개념이 결합된 사례는 발견되지 않았다.

### 7.2 진보성(Inventive Step): ⚠️ 양호 (청구항 작성 시 주의 필요)

단순히 카메라+AI로 각도를 측정한다는 일반적 개념은 진보성 주장이 약할 수 있으나, 다음 요소들이 진보성을 뒷받침한다.

- 건설현장 특유의 열악한 환경에 대응하는 학습 전략
- 샘플 1대 → N대 확장의 경제적 구조
- 건설기계 굴절 조인트의 기구학적 특성을 활용한 마커리스 각도 추정
- 동종/유사/이종 기종에 대한 3단계 전이학습 방법론
- 신뢰도 기반 안전 제어 통합

> 청구항 작성 시 건설기계 특화 요소와 전이학습 방법론을 구체적으로 기재할 필요가 있다.

### 7.3 산업상 이용 가능성: ✅ 높음

건설기계 자율주행 시스템 구축을 위한 핵심 센서 기술. 카메라+엣지 컴퓨터의 저비용 구성으로 대량 장비 적용 및 기존 장비의 자율주행 레트로핏(Retrofit) 시장에 직접 적용 가능.

## 8. 청구항 구성안 (변리사 협의용)

### 8.1 독립 청구항 1 - 시스템 청구항

> 건설기계의 굴절 조향각 측정 시스템으로서,
>
> 굴절 조인트 부위를 촬영하도록 건설기계 본체에 설치된 카메라;
>
> 상기 카메라로부터 영상을 수신하여 조향각을 추정하는 딥러닝 모델이 탑재된 연산 장치;
>
> 를 포함하고,
>
> 상기 딥러닝 모델은 별도의 샘플 건설기계에서 카메라 영상과 기준 측정 장치의 조향각 측정값을 쌍으로 수집한 학습 데이터로 사전 학습된 것인,
>
> 건설기계 굴절 조향각 측정 시스템.

### 8.2 독립 청구항 2 - 학습 방법 청구항

> 건설기계의 굴절 조향각을 비접촉으로 측정하는 방법으로서,
>
> (a) 샘플 건설기계의 굴절 조인트 부위에 카메라와 기준 측정 장치를 설치하는 단계;
>
> (b) 상기 샘플 건설기계를 다양한 조향 조건에서 운용하며, 상기 카메라로 촬영한 관절부 영상과 상기 기준 측정 장치의 조향각 측정값을 시간 동기화하여 학습 데이터셋을 구축하는 단계;
>
> (c) 상기 학습 데이터셋을 이용하여, 관절부 영상을 입력으로 받아 조향각을 출력하는 딥러닝 회귀 모델을 학습시키는 단계;
>
> (d) 대상 건설기계의 굴절 관절부에 카메라만 설치하고, 상기 학습된 모델을 적용하여 카메라 영상으로부터 조향각을 실시간 추정하는 단계;
>
> 를 포함하는, 건설기계 굴절 조향각 비접촉 측정 방법.

### 8.3 독립 청구항 3 - 운용 방법 청구항

> 기준 측정 장치가 설치되지 않은 굴절식 건설기계에서 조향각을 추정하는 운용 방법으로서,
>
> 굴절 조인트 부위의 영상을 카메라로 취득하는 단계;
>
> 상기 영상을 사전 학습된 인공지능 모델에 입력하여 조향각 추정값 및 신뢰도 정보를 생성하는 단계;
>
> 상기 신뢰도가 소정 임계값 이상인 경우 상기 조향각 추정값을 자율주행 제어 입력으로 사용하고, 상기 신뢰도가 소정 임계값 미만인 경우 안전 모드로 전환하는 단계;
>
> 를 포함하는, 굴절식 건설기계의 조향각 추정 운용 방법.

### 8.4 종속 청구항

1. 상기 카메라는 단안 RGB 카메라, 스테레오 카메라, 또는 RGBD 깊이 카메라 중 하나 이상인 것을 특징으로 하는...
2. 상기 관절부 영상은 조인트 핀, 프레임 경계선, 볼트 패턴, 유압 실린더 연결부 중 적어도 하나의 시각적 특징을 포함하는 것을 특징으로 하는...
3. 상기 딥러닝 모델은 CNN 기반 특징 추출부와 회귀 출력부를 포함하는 것을 특징으로 하는...
4. 단일 프레임이 아닌 복수 프레임의 시계열 정보를 입력으로 사용하는 LSTM 또는 Temporal Convolution 구조를 더 포함하는 것을 특징으로 하는...
5. 최대 조향속도, 기구학 제약, 시계열 연속성 조건을 반영하여 비현실적인 추정값을 억제하는 것을 특징으로 하는...
6. 상기 모델의 출력으로 조향각과 함께 신뢰도(confidence) 또는 유효성(validity flag)을 출력하는 것을 특징으로 하는...
7. 가림, 오염, 조도 변화, 블러 상태를 판정하여 추정값 사용을 제한하는 것을 특징으로 하는...
8. 복수 카메라를 사용하여 시야 확보성을 높이고, 한 카메라 고장 시 다른 카메라로 전환하는 이중화 구성을 포함하는 것을 특징으로 하는...
9. 상기 (d) 단계에서 대상 장비의 소량 캘리브레이션 데이터로 상기 학습된 모델을 미세 조정(fine-tuning)하는 단계를 더 포함하는 것을 특징으로 하는...
10. 동종 기종 간 직접 전이, 유사 기종 간 파인튜닝 전이, 이종 기종 간 도메인 적응을 포함하는 전이학습 방법을 적용하는 것을 특징으로 하는...
11. 상기 학습 데이터셋 구축 시 건설 현장 환경 변동(분진, 오염, 조도 변화, 우천 등)을 반영한 데이터 증강을 수행하는 단계를 더 포함하는 것을 특징으로 하는...
12. INT8 양자화된 모델을 NPU 기반 엣지 디바이스에서 실시간 추론하는 것을 특징으로 하는...
13. 초기 보정 절차 또는 steering sweep 절차를 통해 기종별 보정을 수행하는 단계를 더 포함하는 것을 특징으로 하는...
14. 상기 대상 건설기계가 ADT(Articulated Dump Truck) 또는 진동 롤러(Vibratory Roller)인 것을 특징으로 하는...
15. 상기 추정된 조향각을 자율주행, 원격제어, 또는 작업제어 시스템의 조향 피드백 신호로 사용하는 것을 특징으로 하는...

## 9. 보완 실시예 (추가 청구항 검토용)

### 9.1 시각적 마커 부착 방식

관절부에 AR 마커, 컬러 마커, 또는 반사 패턴 등 인공 시각적 기준점을 부착하여 인식 정확도를 향상시키는 실시예. 분진, 오염, 저조도 환경에서 자연 특징점 대비 강건성 확보.

### 9.2 카메라 오염 대응

건설현장에서 카메라 렌즈에 흙, 분진, 물방울 등이 부착되면 추정 정확도가 급격히 저하될 수 있다. 자동 세정 장치(에어/워셔) 또는 오염 감지 모듈(오염 시 경고/자동 보정)을 포함.

### 9.3 자기 교정(Self-Calibration)

카메라 설치 위치/각도의 미세 변동(진동 등에 의한)을 자동 보정하는 온라인 캘리브레이션 기능. 예: 직진 주행 시 조향각 0° 기준점을 자동 갱신.

### 9.4 디지털 트윈 기반 합성 데이터

실제 샘플 장비 데이터 외에, 디지털 트윈(3D 시뮬레이션) 환경에서 생성한 합성 데이터를 활용하여 학습 데이터를 증강. 데이터 수집 비용 절감 효과.

### 9.5 센서 융합 확장

카메라 단독이 아닌, IMU(관성 측정 장치)와의 융합으로 카메라 신뢰도 저하 시 보완하는 확장 구성.

### 9.6 환경 적응형 데이터 증강

학습 데이터에 건설 현장 특유의 환경 변동(분진, 진흙 비산, 우천, 야간 조명, 직사광, 오일 오염 등)을 시뮬레이션하는 데이터 증강(data augmentation) 적용.

## 10. 발명의 효과

1. **비침습식 계측**: 관절부에 상시 센서를 부착하지 않고 조향각 획득. 장비 분해·가공 불필요.
2. **retrofit 용이성**: 기존 운용 장비에 카메라만 추가 설치하여 적용 가능.
3. **비용 절감**: 샘플 1대만 기준 센서 설치. 나머지 N대는 카메라만으로 대규모 현장 적용 비용 대폭 절감.
4. **확장성**: 동일 모델에 대해 한 번 학습한 모델을 다수 장비에 반복 적용 가능. 3단계 전이로 다기종 확장.
5. **보증 유지**: 장비 원형을 훼손하지 않으므로 제조사 보증(warranty) 유지 가능.
6. **유지보수 간편**: 엔코더 대비 기계적 마모 없음, 카메라 교체만으로 유지보수 완료.
7. **현장 운용성**: 신뢰도 기반 출력과 안전 로직으로 가혹한 건설 현장에서도 실용적 운용 가능.
8. **자율주행 통합**: 경로 추종, 자세 제어, 안전 제어의 핵심 센서로 즉시 활용 가능.

## 12. 변리사 전달 핵심 포인트

본 기술의 핵심은 단순히 "카메라로 조향각을 본다"는 수준이 아니라, 다음 요소들의 조합에 있다.

1. **건설기계 articulated joint**를 대상으로 하는 점
2. 조인트에 상시 엔코더를 달지 않는 **비침습식 구조**라는 점
3. 샘플 장비에서만 기준 센서를 사용하고, 실제 적용 장비는 **카메라만 사용**한다는 점
4. 카메라 영상으로부터 조향각을 추정하는 **AI 기반 가상센서(virtual sensor)**라는 점
5. 현장 적용을 위해 **신뢰도 판단 및 안전 로직**까지 포함하는 점
6. 여러 기종에 확장 가능하도록 **3단계 전이 구조**를 포함하는 점

따라서 청구항은 단순한 영상 측정 일반론보다, **"건설기계 retrofit형 카메라 기반 articulation angle virtual sensor 시스템"**이라는 방향으로 구성되기를 희망한다.

또한 권리범위를 넓히기 위해 "엔코더"에 한정하지 말고, **기준 측정 장치(Reference Measurement Device)**로 넓게 표현하여 로터리 엔코더, IMU, GNSS, 외부 계측기 등을 포괄하는 것이 바람직하다.
