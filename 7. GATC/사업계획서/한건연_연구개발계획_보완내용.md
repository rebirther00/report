# 한국건설기계연구원(한건연) 연구개발계획서 보완 내용

> **과제명**: 스마트 컨스트럭션 구현을 위한 콘크리트펌프카 자율타설 시스템 개발  
> **한건연 역할**: CPC 및 DMCR, 펌핑 동작 등의 원격 제어 시스템 개발  
> **연구 기간**: 2026년 4월 ~ 2028년 12월 (33개월)  
> **작성 기준**: 연구개발계획서 v0.1 보완용

## 1. 자율 운용 과제에서 원격 제어의 필요성

콘크리트펌프카(CPC) 자율타설 시스템은 궁극적으로 무인·자율 운용을 지향하나, 다음과 같은 이유로 **원격 제어 시스템이 필수적**이다.

### 1.1 안전 감시 및 비상 개입

- 자율 운용 중 예상치 못한 상황(장애물 출현, 붐 간섭, 콘크리트 막힘 등) 발생 시 **원격 운전자의 즉각적 개입**이 필요
- 비상정지, 붐 회수, 펌핑 중단 등 **안전 크리티컬 조작**을 원격으로 수행
- 건설현장 안전 규정상 **무인 장비의 원격 모니터링 의무** 충족

### 1.2 자율 모드 전환 제어

- 완전 자율 → 원격 수동 → 반자율 등 **운용 모드 간 전환**을 원격에서 제어
- 자율 알고리즘이 처리하기 어려운 **비정형 작업**(특수 형상 구조물 타설, 정밀 마감 등)은 원격 수동 제어로 수행

### 1.3 운용 효율 및 현장 무인화

- **오피스 기반 원격 제어**를 통해 운전자가 현장에 상주하지 않아도 됨
- 1인 운전자가 여러 현장의 장비를 **순차 또는 동시 모니터링** 가능
- 악천후, 야간, 위험 환경에서의 작업 안전성 향상

### 1.4 단계적 자율화 전략

- 1차년도: 원격 제어 중심 → 2차년도: 반자율+원격 감시 → 3차년도: 자율 운용+원격 비상 개입
- **원격 제어 시스템은 자율화 수준에 관계없이 항상 필요한 안전 백업 체계**

## 2. 장비 탑재 HW/SW 구성 (CPC·DMCR 측)

> **참고**: HW 구매는 주관기관(전진로보틱스)에서 수행하며, 한건연은 시스템 설계·SW 개발·통합을 담당

원격 제어를 위해 CPC와 DMCR에 다음과 같은 장비 측 시스템이 필요하다.

### 2.1 엣지 컴퓨팅 유닛 (ECU)

- **역할**: 장비 측 데이터 처리, 영상 인코딩/스트리밍, 통신 게이트웨이
- **사양**: 산업용 임베디드 PC (방진·방수·내진동), GPU 가속 영상 처리
- **SW**: 실시간 영상 스트리밍 서버, 센서 데이터 수집·전송 에이전트, 원격 명령 수신·처리 모듈
- **한건연 역할**: ECU SW 아키텍처 설계, 통신 미들웨어 개발, 영상 스트리밍 파이프라인 구현

### 2.2 IP 카메라 시스템

- **구성**: CPC 붐 선단, 조종석 주변, DMCR 타설부 등 **다시점 카메라 4~6대**
- **사양**: Full HD 이상, 저지연 스트리밍(H.265), 야간/역광 대응(WDR), IP67
- **한건연 역할**: 카메라 배치 설계, 영상 합성·전환 SW 개발, 멀티뷰 스트리밍 최적화

### 2.3 장거리 통신 모듈

- **목표 거리**: 오피스 기반 원격 제어 (수 km ~ 수십 km 이상)
- **통신 방식**: 5G/LTE 기반 상용 이동통신 (주 링크) + Wi-Fi (근거리 백업)
- **구성**: 5G/LTE 라우터, 외장 안테나, VPN 모듈
- **한건연 역할**: 통신 프로토콜 설계, 네트워크 이중화·품질 관리 SW, 통신 지연 보상 알고리즘 개발

### 2.4 센서 데이터 수집 게이트웨이

- **역할**: CPC/DMCR의 기존 제어 시스템(CAN, PLC 등)과 인터페이스하여 장비 상태 데이터 수집
- **수집 항목**: 붐 관절 각도, 유압 압력, 펌핑 압력/유량, 아웃리거 상태, 엔진 상태, DMCR 위치/자세
- **한건연 역할**: 데이터 수집 프로토콜 정의, 게이트웨이 SW 개발, 실시간 데이터 패키징·전송

### 2.5 기타 고려사항

| 항목 | 내용 | 한건연 역할 |
|------|------|-------------|
| 사이버보안 | 원격 제어 채널 암호화, 인증 체계 | 보안 프로토콜 설계·구현 |
| 양방향 음성 통신 | 현장 작업자 ↔ 원격 운전자 음성 교신 | 음성 코덱·통신 모듈 통합 |
| 데이터 로깅 | 운용 이력 기록 (블랙박스 기능) | 로깅 SW 개발, 데이터 포맷 정의 |
| 환경 센서 연동 | 풍속, 온습도, 진동 등 현장 환경 모니터링 | 센서 인터페이스 통합, 경보 로직 |

### 3.1 1차년도 (2026.04 ~ 2026.12, 9개월)

#### ① 개발 목표

**원격 제어 시스템 아키텍처 설계 및 핵심 통신 인프라 구축**

- CPC 및 DMCR 원격 제어를 위한 **전체 시스템 아키텍처** 설계
- 오피스 기반 장거리 원격 제어를 위한 **5G/LTE 통신 인프라** 구축 및 검증
- 장비 탑재 **엣지 컴퓨팅 플랫폼** 기본 SW 개발
- 원격 제어 스테이션 **UI/UX 컨셉 설계**
- 원격 영상 전송 기본 파이프라인 구축 및 **지연시간 500ms 이내** 달성

#### ② 개발 내용 및 범위

**(가) 원격 제어 시스템 아키텍처 설계**

- 원격 제어 시스템의 전체 구성도 및 데이터 흐름도 설계
  - 원격 제어 스테이션 ↔ 통신 네트워크 ↔ 장비 탑재 시스템 간 인터페이스 정의
  - CPC 제어 시스템(전진로보틱스)과의 연동 인터페이스 프로토콜 설계
  - DMCR 제어 시스템(전진로보틱스)과의 연동 인터페이스 프로토콜 설계
- 기능 요구사항 분석 및 시스템 사양서 작성
  - 원격 제어 대상 기능 목록 정의 (붐 조작, 펌핑 제어, 아웃리거 제어, DMCR 이동/타설 등)
  - 안전 요구사항 정의 (비상정지 응답시간, 통신 두절 시 Fail-safe 동작 등)
  - 통신 요구사항 정의 (대역폭, 지연시간, 신뢰성 목표)

**(나) 장거리 통신 인프라 구축 및 검증**

- 5G/LTE 기반 장거리 원격 통신 체계 설계
  - 상용 5G/LTE 네트워크 활용 방안 수립
  - 통신 이중화 구조 설계 (주 링크: 5G/LTE, 백업: Wi-Fi 또는 위성)
  - VPN 기반 보안 통신 채널 구성
- 통신 성능 벤치마크 테스트
  - 다양한 거리 및 환경에서의 5G/LTE 통신 지연·대역폭·안정성 측정
  - 영상 스트리밍 품질 대비 대역폭 최적화 파라미터 도출
  - 통신 두절 시 자동 재연결 및 Fail-safe 시나리오 검증

**(다) 장비 탑재 엣지 컴퓨팅 플랫폼 기본 개발**

- 엣지 컴퓨팅 유닛(ECU) SW 아키텍처 설계
  - 실시간 운영체제(RTOS) 또는 리눅스 기반 소프트웨어 플랫폼 선정
  - 모듈화된 SW 구조 설계 (영상처리, 통신, 센서수집, 제어명령 처리)
- 영상 스트리밍 기본 파이프라인 개발
  - H.265 하드웨어 인코딩 기반 저지연 영상 압축
  - 적응적 비트레이트 스트리밍 (네트워크 상태에 따른 품질 자동 조절)
  - 단일 카메라 기준 영상 전송 지연시간 500ms 이내 목표 달성

**(라) 원격 제어 스테이션 UI/UX 컨셉 설계**

- 원격 운전자의 작업 분석 및 필요 정보 도출
  - 현장 운전자의 조작 패턴·시선 분석을 통한 원격 제어 요구사항 도출
  - 원격 환경에서의 상황 인지에 필요한 정보 항목 정의
- UI/UX 컨셉 레이아웃 설계
  - 메인 영상 뷰 + 보조 카메라 뷰 배치
  - 장비 상태 대시보드 (유압, 펌핑, 붐 자세, DMCR 상태)
  - 조작 패널 레이아웃 (붐 제어, 펌핑 제어, 비상정지)
  - 경보 및 알림 표시 영역
- 원격 제어 입력 장치 사양 검토
  - 조이스틱, 터치스크린, 물리 버튼 등 입력 장치 조합 검토

### 3.2 2차년도 (2027.01 ~ 2027.12, 12개월)

#### ① 개발 목표

**원격 제어 시스템 핵심 기능 개발 및 CPC 통합 시험**

- 멀티뷰 영상 스트리밍 시스템 개발 및 **영상 지연시간 300ms 이내** 달성
- CPC 원격 제어 **전 기능** 구현 (붐 조작, 펌핑 제어, 아웃리거, 비상정지)
- 원격 제어 스테이션 **프로토타입** 개발 및 CPC 연동 시험
- 장비 상태 모니터링 및 **안전 관리 시스템** 개발
- 원격 비상정지 응답시간 **500ms 이내** 달성

#### ② 개발 내용 및 범위

**(가) 멀티뷰 영상 스트리밍 시스템 개발**

- 다시점 카메라 동시 스트리밍 시스템 구현
  - CPC 탑재 4~6대 카메라의 동시 영상 수신 및 디스플레이
  - 카메라 뷰 자동 전환 로직 (작업 단계에 따라 최적 시점 자동 선택)
  - 붐 선단 카메라, 조종석 전방/측면 카메라, 전체 조감 카메라 통합 관리
- 영상 품질 최적화
  - 네트워크 대역폭에 따른 적응적 해상도·프레임레이트 조절
  - 관심 영역(ROI) 기반 선택적 고화질 스트리밍
  - 멀티뷰 동시 전송 시 영상 지연시간 300ms 이내 달성

**(나) CPC 원격 제어 기능 개발**

- 붐 원격 조작 시스템
  - 다관절 붐의 실시간 원격 조작 (조이스틱 → 제어 명령 → CPC 유압 제어)
  - 붐 자세 3D 시각화 및 작업 반경 표시
  - 조작 지연 보상 알고리즘 (예측 디스플레이, 명령 버퍼링)
- 펌핑 원격 제어 시스템
  - 콘크리트 펌핑 시작/정지/속도 제어
  - 펌핑 압력·유량 실시간 모니터링 및 이상 감지
- 아웃리거 원격 제어
  - 아웃리거 전개/수축 원격 조작
  - 장비 수평 상태 모니터링 및 안전 인터록
- 비상정지 시스템
  - 원격 비상정지 버튼 → 장비 즉시 정지 (응답시간 500ms 이내)
  - 통신 두절 시 자동 안전 정지 (Fail-safe)
  - 비상정지 해제 및 재가동 프로세스

**(다) 원격 제어 스테이션 프로토타입 개발**

- HW 구성
  - 다중 모니터 시스템 (메인 영상 + 보조 영상 + 계기판)
  - 산업용 조이스틱 및 조작 패널
  - 비상정지 물리 버튼
  - 양방향 음성 통신 장치
- SW 구성
  - 멀티뷰 영상 디스플레이 애플리케이션
  - 장비 상태 대시보드 (실시간 계기판)
  - 제어 명령 입력 처리 및 전송
  - 운용 이력 로깅 (블랙박스)

**(라) 안전 관리 시스템 개발**

- 원격 제어 안전 기능 구현
  - 통신 품질 실시간 모니터링 및 경보 (지연시간, 패킷 손실률)
  - 통신 품질 저하 시 자동 동작 제한 (속도 감속, 신규 명령 차단)
  - 인증 기반 접근 제어 (운전자 로그인, 권한 관리)
- CPC 통합 시험
  - 실내 시험: 통신 루프백 테스트, 기능 단위 검증
  - 실외 시험: CPC 실장비 연동 원격 제어 시험 (테스트베드)
  - 시험 항목별 합격 기준 수립 및 평가

## 4. 연구개발성과 성능목표

### 성능지표 1: 원격 영상 전송 지연시간

| 항목 | 내용 |
|------|------|
| **성능지표명** | 원격 영상 전송 지연시간 (Video Transmission Latency) |
| **단위** | ms (밀리초) |
| **정의** | CPC/DMCR 탑재 카메라에서 촬영된 영상이 원격 제어 스테이션 모니터에 표시되기까지의 종단 간(End-to-End) 지연시간 |
| **1차년도 목표** | 500ms 이내 (단일 카메라, 5G/LTE 환경) |
| **2차년도 목표** | 300ms 이내 (멀티뷰 4채널 동시, 5G/LTE 환경) |
| **3차년도 목표** | 200ms 이내 (멀티뷰 4채널 동시, 5G/LTE 환경) |

#### 평가 방법

- **측정 방식**: 타임스탬프 동기화 방식
  - 장비 측 카메라 앞에 정밀 타이머(ms 단위)를 배치
  - 원격 스테이션 모니터에 표시된 타이머 값과 실제 현재 시간의 차이를 측정
  - 동일 GPS 시간 소스로 양측 시계 동기화 (NTP/PTP)
- **측정 조건**:
  - 통신: 상용 5G/LTE 네트워크 (특정 통신사 전용망 사용 불가)
  - 거리: 원격 스테이션과 장비 간 최소 5km 이상 이격
  - 영상: Full HD(1920×1080), 30fps 기준
  - 반복: 동일 조건 100회 이상 측정, 평균값 및 95 퍼센타일 값 모두 목표 이내
- **평가 환경**: 한건연 테스트베드 또는 실제 건설현장, 상용 5G/LTE 통신 환경

- **평가 환경**: 한건연 테스트베드 또는 지정 시험장, 상용 5G/LTE 통신 환경
