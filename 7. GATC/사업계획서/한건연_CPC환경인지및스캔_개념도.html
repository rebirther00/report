1차년도 (26.04~26.12) : 센서 선정 및 아키텍처 설계
환경 인지
센서 시스템 설계
  • 다중 센서 선정 및 사양 검토
    (LiDAR, Radar, Camera, Ultrasonic)
  • 센서 융합 아키텍처 설계
    (시간 동기화, 좌표 변환)
  • CPC 붐 센서 배치 설계
    (선단/중간/기부)
  • 센서 마운트 방진·방수 설계
장애물 인지
알고리즘 기본 설계
  • LiDAR 포인트 클라우드 기반
    클러스터링 알고리즘 컨셉
  • 카메라 딥러닝 객체 검출 설계
    (YOLO/SSD 계열)
  • 센서 융합 방식 비교·선정
    (Early/Late/Mid Fusion)
  • 벤치마크 환경 구축
    (실내 테스트 + 시뮬레이션)
현장 스캔
센서 선정 및 기본 설계
  • 스캔 센서 선정
    (소형 LiDAR + 스테레오 카메라)
  • 3D 포인트 클라우드 처리
    알고리즘 설계 (ICP, NDT)
  • 작업량 추론 개념 설계
    (필요량 예측 + 달성량 확인)
  • 운용 시나리오 정의
    (사전→타설→사후 스캔)

2차년도 (27.01~27.12) : 핵심 알고리즘 개발 및 시스템 구현
장애물 인지
핵심 알고리즘 개발
  • LiDAR 기반 장애물 검출
    (클러스터링, 바운딩 박스)
  • 카메라 딥러닝 모델 학습
    (건설현장 특화 데이터셋)
  • 레이더 이동체 검출
    (도플러 효과 활용)
  • 다중 센서 융합 엔진 구현
    (신뢰도 가중 융합)
  • 장애물 추적 알고리즘
    (칼만 필터 + MOT)
3D 맵 생성 및
작업량 추론 시스템
  • 포인트 클라우드 정합
    (ICP/NDT + IMU 보정)
  • 바닥면 추출 및 영역 분할
    (RANSAC + AI 분류)
  • 사전: 필요 체적 자동 계산
    (면적 × 두께 - 비타설 공제)
  • 사후: 달성량 확인 시스템
    (3D 맵 차분 + 달성률)
  • 위험도 평가 및
    안전 신호 출력 시스템
실내 환경 및
CPC 탑재 기초 시험
  • 센서 단품 성능 측정
    (검지 범위, 정확도, 응답)
  • 표준 장애물 검출·분류
    정확도 평가
  • 3D 맵 생성 정확도 평가
    (기준 환경 대비)
  • CPC 붐 센서 장착 테스트
    (진동/움직임 환경)
  • 실외 기본 성능 확인
    (날씨, 분진, 조도)

3차년도 (28.01~28.12) : 시스템 고도화 및 현장 실증
장애물 인지
시스템 고도화
  • 동적 장애물 추적 고도화
    (최대 20개 동시 추적)
  • 악천후 대응 강화
    (우천, 분진, 야간, 역광)
  • 센서 고장 대응
    (Degraded Mode 운용)
  • 전체 붐 간섭 검사 확장
    (전 링크 실시간 검사)
작업량 추론
정확도 향상
  • 3D 맵 정확도 향상
    (붐 자세 오차 보정)
  • 필요량 예측 정밀화
    (ML 기반 보정 모델)
  • 달성량 확인 고도화
    (미타설/두께부족 자동 식별)
  • 타설 품질 지표 산출
    (균일도, 편차 분포)
현장 실증 시험
및 인터페이스 문서화
  • 검출 정확도 ≥ 90%
    오검출률 ≤ 5%
  • 정지 신호 응답 ≤ 500ms
  • 체적 추론 오차 ≤ ±15%
    (필요량 + 달성량 모두)
  • 연속 운용 ≥ 2시간
  • 주관기관 연동
    인터페이스 정의서 작성
