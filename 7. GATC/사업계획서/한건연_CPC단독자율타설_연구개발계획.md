## 1. CPC 단독 자율타설의 필요성

### 1.1 현장 운용 현실과 단독 타설 요구

건설현장에서의 콘크리트 타설 작업은 크게 두 가지로 나뉜다.

- **CPC 단독 타설**: CPC 붐을 직접 이용하여 콘크리트를 타설하는 방식. 일반 건축·토목 현장에서 **전체 타설 작업의 80% 이상**을 차지
- **CPC-DMCR 연계 타설**: 모바일 디스트리뷰터(DMCR)를 통한 분배 타설. 초고층, 대면적, 장거리 분배 등 **특수 현장**에 한정

현재 과제의 자율타설 시스템은 CPC-DMCR 연계 운용을 주요 목표로 하고 있으나, **실제 건설현장의 대다수 작업은 CPC 단독 타설**이다. 따라서 DMCR 없이 CPC만으로 수행하는 **단독 부분 자율타설 시스템**의 개발이 현장 활용도를 높이기 위해 필수적이다.

### 1.2 기존 수동 타설의 문제점

현재 CPC 단독 타설은 숙련 작업자가 조작기(리모컨)로 다관절 붐의 각 관절을 **개별적으로 수동 조작**하며 수행한다.

- **숙련도 의존**: 4~5개 관절의 동시 조작은 높은 숙련도가 필요하며, 숙련 작업자의 **고령화 및 인력 부족**이 심화
- **작업자 피로**: 장시간 반복 타설(1회 타설에 레미콘 수십 대 분량) 시 **피로 누적 → 품질 저하 및 안전사고** 위험
- **비직관적 조작**: 관절 개별 제어는 붐 선단(엔드호스)의 이동 경로를 직관적으로 파악하기 어려워 **비효율적 동선** 발생
- **품질 불균일**: 작업자 숙련도에 따라 타설 두께, 분포가 불균일하여 **시공 품질 편차** 발생

### 1.3 반자율 타설의 개념: 작업자 티칭 기반 자동 타설

본 과제에서 개발하는 CPC 단독 자율타설은 **완전 자율이 아닌 "작업자 티칭(Teaching) 기반 반자율 타설"** 개념이다.

| 단계 | 수행 주체 | 설명 |
|------|----------|------|
| 1. 작업 영역 티칭 | **작업자** | 레미콘 도착 전, 조작기로 붐을 이동하며 타설 영역 경계를 설정 |
| 2. 현장 스캔 | **시스템** | 붐 선단 센서로 바닥 철근부 등 작업 환경을 자동 스캔 |
| 3. 경로 생성 | **시스템** | 티칭 데이터 + 스캔 데이터를 기반으로 최적 타설 경로 자동 생성 |
| 4. 작업자 확인 | **작업자** | 생성된 경로를 콘솔 UI에서 확인·수정·승인 |
| 5. 자동 타설 | **시스템** | 레미콘 도착 후, 생성된 경로를 따라 붐이 자동 이동하며 타설 수행 |
| 6. 감시/개입 | **작업자** | 모니터링하며 이상 시 수동 개입 또는 비상정지 |

이 방식은 작업자의 현장 경험과 판단을 **티칭 단계에서 활용**하면서, 반복적인 타설 작업은 **시스템이 자동 수행**하는 인간-기계 협업 모델이다.

### 1.4 CPC 단독 자동 타설 시나리오

```
[시나리오: CPC 단독 자동 타설 작업 흐름]

① CPC 현장 진입 및 거치
   └─ 아웃리거 전개, 수평 확보, 안전 영역 확인

② 붐 전개 및 현장 스캔
   └─ 붐 선단 센서(LiDAR/카메라)로 바닥 철근부 위주 3D 스캔
   └─ 작업 영역 환경 맵 생성, 타설량(체적) 예측

③ 작업자 티칭 (레미콘 도착 전)
   └─ 작업자가 조작기로 붐을 이동하여 타설 영역 경계 4~N개 포인트 설정
   └─ 높이, 두께, 타설 패턴 등 파라미터 입력 (콘솔 UI)
   └─ 티칭 데이터 저장 (반복 작업 시 재사용 가능)

④ 경로 자동 생성
   └─ 티칭 영역 + 스캔 데이터 → 최적 타설 경로 계산
   └─ 붐 기구학 제약 반영 (도달 범위, 관절 한계, 특이점 회피)
   └─ 장애물 회피 경로 포함
   └─ 작업자 콘솔에서 경로 확인 및 승인

⑤ 레미콘 도착 → 자동 타설 실행
   └─ 작업자 시작 명령 → 시스템이 경로를 따라 붐 자동 이동
   └─ 펌핑 동기화 (타설 속도에 맞춘 콘크리트 공급)
   └─ 타설 진행률 실시간 표시

⑥ 작업자 감시 및 수동 개입
   └─ 콘솔에서 실시간 모니터링 (붐 위치, 타설 진행, 안전 상태)
   └─ 이상 발생 시: 자동 정지 + 수동 개입 전환
   └─ 비상 시: 즉시 비상정지

⑦ 타설 완료
   └─ 영역별 타설 완료 보고 (타설량, 소요시간, 경로 이력)
   └─ 다음 영역 티칭 또는 작업 종료
```

### 1.5 기대 효과

- **생산성 향상**: 작업자 티칭 시간(5~10분) 후 자동 타설로 **연속 작업 효율 30% 이상 향상** 기대
- **품질 균일화**: 시스템 기반 정밀 경로 추종으로 **타설 두께 및 분포 균일성** 확보
- **안전성 제고**: 자동 운전 중 작업자가 위험 구역에서 이탈 가능, **충돌·전복 방지 시스템** 상시 가동
- **숙련도 부담 경감**: 관절 개별 조작 → 좌표 기반 직관적 제어로 **비숙련자도 운용 가능**

## 2. 시스템 구성 (CPC 탑재 HW/SW)

> **참고**: HW 구매는 주관기관(전진로보틱스)에서 수행하며, 한건연은 시스템 설계·SW 개발·알고리즘 개발·통합을 담당

### 2.1 붐 기구학 제어 시스템

- **역할**: CPC 다관절 붐(4~5 관절)의 정기구학(FK)/역기구학(IK) 모델을 기반으로 붐 선단(엔드호스)을 X, Y, Z 좌표로 제어
- **현재**: 조작기로 각 관절을 개별 레버 조작 → 숙련 필요
- **목표**: 목표 좌표 입력 → 시스템이 관절 각도를 자동 계산하여 붐 이동
- **한건연 역할**: 붐 기구학 모델링, FK/IK 알고리즘 개발, 경로 추종 제어기 설계, 특이점·관절 한계 처리 로직

### 2.2 현장 스캔 시스템

- **역할**: 붐 선단(엔드호스 부근)에 탑재된 센서로 바닥 철근부 위주 작업 환경을 3D 스캔
- **센서**: 3D LiDAR (소형, 경량) + 스테레오 카메라 (시각 보완)
- **기능**: 바닥 형상 인식, 철근 배근 패턴 감지, 작업 영역 3D 맵 생성, 타설 체적 예측
- **한건연 역할**: 센서 선정·배치 설계, 3D 포인트 클라우드 처리 SW, 환경 맵 생성 알고리즘, 타설량 예측 모델

### 2.3 작업자 티칭 시스템

- **역할**: 작업자가 조작기로 붐을 직접 이동하며 타설 영역의 경계를 설정하는 인터페이스
- **구성**: 티칭 모드 진입/종료, 경계 포인트 기록, 영역 자동 생성, 높이/두께 파라미터 설정
- **한건연 역할**: 티칭 프로토콜 설계, 포인트 기록·보간 알고리즘, 티칭 데이터 저장·편집·재사용 SW

### 2.4 경로 생성 시스템

- **역할**: 티칭된 작업 영역과 현장 스캔 데이터를 기반으로 최적 타설 경로를 자동 생성
- **알고리즘**: 영역 분할, 지그재그/나선형 패턴 생성, 타설 중첩률 제어, 붐 기구학 제약 반영
- **한건연 역할**: 경로 생성 알고리즘 설계·구현, 붐 도달 범위·특이점 회피 통합, 경로 최적화

### 2.5 안전 시스템

| 항목 | 위험 요소 | 대응 방안 | 한건연 역할 |
|------|----------|----------|------------|
| 충돌 방지 | 붐-구조물, 붐-작업자 접촉 | 근거리 센서 기반 충돌 예측 및 자동 정지 | 충돌 감지 알고리즘, 안전 거리 계산 |
| 전복 방지 | 붐 하중에 의한 장비 전복 | 아웃리거 반력·모멘트 실시간 계산, 안전 영역 제한 | 전복 안정성 모델, 작업 반경 제한 로직 |
| 장애물 회피 | 주변 구조물, 전력선, 크레인 등 | LiDAR/카메라 기반 장애물 인지 및 경로 재계획 | 장애물 감지·분류 알고리즘, 회피 경로 생성 |
| 수동 개입 | 센서 이상, 경로 이탈, 비정상 상황 | 자동 정지 후 수동 제어 전환, 비상정지 | 개입 조건 정의, 모드 전환 로직 |

> **참고**: CPC 붐 완전 전개 시 높이 약 50~75m에 달하므로, 고소 영역에서의 장애물(타워크레인, 전력선, 주변 건물 등) 인지에는 **장거리 LiDAR 또는 레이더 기반 감지**와 **사전 3D 현장 모델 입력** 방식을 병행해야 한다. 1차년도에 가용 기술 검토 및 실현 가능한 안전 범위를 정의한다.

### 2.6 작업 콘솔 및 UI

- **역할**: CPC 현장에서 작업자가 티칭, 모니터링, 수동 개입을 수행하는 전용 인터페이스
- **HW**: 산업용 태블릿 또는 전용 콘솔 단말기 (방진·방수, IP65 이상, 옥외 가시성 디스플레이)
- **화면 구성**:
  - 붐 3D 뷰 (현재 자세, 목표 경로, 작업 영역)
  - 타설 진행 상황 (진행률, 잔여 물량, 현재 위치)
  - 장비 상태 계기판 (유압, 펌핑, 안전 지표)
  - 티칭 인터페이스 (영역 설정, 파라미터 입력)
  - 안전 경보 및 비상정지 버튼
- **한건연 역할**: 콘솔 UI/UX 설계, 티칭 조작 로직, 3D 시각화, 경보 시스템 통합

### 3.1 1차년도 (2026.04 ~ 2026.12, 9개월)

#### ① 개발 목표

**붐 기구학 모델 및 좌표 제어 시스템 설계, 티칭·스캔·안전 개념 정의**

- CPC 다관절 붐의 **정기구학/역기구학 모델** 개발 및 시뮬레이션 검증
- 작업자 **티칭 개념 정의** 및 프로토콜 설계
- 현장 스캔 시스템 **센서 선정 및 설계**
- 안전 시스템 **기본 모델** 설계 (충돌·전복 방지)
- 콘솔 UI **컨셉 설계**

#### ② 개발 내용 및 범위

**(가) 붐 기구학 모델 개발**

- CPC 다관절 붐(4~5 관절) 기구학 모델링
  - DH(Denavit-Hartenberg) 파라미터 기반 붐 구조 모델링
  - 정기구학(FK): 관절 각도 → 붐 선단 3D 위치/자세 계산
  - 역기구학(IK): 목표 좌표 → 관절 각도 역산 알고리즘 (수치 해석 기반)
  - 관절 구동 범위, 특이점(Singularity), 자기 간섭 조건 분석
- 기구학 시뮬레이션 환경 구축
  - 3D 시뮬레이터에서 붐 동작 검증 (MATLAB/Simulink 또는 ROS 기반)
  - 관절 각도 센서 데이터 연동 인터페이스 설계
  - X, Y 축 붐 선단 이동 명령 → 관절 각도 변환 시뮬레이션 검증

**(나) 작업자 티칭 개념 정의 및 프로토콜 설계**

- 티칭 운용 시나리오 정의
  - 티칭 모드 진입/종료 프로세스
  - 경계 포인트 기록 방식 (조작기 버튼 트리거, 자동 샘플링 등)
  - 영역 형상 생성 (포인트 → 다각형 → 타설 구역)
- 작업 영역 지정 방식 설계
  - 2D 평면 영역 지정 (바닥 타설 기준)
  - 높이·두께 파라미터 입력 방식
  - 복수 영역 분할 및 우선순위 설정
- 티칭 데이터 포맷 및 저장 구조 설계
  - 좌표 데이터 + 파라미터 + 메타정보 구조 정의
  - 데이터 저장·불러오기·편집 프로토콜

**(다) 현장 스캔 시스템 설계 및 센서 선정**

- 붐 선단 탑재 스캔 센서 검토 및 선정
  - 소형·경량 3D LiDAR 사양 검토 (무게, 스캔 범위, 해상도, 내환경성)
  - 스테레오 카메라 보조 센서 검토
  - 붐 진동·움직임 환경에서의 센서 안정성 평가
- 바닥 철근부 인식 방안 설계
  - 포인트 클라우드 기반 바닥 면 추출 알고리즘 컨셉 설계

#### 평가 방법

- **측정 방식**: 외부 기준 좌표 측정
  - 토탈 스테이션(Total Station) 또는 RTK-GPS로 붐 선단 실제 위치 측정
  - 시스템이 계산한 FK 위치와 외부 측정 위치를 비교
  - 3D 유클리드 거리 오차 산출: √(Δx² + Δy² + Δz²)
- **측정 조건**:
  - 2차년도: 정적 상태 (붐 정지 상태에서 목표점 도달 후 측정), 붐 전개 50% 이상
  - 3차년도: 동적 상태 (경로 추종 중 연속 측정), 다양한 붐 전개 각도
  - 반복: 동일 조건 50회 이상 측정, **95 퍼센타일 값**이 목표 이내
- **평가 환경**: 한건연 테스트베드, CPC 실장비, 무풍/미풍 조건

### 성능지표 2: 장애물 감지 후 정지 응답시간

| 항목 | 내용 |
|------|------|
| **성능지표명** | 장애물 감지 후 정지 응답시간 (Obstacle Detection to Stop Response Time) |
| **단위** | ms (밀리초) |
| **정의** | 자동 타설 중 붐 이동 경로상에 장애물이 진입한 시점부터 붐 동작이 완전히 정지하기까지의 소요 시간 |
| **1차년도 목표** | 안전 로직 설계 및 시뮬레이션 검증 |
| **2차년도 목표** | 1,000ms 이내 (근거리 장애물, 센서 기반) |
| **3차년도 목표** | 500ms 이내 (근거리 장애물, 센서 기반) |

#### 평가 방법

- **측정 방식**: 이벤트 타임스탬프 측정
  - 표준 장애물(더미)을 자동 타설 경로 상에 진입시킴
  - 센서가 장애물을 감지한 시점(타임스탬프 T1)
  - 붐 동작이 완전히 정지한 시점(타임스탬프 T2, 가속도 센서 기반)
  - 응답시간 = T2 - T1
- **측정 조건**:
  - 장애물: 표준 더미(60cm × 60cm × 180cm, 사람 크기 모사)
  - 감지 거리: 안전 거리 5m 이내 진입 시점 기준
  - 붐 동작: 경로 추종 중 (이동 속도 0.5m/s 이상)
  - 반복: 동일 조건 30회 이상 측정, **모든 측정값**이 목표 이내 (최악값 기준)
- **평가 환경**: 한건연 테스트베드, CPC 실장비, 자동 타설 운전 중
