## 성능지표 1: 장애물 검출 정확도 (Detection Rate)

| 항목 | 내용 |
|------|------|
| **성능지표명** | 장애물 검출 정확도 (Obstacle Detection Rate) |
| **단위** | % (퍼센트) |
| **정의** | 검지 범위 내에 존재하는 장애물 중 시스템이 정상적으로 검출한 비율 (True Positive Rate). 검출 정확도 = 정상 검출 수 / 실제 장애물 수 × 100% |
| **세계 최고 수준 보유국** | 미국, 일본 |
| **세계 최고 수준 보유기업** | Caterpillar (미국) — 자율 광산 운반차량 MineStar, 다중 센서 융합 기반 장애물 검출; Komatsu (일본) — 자율 건설장비 AHS(Autonomous Haulage System), 2025년 Ouster 3D LiDAR 도입으로 인지 성능 고도화 |
| **세계 최고 수준** | 95% 이상 (자율 광산/건설장비, 다중 센서 융합 환경, 정적+동적 장애물) |
| **연구개발 전 국내수준** | 60~70% (단일 센서 기반, ETRI 다중센서 융합 기술 TRL 7 수준이나 건설장비 특화 적용은 초기 단계) |
| **1차년도 목표** | 센서 선정 및 융합 아키텍처 설계 완료, 벤치마크 환경 구축 |
| **2차년도 목표** | 70% 이상 (실내 표준 환경, 다중 센서 융합, 정적 장애물 위주) |
| **3차년도 목표** | **90% 이상** (CPC 탑재, 실외 실증 환경, 동적 장애물 포함) |

### 표준

| 표준/규격 | 내용 |
|----------|------|
| ISO 13849 | 기계류 안전 — 제어 시스템의 안전 관련 부분 |
| IEC 62998 | 기계류 안전 — 안전 관련 센서에 의한 사람 검출 시스템 |
| ISO 17757 | 토공기계 — 자율 기계 및 반자율 기계의 안전 요구사항 |
| EU Machinery Regulation 2023/1230 | EU 기계류 규정 — 자율/반자율 장비 안전 요구사항 |

### 기준 설정 근거

- **세계 최고 수준 95%**: Caterpillar, Komatsu 등 선진 기업의 자율 광산/건설장비는 LiDAR+Radar+Camera 다중 센서 융합으로 95% 이상의 장애물 검출률을 달성하고 있으나, 이는 비교적 개방된 광산 환경에서의 수치임. 건설현장은 복잡도가 높아 동일 수준 달성이 더 어려움
- **국내 수준 60~70%**: 국내 건설장비 안전 시스템은 주로 단일 카메라 또는 초음파 기반으로, 다중 센서 융합 기반 시스템의 건설현장 실증은 초기 단계. ETRI의 다중센서 융합 기술이 TRL 7 수준으로 기술이전 단계이나, CPC 붐과 같은 고소 대형 장비 특화 적용 사례는 부재
- **목표치 90%**: CPC 붐 운용 환경(50~75m 높이, 분진, 진동)의 특수성을 고려하여 세계 최고 대비 약 95% 수준인 90%를 현실적 목표로 설정. 산업안전보건법 및 중대재해처벌법 강화에 따른 건설장비 안전 시스템 요구 수준을 충족하는 것을 목표
- **연차별 단계**: 1차년도(설계) → 2차년도(70%, 실내 기본 검증) → 3차년도(90%, 실외 실증)로 단계적 고도화

### 평가 방법

- **측정 방식**: 표준 장애물 시험
  - 사전 정의된 표준 장애물 세트를 검지 범위 내 다양한 거리·위치에 배치
  - 검출 정확도 = 시스템 정상 검출 수 / 실제 배치 장애물 수 × 100%
  - 장애물 유형별(사람, 구조물, 차량 등) 개별 검출률도 산출
- **표준 장애물 세트**:
  - 사람 모형 더미 (60cm × 60cm × 180cm)
  - 비계/거푸집 모사 구조물 (1m × 1m × 2m)
  - 전력선 모사 (직경 3cm 와이어, 높이 15m)
  - 이동 차량 모사 (원격 조종 카트 또는 실차)
- **측정 조건**:
  - 2차년도: 실내 표준 환경 (정적 장애물 위주, 조명 제어)
  - 3차년도: 실외 실증 환경 (동적 장애물 포함, 자연 조명, 우천·야간 포함)
  - 검지 거리: 5m, 10m, 30m, 50m 각 거리별 평가
  - 반복: 각 조건 30회 이상 반복, **평균 검출률**이 목표 이상
- **평가 환경**: 한건연 테스트베드 또는 건설현장, CPC 실장비 탑재 상태

## 성능지표 2: 장애물 오검출률 (False Positive Rate)

| 항목 | 내용 |
|------|------|
| **성능지표명** | 장애물 오검출률 (False Positive Rate) |
| **단위** | % (퍼센트) |
| **정의** | 실제로 장애물이 없는 영역에서 시스템이 장애물로 잘못 판단한 비율. 오검출률 = 오검출 횟수 / 전체 검출 횟수 × 100% |
| **세계 최고 수준 보유국** | 미국, 이스라엘 |
| **세계 최고 수준 보유기업** | Caterpillar (미국) — MineStar 자율 운용 시스템의 다중 센서 검증 체계; Mobileye (이스라엘) — EyeQ 비전 프로세서 기반 저오검출 인지 시스템 |
| **세계 최고 수준** | 3% 이하 (다중 센서 교차 검증 환경, 광산/건설 자율장비) |
| **연구개발 전 국내수준** | 15~20% (단일 센서 기반, 환경 조건 변화 시 오검출 빈발. 체계적 측정 사례 부족) |
| **1차년도 목표** | 센서 융합 기반 오검출 저감 아키텍처 설계 완료 |
| **2차년도 목표** | 15% 이하 (실내 표준 환경, 다중 센서 교차 검증) |
| **3차년도 목표** | **5% 이하** (CPC 탑재, 실외 실증 환경) |

### 표준

| 표준/규격 | 내용 |
|----------|------|
| ISO 13849 | 기계류 안전 — 제어 시스템의 안전 관련 부분 (오경보 관련 신뢰성 요구) |
| IEC 62998 | 기계류 안전 — 안전 관련 센서에 의한 사람 검출 시스템 (오검출 허용 기준) |
| ISO 17757 | 토공기계 — 자율 기계의 안전 요구사항 (잘못된 감지에 의한 불필요 정지 최소화) |

### 기준 설정 근거

- **세계 최고 수준 3%**: 자율 주행 및 자율 건설장비 분야에서는 다중 센서 교차 검증(LiDAR-Camera-Radar 상호 확인)을 통해 오검출률 3% 이하를 달성. Mobileye의 RSS(Responsibility-Sensitive Safety) 프레임워크에서도 오검출 최소화가 안전성과 운용 효율의 핵심 지표로 관리됨
- **국내 수준 15~20%**: 국내 건설장비 안전 시스템은 단일 센서 의존도가 높아 분진, 역광, 진동 등 환경 변화 시 오검출이 빈발. 오검출률에 대한 체계적 측정·관리 사례가 거의 부재
- **목표치 5%**: 오검출률이 높으면 불필요한 경고·정지가 빈발하여 작업 효율 저하 및 경고 무시(Alarm Fatigue) 유발. 건설현장 실용성을 확보하기 위해 5% 이하를 목표로 설정. 이는 20회 검출 중 1회 이하의 오경보를 의미
- **연차별 단계**: 1차년도(아키텍처 설계) → 2차년도(15%, 다중 센서 교차 검증 기본 효과) → 3차년도(5%, 알고리즘 고도화 및 환경 적응)

### 평가 방법

- **측정 방식**: 장애물 미배치 환경 시험 + 오검출 카운팅
  - 장애물이 없는 표준 환경에서 시스템 운용, 오검출 발생 횟수 측정
  - 장애물이 배치된 환경에서도 비장애물(정상 구조물, 지면 등)의 오인식 횟수 측정
  - 오검출률 = 오검출 횟수 / 전체 검출 이벤트 × 100%
- **오검출 유형 정의**:
  - 지면·벽면 등 고정 배경을 장애물로 오인식
  - 분진·빗방울·눈 등 환경 요인에 의한 허위 검출
  - 센서 노이즈에 의한 비실재 객체 검출
- **측정 조건**:
  - 2차년도: 실내 표준 환경 (1시간 연속 운용 중 오검출 집계)
  - 3차년도: 실외 실증 환경 (2시간 연속 운용, 다양한 기상 조건 포함)
  - 반복: 동일 조건 5회 이상 세션, **각 세션 평균 오검출률**이 목표 이하
- **평가 환경**: 한건연 테스트베드 또는 건설현장, CPC 실장비 탑재 상태

## 성능지표 3: 필요량 예측 오차 (Pre-Pour Volume Estimation Error)

| 항목 | 내용 |
|------|------|
| **성능지표명** | 타설 필요량 예측 오차 (Pre-Pour Volume Estimation Error) |
| **단위** | % (퍼센트, 오차율) |
| **정의** | 사전 스캔으로 추론한 타설 필요 체적과 설계 기준 체적(정밀 측량 기준) 간의 오차율. 오차율 = \|추론값 − 기준값\| / 기준값 × 100% |
| **세계 최고 수준 보유국** | 미국, 스위스 |
| **세계 최고 수준 보유기업** | Trimble (미국) — 3D 레이저 스캐닝 기반 건설현장 체적 측정 솔루션(Trimble X7/SX12); Leica Geosystems/Hexagon (스위스/스웨덴) — RTC360/BLK 시리즈 TLS 기반 정밀 체적 산출 |
| **세계 최고 수준** | ±5% 이내 (측량급 고정형 TLS 장비, 정적 환경, 단순 형상) |
| **연구개발 전 국내수준** | ±30~40% (작업자 경험 기반 육안 추정, 레미콘 투입 후 과부족 빈발. 3D 스캔 기반 자동 추론 체계 미구축) |
| **1차년도 목표** | 알고리즘 개념 설계 완료 (사전 스캔 기반 체적 추론 파이프라인 설계) |
| **2차년도 목표** | ±25% 이내 (실내 표준 환경, 단순 형상 영역) |
| **3차년도 목표** | **±15% 이내** (CPC 탑재, 실외 실증 환경, 복합 형상 포함) |

### 표준

| 표준/규격 | 내용 |
|----------|------|
| ISO 17123-9 | 광학 및 광학 기기 — 측지·측량 기기 현장 시험 절차 — 지상 레이저 스캐너 |
| ASTM E2807 | 3D 이미징 시스템의 정밀도 평가 표준 (3D Imaging Systems) |
| KS F 4009 | 레디믹스트 콘크리트 (콘크리트 물량 관리 관련) |

### 기준 설정 근거

- **세계 최고 수준 ±5%**: Trimble, Leica 등의 측량급 고정형 TLS(Terrestrial Laser Scanner)는 정적 환경에서 ±5% 이내의 체적 측정 정확도를 달성. 단, 이는 삼각대 설치 후 정밀 스캔 기반이며, CPC 붐 선단 탑재 이동 스캔과는 조건이 상이
- **국내 수준 ±30~40%**: 국내 건설현장의 콘크리트 타설 물량 산출은 대부분 설계 도면 기반 수계산 또는 작업자 경험에 의존. 현장 바닥면의 실제 상태(단차, 경사, 구조물 간섭 등)를 반영하지 못해 레미콘 과다 투입 또는 부족이 빈발
- **목표치 ±15%**: CPC 붐 선단에 탑재된 소형 센서로 이동 중 스캔하는 조건은 고정형 TLS 대비 정확도가 떨어질 수밖에 없음. 붐 진동, 풍하중, 센서 해상도 제한 등을 고려하여 ±15%를 현실적 목표로 설정. 이 수준이면 레미콘 6㎥ 기준 약 1㎥ 오차로, 기존 수작업 대비 물량 관리 효율이 대폭 향상
- **연차별 단계**: 1차년도(설계) → 2차년도(±25%, 실내 기본 검증) → 3차년도(±15%, 실외 실증·보정 모델 적용)

### 평가 방법

- **측정 방식**: 기준 체적 비교
  - 사전에 정밀 측량(토탈 스테이션 또는 RTK-GPS)으로 확인된 기준 영역을 스캔
  - 시스템 추론 필요 체적과 정밀 측량 기반 설계 기준 체적 비교
  - 오차율 = |추론값 − 기준값| / 기준값 × 100%
- **기준 영역 구성**:
  - 평면 영역: 정사각형(5m × 5m) 바닥면, 균일 두께 200mm → 기준 체적 5.0㎥
  - 복합 영역: 기둥(비타설 영역) 포함, 단차 포함, 경사면 포함
  - 실제 철근 배근 영역: 실제 건설현장 또는 테스트베드의 철근부
- **측정 조건**:
  - 2차년도: 실내 표준 환경, 단순 형상 영역 (평면 위주)
  - 3차년도: 실외 실증 환경, 복합 형상 영역 포함
  - 반복: 각 영역 유형별 10회 이상 스캔
  - **평균 오차율** 및 **최대 오차율** 모두 목표 이내
- **평가 환경**: 한건연 테스트베드 또는 건설현장, CPC 붐 선단 센서 탑재 상태

## 성능지표 4: 작업량 확인 오차 (Post-Pour Achievement Verification Error)

| 항목 | 내용 |
|------|------|
| **성능지표명** | 타설 작업량 확인 오차 (Post-Pour Achievement Verification Error) |
| **단위** | % (퍼센트, 오차율) |
| **정의** | 사후 스캔(타설 후, 크레인 이동 전)으로 산출한 타설 달성 체적과 실제 투입 체적 간의 오차율. 오차율 = \|산출값 − 실제값\| / 실제값 × 100% |
| **세계 최고 수준 보유국** | 미국, 스위스 |
| **세계 최고 수준 보유기업** | Trimble (미국) — Earthworks 시리즈, 시공 전후 3D 비교 기반 토공량/체적 변화 측정; Leica Geosystems/Hexagon (스위스/스웨덴) — Cyclone 3DR 소프트웨어 기반 사전·사후 맵 차분 체적 분석 |
| **세계 최고 수준** | ±8% 이내 (고정형 TLS 사전·사후 비교, 정적 환경, 토공/콘크리트) |
| **연구개발 전 국내수준** | 측정 체계 미구축 (타설 후 달성량은 육안 검사 또는 레미콘 투입 대수로 간접 추정. 3D 스캔 기반 사전/사후 비교 체계는 국내 건설현장에 적용 사례 없음) |
| **1차년도 목표** | 사후 스캔 기반 달성량 확인 알고리즘 개념 설계 완료 |
| **2차년도 목표** | ±25% 이내 (실내 표준 환경, 알려진 양의 물질 투입 후 비교) |
| **3차년도 목표** | **±15% 이내** (CPC 탑재, 실외 실증 환경, 실제 타설 전후 비교) |

### 표준

| 표준/규격 | 내용 |
|----------|------|
| ISO 17123-9 | 광학 및 광학 기기 — 지상 레이저 스캐너 현장 시험 절차 |
| ASTM E2807 | 3D 이미징 시스템의 정밀도 평가 표준 |
| ASTM C172 | 콘크리트 시료 채취 표준 (타설량 검증 참조) |
| KS F 2402 | 콘크리트의 슬럼프 시험 방법 (타설 품질 관리 관련) |

### 기준 설정 근거

- **세계 최고 수준 ±8%**: 선진 측량 기업(Trimble, Leica)의 고정형 TLS 기반 사전·사후 비교 체적 분석은 ±5~8% 정확도를 달성. 이는 삼각대 고정 스캔·정밀 정합 기반이며, 콘크리트 타설의 경우 표면 거칠기, 수축, 블리딩 등의 영향으로 토공 대비 오차가 다소 큼
- **국내 수준 — 측정 체계 미구축**: 국내 건설현장에서 타설 후 달성량을 3D 스캔으로 객관적·정량적으로 확인하는 체계는 사실상 부재. 레미콘 투입 대수 기록 또는 육안 확인에 의존하여 두께 부족·미타설 등의 품질 문제가 사후에 발견되는 경우가 빈발
- **목표치 ±15%**: CPC 붐 선단 이동 스캔 조건에서 사전·사후 맵 차분의 정확도는 고정형 TLS 대비 제약이 있음. 특히 사후 스캔 시 콘크리트 표면의 불규칙성(블리딩수, 초기 수축 등)이 추가 오차 요인. 이를 고려하여 ±15%를 목표로 설정. 기존에 측정 체계 자체가 없었으므로 ±15% 수준이라도 달성하면 **국내 최초의 정량적 타설 달성량 확인 체계 구축**이라는 의의
- **연차별 단계**: 1차년도(개념 설계) → 2차년도(±25%, 실내 환경에서 맵 차분 기본 검증) → 3차년도(±15%, 실외 실증·보정 모델 적용)

### 평가 방법

- **측정 방식**: 사전·사후 맵 차분 기반 체적 비교
  - 기준 영역에 알려진 양의 콘크리트(또는 대체 물질)를 투입
  - 타설 전 사전 스캔 → 물질 투입 → 타설 후 사후 스캔 (크레인 이동 전)
  - 시스템 산출 달성 체적(사전·사후 맵 차분)과 실제 투입 체적 비교
  - 오차율 = |산출값 − 실제값| / 실제값 × 100%
- **기준 영역 구성**:
  - 평면 영역: 정사각형(5m × 5m), 두께 200mm → 투입 체적 5.0㎥
  - 복합 영역: 기둥 포함, 단차 포함 → 투입 체적 별도 정밀 계량
  - 실제 타설 영역: 실제 레미콘 투입량(계량기 기준)과 비교
- **측정 조건**:
  - 2차년도: 실내 표준 환경, 단순 형상 (알려진 양의 물질 투입)
  - 3차년도: 실외 실증 환경, 실제 콘크리트 타설 전후 비교 포함
  - 반복: 각 영역 유형별 10회 이상 스캔
  - **평균 오차율** 및 **최대 오차율** 모두 목표 이내
- **평가 환경**: 한건연 테스트베드 또는 건설현장, CPC 붐 선단 센서 탑재 상태
