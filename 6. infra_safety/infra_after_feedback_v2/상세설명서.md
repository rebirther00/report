# 자율 작업형 건설기계 인프라 상세 설명서 (v2)

> **버전**: v2.0 (2단계 5개년 체계 반영)  
> **작성일**: 2026.01.08  
> **주요 변경**: 2단계 5개년(1-1~2-2) 로드맵 개편, 장비비 80억 조정 반영, 패키지별 적용 표준 명시

---

## 📖 문서 개요

본 문서는 자율 작업형 건설기계 통합 제어기 평가 인프라의 핵심인 **6종 통합 패키지 시스템**의 기능, 구성 요소, 활용 시나리오 및 주요 장비 사양을 상세히 설명합니다.

---

## 1. 📦 Package 1: 제어로직 모델링 검증 시스템 (A1)

### 1.1 시스템 개요
*   **핵심 기능**: PC 기반 가상 환경에서 건설기계 제어 로직(VCU, MCU 등)과 유압/구동 플랜트 모델을 연동하여 검증.
*   **검증 레벨**: MIL(Model-in-the-Loop), SIL(Software-in-the-Loop).
*   **적용 표준**: ISO 19014 Part 1~4, IEC 61508.
*   **예산**: 1,600백만원.
*   **구축 시기**: 1-1차 ~ 1-2차 (2026~2027).

### 1.2 주요 구성 요소
1.  **모델링 플랫폼**: MATLAB/Simulink 기반 제어 알고리즘 설계 환경.
2.  **자동 코드 생성**: dSPACE TargetLink를 활용한 ISO 26262 준수 C-Code 생성.
3.  **가상 ECU 플랫폼**: dSPACE VEOS를 활용하여 실제 HW 없이 가상 제어기 검증.
4.  **범용 플랜트 모델**: 굴착기, 로더 등 다기종에 대응 가능한 모듈형 라이브러리.

---

## 2. 📦 Package 2: 통합 제어 SW/HW 시나리오 검증 시스템 (A2+A3+A4)

### 2.1 시스템 개요
*   **핵심 기능**: 소스코드 품질 분석부터 실제 ECU와 가상 환경을 연동한 HILS 검증까지 통합 수행.
*   **검증 레벨**: Static Analysis, HILS(Hardware-in-the-Loop Simulation), Scenario Testing.
*   **적용 표준**: ISO 26262, MISRA-C/C++, CAN J1939.
*   **예산**: 2,800백만원.
*   **구축 시기**: 1-2차 ~ 1-3차 (2027~2028).

### 2.2 모듈별 상세 기능
1.  **A2 (코드분석)**: 정적 분석(STATIC), 커버리지(COVER), 단위테스트(CT)를 통한 SW 품질 보증.
2.  **A3 (HILS)**: dSPACE SCALEXIO LabBox를 활용한 실제 ECU와 가상 환경의 실시간 연동 검증.
3.  **A4 (시나리오)**: CARLA 3D 엔진과 가상 센서(LiDAR/CAM)를 연동한 자율작업 시나리오 검증.

---

## 3. 📦 Package 3: 실차-가상 연동 커넥티비티 평가 시스템 (A5+A6+B6)

### 3.1 시스템 개요
*   **핵심 기능**: 실제 건설기계에 평가 시스템을 탑재하여 가상 환경과 연동(VILS)하고, 통신 보안성을 검증.
*   **검증 레벨**: VILS(Vehicle-in-the-Loop Simulation), 실차 계측, 통신 보안 분석.
*   **적용 표준**: UN R155, ISO/SAE 21434.
*   **예산**: 1,450백만원.
*   **구축 시기**: 2-1차 ~ 2-2차 (2029~2030).

### 3.2 주요 구성 요소
1.  **A5 (VILS)**: MicroAutoBox III를 활용한 실차-가상 연동 및 위험 상황(통신 지연 등) 재현.
2.  **A6 (실차 계측)**: 고정밀 GPS RTK, IMU, 유압 센서를 활용한 실제 주행/작업 데이터 수집.
3.  **B6 (커넥티비티)**: 5G/LTE 프로토콜 분석 및 IDS(침입 탐지) 시스템을 통한 통신 보안 검증.

---

## 4. 📦 Package 4: 전주기 사이버보안 위협 분석 시스템 (B1~B4)

### 4.1 시스템 개요
*   **핵심 기능**: 설계부터 운영까지 사이버보안 위협을 분석하고 취약점을 보완하는 전주기 보안 관리 체계.
*   **검증 레벨**: TARA(Threat Analysis), 보안코딩, 침투테스트, CSMS 인증 지원.
*   **적용 표준**: ISO/SAE 21434, NIST SP 800-115.
*   **예산**: 950백만원.
*   **구축 시기**: 1-2차 (2027).

### 4.2 주요 단계
1.  **B1 (TARA)**: 자산 식별 및 위협 시나리오 도출(itemis SECURE).
2.  **B2 (보안코딩)**: CWE/CERT 취약점 분석 및 AI 기반 수정 가이드 제공.
3.  **B3 (침투테스트)**: ECU 하드웨어 해킹, 퍼징 테스트, GPS 스푸핑 모의 해킹.
4.  **B4 (CSMS)**: 보안 관리 체계 구축 및 UN R155 인증 문서화 지원.

---

## 5. 📦 Package 5: SUMS 대응 인증 평가 시스템 (B5)

### 5.1 시스템 개요
*   **핵심 기능**: 소프트웨어 업데이트 관리 체계(SUMS) 및 OTA 보안성 검증.
*   **검증 레벨**: OTA 업데이트 프로세스 무결성 및 복원력 검증.
*   **적용 표준**: UN R156, ISO 24089.
*   **예산**: 350백만원.
*   **구축 시기**: 2-1차 (2029).

### 5.2 주요 기능
1.  **OTA 무결성 검증**: 업데이트 파일의 서명/암호화 확인 및 배포 서버 보안 테스트.
2.  **롤백 테스트**: 업데이트 실패 시 안전한 복구(Rollback) 기능 검증.
3.  **이력 관리**: 규제 요구사항에 따른 5년 이상의 업데이트 이력 관리 시스템 구축.

---

## 6. 📦 Package 6: AI 안전성/신뢰성 실증 시스템 (C1~C3)

### 6.1 시스템 개요
*   **핵심 기능**: AI 모델의 설명가능성(XAI) 확보, 적대적 공격 강건성 테스트 및 수명주기 관리(MLOps).
*   **검증 레벨**: AI 모델 정확도, 강건성, 성능 드리프트 모니터링.
*   **적용 표준**: EU AI Act, ISO/IEC 42001.
*   **예산**: 850백만원.
*   **구축 시기**: 1-3차 (2028).

### 6.2 주요 구성 요소
1.  **C1 (XAI)**: SHAP/LIME 등을 활용한 AI 의사결정 근거 분석 및 성능 리포트 자동 생성.
2.  **C2 (적대적 공격)**: LiDAR 공격 시뮬레이터 및 물리적 Adversarial Patch를 통한 강건성 검증.
3.  **C3 (MLOps)**: 모델 버전 관리 및 현장 데이터 기반 성능 저하(Drift) 탐지 및 재학습 체계.
