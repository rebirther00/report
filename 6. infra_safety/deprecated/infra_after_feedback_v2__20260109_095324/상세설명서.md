## 📖 문서 개요

본 문서는 자율 작업형 건설기계 통합 제어기 평가 인프라의 핵심인 **6종 통합 패키지 시스템**의 상세 사양, 기능, 활용 시나리오를 설명합니다.

---

## 1. 📦 Package 1: 제어로직 모델링 검증 시스템 (A1)

### 1.1 시스템 개요
*   **핵심 기능**: PC 기반 가상 환경에서 제어 로직과 플랜트 모델을 연동하여 MIL/SILS 검증 수행.
*   **적용 표준**: ISO 19014, IEC 61508.
*   **예산**: 1,600백만원.
*   **구축 시기**: 1-1차 ~ 1-2차.

### 1.2 시스템 구성도
```
┌──────────────────────────────────────────────────────────────┐
│                 Package 1: 제어로직 모델링 검증               │
├──────────────────────────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐      │
│  │  모델링 도구  │ →  │  코드 생성   │ →  │  가상 ECU   │      │
│  │ (Simulink)  │    │ (TargetLink)│    │  (VEOS)    │      │
│  └─────────────┘    └─────────────┘    └─────────────┘      │
│         ↑                                     ↓              │
│  ┌──────────────────────────────────────────────────┐       │
│  │         범용 건설기계 플랜트 모델 라이브러리         │       │
│  └──────────────────────────────────────────────────┘       │
└──────────────────────────────────────────────────────────────┘
```

### 1.3 활용 시나리오
*   **시나리오 1**: 부품사 유압 펌프 제어 알고리즘 검증.
*   **시나리오 2**: 완성차 VCU 로직 사전 검증.

---

## 2. 📦 Package 2: 통합 제어 SW/HW 시나리오 검증 시스템 (A2+A3+A4)

### 2.1 시스템 개요
*   **핵심 기능**: SW 코드 분석부터 ECU 실물 연동 HILS, 가상 센서 연동 시나리오 검증까지 통합 수행.
*   **적용 표준**: ISO 26262, MISRA-C/C++.
*   **예산**: 2,800백만원.
*   **구축 시기**: 1-2차 ~ 1-3차.

### 2.2 검증 단계별 흐름
```
[STEP 1: A2 코드분석] → [STEP 2: A3 HILS] → [STEP 3: A4 시나리오]
(정적분석/커버리지)     (ECU 실물 연결)      (가상 환경/센서 연동)
```

### 2.3 주요 특징
*   **CARLA 활용**: 오픈소스 3D 엔진을 활용하여 LiDAR/Camera 센서 시뮬레이션 및 토공 작업 시나리오 구축.
*   **모델 재사용**: Pkg 1에서 개발된 플랜트 모델을 Pkg 2의 실시간 시뮬레이터(SCALEXIO)에서 재사용하여 효율성 극대화.

---

## 3. 📦 Package 3: 실차-가상 연동 커넥티비티 평가 시스템 (A5+A6+B6)

### 3.1 시스템 개요
*   **핵심 기능**: 실차 계측 데이터와 가상 환경을 연동(VILS)하고, 원격 제어 및 커넥티비티 보안성을 평가.
*   **적용 표준**: UN R155, ISO/SAE 21434.
*   **예산**: 1,450백만원.
*   **구축 시기**: 2-1차 ~ 2-2차.

### 3.2 VILS vs 실차 시험장 역할 분담
*   **VILS (A5)**: GPS 스푸핑, 통신 지연 등 위험/이상 상황 재현 및 검증.
*   **실차 시험장 (A6)**: 실제 지형에서의 정상 주행 및 작업 성능 계측.
*   **커넥티비티 (B6)**: 5G/LTE 프로토콜 분석 및 침입 탐지(IDS) 검증.

---

## 4. 📦 Package 4: 전주기 사이버보안 위협 분석 시스템 (B1~B4)

### 4.1 시스템 개요
*   **핵심 기능**: 설계(TARA) → 구현(보안코딩) → 검증(침투테스트) → 운영(CSMS) 전주기 대응.
*   **적용 표준**: ISO 21434, NIST SP 800-115.
*   **예산**: 950백만원.
*   **구축 시기**: 1-2차.

### 4.2 주요 구성
*   **B1 TARA**: 위협 분석 및 위험 평가.
*   **B2 보안코딩**: 소스코드 취약점 분석 및 AI 기반 수정 가이드 제공.
*   **B3 침투테스트**: 모의 해킹, 퍼징 테스트를 통한 보안 강건성 확인.

## 5. 📦 Package 5: SUMS 대응 인증 평가 시스템 (B5)

### 5.1 시스템 개요
*   **핵심 기능**: OTA(Over-the-Air) 업데이트 보안성 및 업데이트 관리 체계(SUMS) 적합성 검증.
*   **적용 표준**: UN R156, ISO 24089.
*   **예산**: 350백만원.
*   **구축 시기**: 2-1차.

## 6. 📦 Package 6: AI 안전성/신뢰성 실증 시스템 (C1~C3)

### 6.1 시스템 개요
*   **핵심 기능**: AI 모델의 정확도, 설명가능성(XAI), 적대적 공격 강건성 및 수명주기(MLOps) 관리.
*   **적용 표준**: EU AI Act.
*   **예산**: 850백만원.
*   **구축 시기**: 1-3차.

### 6.2 주요 모듈
*   **C1 AI 검증/XAI**: AI 모델의 의사결정 근거 분석.
*   **C2 적대적 공격**: LiDAR 공격 시뮬레이터 및 Adversarial Patch 생성 시스템 구축.
*   **C3 MLOps**: 모델 버전 관리 및 현장 성능 드리프트 감지.
