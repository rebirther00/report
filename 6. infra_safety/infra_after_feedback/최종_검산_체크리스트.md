## 최종 검산 체크리스트 (1페이지 요약)

목표: `개선안.md`, `도구.md`, `상세설명서.md`, `세부예산.md` 4개 문서의 **숫자/연차/표준/표 구조**가 서로 모순 없이 완전히 동일한지 최종 검산한다.

---

## 1) 최상위 불변값(반드시 동일)

- **총사업비(백만원)**: **15,000**
- **장비비(패키지 Pkg 1~6 합계, 백만원)**: **8,000**
- **시설비(공용 시설, 백만원)**: **425** *(장비비 외: 재료비/운영비 성격으로 분리 표기)*
- **기술개발비(백만원)**: **4,500**
- **운영비(백만원)**: **1,500**
- **예비비(조정분, 백만원)**: **575**
- **합계 검산**: 8,000 + 425 + 4,500 + 1,500 + 575 = **15,000**

---

## 2) 연차 체계(표기 통일)

- **연차 체계**: **1-1차 → 1-2차 → 1-3차 → 2-1차 → 2-2차** (총 5개 연차)
- **금지 표기(잔존 시 오류)**: `1차/2차/3차/4차/5차`, `1~5차년도`, `2~4차년도`

## 5) 연차별 장비비(배분표 검산: 세로/가로 합계)

### 5.1 Pkg×연차 배분표(50:50 규칙)

- **2개 연차에 걸친 Pkg는 50:50 균등 배분**
  - Pkg1: 1,500 → (1-1: 750 / 1-2: 750)
  - Pkg2: 2,980 → (1-2: 1,490 / 1-3: 1,490)
  - Pkg3: 1,410 → (2-1: 705 / 2-2: 705)

### 5.2 연차 합계(장비비)

| 연차 | 장비비(백만원) |
|:---:|---:|
| **1-1** | 750 |
| **1-2** | 3,100 |
| **1-3** | 2,460 |
| **2-1** | 985 |
| **2-2** | 705 |
| **합계** | **8,000** |

## 6) 시설비(공용 시설) 처리 규칙

- **시설비 425(백만원)**은 **장비비(패키지 8,000) 합계에 포함하면 안 됨**
- 문서 내 표현은 다음 중 하나로 명확해야 함:
  - “시설비(공용 시설) 425는 장비비 외(재료비/운영비 성격)”
  - “장비비(Pkg 1~6) 8,000 + 시설비 425 + … = 총 15,000”

## 7) 적용 표준/규제(각 Pkg 1줄씩 존재해야 함)

- **Pkg 1**: ISO 19014 *(기존 유지)*  
- **Pkg 2**: ISO 26262(기능안전), MISRA-C(코딩규격)  
- **Pkg 3**: ISO 15143-3(데이터 통신), UN R155/156  
- **Pkg 4**: EU CRA(사이버복원력법), ISO/SAE 21434  
- **Pkg 5**: ISO 24089(SW 업데이트)  
- **Pkg 6**: EU AI Act, ISO/IEC 23894(AI 위험관리)

## 9) 파일별 체크 포인트(어디를 보면 되는지)

- **`세부예산.md`**
  - **총괄표**: 총사업비 15,000 유지 + 장비비(패키지) 8,000 + 시설비 425 + 예비비 575 구조 확인
  - **Pkg별 예산 요약**: Pkg1~6 금액이 1,500/2,980/1,410/860/280/970로 일치
  - **Pkg×연차 배분표**: 50:50 적용 및 가로/세로 합계가 8,000으로 닫힘
  - **연차별 집행 계획**: 1-1~2-2차 표기 및 총합 15,000 일치

- **`개선안.md`**
  - **2.2 인프라 구축 계획 표**: 연차가 1-1~2-2로 표기되고, `유형` 열이 없어야 함
  - **5.1 로드맵/5.2 Gantt**: 구축 연차 및 장비비(패키지) 연차별 값이 750/3,100/2,460/985/705로 일치
  - **예산 요약 표**: 장비비(패키지) 8,000 + 시설비 425 + 예비비 575 포함해 총 15,000 일치

- **`상세설명서.md`**
  - 각 Pkg 개요 표의 **구축 연차/예산/적용 표준**이 본 체크리스트와 일치
  - (추가 표가 있으면) 기종별 모델 확보 연차 등도 1-1~2-2 체계로 표기

- **`도구.md`**
  - 증액된 수량/예산(예: TargetLink 4, VEOS 4, A2 도구 6, I/O 보드 12, GPU/AI 서버 등)이 `세부예산.md`의 패키지 예산과 모순 없음
  - 하단 “전체 예산” 요약이 **장비비(패키지) 8,000 / 시설비 425 / 총 15,000** 구조로 맞춰져야 함
