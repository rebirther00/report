## 요약표

| 구분 | 내용 |
|:---:|:---|
| **글로벌 규제** | EU MR (기능안전), EU CRA (사이버보안), EU AI Act (AI 안전성) |
| **후방 산업** | 센서, ECU, 액추에이터, SW/AI (부품사) |
| **본 사업** | 6종 장비 (MIL/SIL, HILS, 실차연동, 사이버보안, OTA, AI안전성) |
| **전방 산업** | 굴착기, 휠로더, 지게차, 도저, 덤프트럭 (완성차) |
| **최종 수요** | 건설업, 광업, 물류/항만, 농업 |
| **정책 연계** | 피지컬 AI 초격차 프로젝트 |

## Mermaid 다이어그램 코드

### 버전 1: 전체 산업구조 흐름도

```mermaid
flowchart TB
    subgraph REG["🌍 글로벌 규제 환경 ('27년~)"]
        R1["EU MR<br/>기능안전"]
        R2["EU CRA<br/>사이버보안"]
        R3["EU AI Act<br/>AI 안전성"]
    end

    subgraph BACK["⬅️ 후방 산업 (부품사)"]
        B1["센서<br/>LiDAR/Radar/Camera"]
        B2["ECU<br/>통합/자율제어"]
        B3["액추에이터<br/>조향/주행/유압"]
        B4["SW/AI<br/>알고리즘/OTA"]
    end

    subgraph MAIN["⭐ 본 사업: 적합성 평가 기반 구축"]
        subgraph STEP1["1단계: SW·ECU 레벨 (1~3차년도)"]
            E1["장비1<br/>MIL/SIL<br/>모델검증"]
            E2["장비2<br/>HILS<br/>ECU통합"]
            E4["장비4<br/>사이버보안<br/>전주기"]
            E6["장비6<br/>AI안전성<br/>XAI/MLOps"]
        end
        subgraph STEP2["2단계: 실차 레벨 (4~5차년도)"]
            E3["장비3<br/>실차연동<br/>MIL"]
            E5["장비5<br/>OTA보안<br/>SUMS"]
        end
    end

    subgraph FRONT["➡️ 전방 산업 (완성차)"]
        F1["굴착기"]
        F2["휠로더"]
        F3["지게차"]
        F4["도저"]
        F5["덤프트럭"]
    end

    subgraph END["🏭 최종 수요처"]
        D1["건설업"]
        D2["광업"]
        D3["물류/항만"]
        D4["농업"]
    end

    REG -->|적합성 평가 요구| BACK
    BACK -->|부품 공급| MAIN
    E1 --> E2 --> E4
    E4 --> E3
    E4 --> E5
    E6 -.->|피지컬 AI 연계| E2
    MAIN -->|검증 완료| FRONT
    FRONT -->|제품 공급| END

    style MAIN fill:#fff3cd,stroke:#ffc107,stroke-width:3px
    style REG fill:#f8d7da,stroke:#dc3545
    style BACK fill:#d1ecf1,stroke:#17a2b8
    style FRONT fill:#d4edda,stroke:#28a745
    style END fill:#e2e3e5,stroke:#6c757d
```
