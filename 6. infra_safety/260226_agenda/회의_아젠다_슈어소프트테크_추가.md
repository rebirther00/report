## 1. 답변 분석 - 문제점 및 보완 필요사항

### 1.1 구체성이 부족한 답변

| 질문 항목 | 슈어소프트 답변 요약 | 문제점 |
|:---|:---|:---|
| **SIMVA + SCALEXIO 연동** | "가능합니다" | 실제 연동 경험/사례, 기술적 방식(FMI/FMU 등) 설명 없음 |
| **VERIFAI-M 커버 범위** | "AI 모델 검증 솔루션으로 전 과정 통합 검증" | XAI, 적대적 공격, 뉴런커버리지, EU AI Act 보고서 자동 생성 등 구체 기능 미답변 |
| **HILS 납품 실적** | "모빌리티 분야 납품 실적 다수" | 구체적 건수, 프로젝트명, HW 구성 상세 없음 |

### 1.2 건설기계 분야 경험 부재

- **레퍼런스**: 국방과학연구소 사례(다중로봇 협동자율주행)를 제시했으나, 이는 **군용 로봇** 분야로 건설기계(유압 제어, 토공작업, J1939) 고유 영역과 차이가 큼
- **ISO 19014**: 대응 사례 **없음을 명시적으로 인정**. 로봇/국방/원자력/철도 등 Mission Critical 분야 경험만 보유
- **시사점**: 건설기계 특화 역량(유압 시스템, 토공 시나리오, J1939 프로토콜 등)에 대한 기술 이전/학습 비용 발생 가능

### 1.3 AUTORACT vs CANoe 뉘앙스

- "CANoe와 동일기능"이라 하면서 "CANoe는 Vector사 제품군 특화 검증이 가능"이라고 부연
- **해석**: Vector VN 장치 연동이나 Vector 고유 프로토콜 지원에서는 CANoe가 여전히 필요할 수 있음
- **확인 필요**: AUTORACT 단독 운용 시 Vector 장비 없이 CAN J1939 분석/시뮬이 완전히 가능한지

### 1.4 가격/라이선스 관련 답변 전면 누락

사전 요청한 핵심 자료가 전혀 포함되지 않음:

| 요청 자료 | 수신 여부 |
|:---|:---:|
| Floating 라이선스 수량별 단가표 (1/3/5/6/10 user) | ❌ |
| 패키지 번들 할인 조건표 | ❌ |
| 연간 유지보수 비용 | ❌ |
| 교육 프로그램 상세 | ❌ |
| 제품별 기능 스펙시트 (SIMVA, ARCHON Z, VERIFAI-M) | ❌ |
| dSPACE SCALEXIO 연동 아키텍처 다이어그램 | ❌ |
| 연차별 납품/설치/교육 일정 제안 | ❌ |

### 1.5 긍정적 확인 사항

| 항목 | 내용 |
|:---|:---|
| **DCAT = AUTOSIM 통합** | DCAT은 별도 제품이 아닌 AUTOSIM 번들 포함 항목 (추가 비용 없음) |
| **ARCHON Z J1939** | CAN/CAN-FD 모두 지원 확인 |
| **개발 지원 범위** | 3D 환경, 시나리오, 맵 구성, HILS 연동 등 개발 파트 전반 지원 가능 (담당 부서 실장 동행 가능) |
| **DCAT MLOps 연동** | 데이터 생성-분석-연동 기능으로 MLOps 구축 시 활용 가능 |

## 2. 미팅 시 추가 질의 사항

### 2.1 기술 상세 확인 (필수)

| 순번 | 질의 | 배경/목적 |
|:---:|:---|:---|
| 1 | **SIMVA**가 dSPACE SCALEXIO와 연동 시 사용하는 프로토콜/표준은? (FMI/FMU, XCP 등) 실제 연동 구축 사례가 있는가? | VEOS 대체 검토의 핵심 판단 기준 |
| 2 | **VERIFAI-M**이 커버하는 구체적 기능 목록: ① XAI(SHAP/LIME 수준), ② 뉴런커버리지, ③ 적대적 공격 강건성, ④ EU AI Act/ISO IEC TS 4213 기반 리포트 자동 생성 | 오픈소스(30M) 대비 200M 정당성 확보 |
| 3 | **AUTORACT**가 Vector VN 장치 없이 독립 운영 가능한가? dSPACE I/O 보드(DS2655 CAN)와 직접 연동되는가? | CANoe 완전 대체 vs 병행 판단 |
| 4 | **ARCHON Z** 200M vs Defensics 60M: 3배 이상 가격 차이에 대한 기능/성능 차별점은? 건설기계 CAN J1939 퍼징 실적은? | 가격 대비 가치 판단 |
| 5 | **PROV**: 건설기계 ECU(TriCore/AURIX 기반) 타이밍 측정 지원 여부, 지원 RTOS 목록 | ISO 19014 대응 필요성 판단 |
| 6 | **ALIRA-AI**: STATIC/CT/COVER 연동 자동화의 구체적 범위는? 실제 적용 사례(검증 자동화 전후 비교)가 있는가? | 300M 투자 대비 실효성 판단 |

### 2.2 가격/라이선스 (필수 - 미수신 자료 재요청)

| 순번 | 요청 사항 |
|:---:|:---|
| 1 | 제품별 **Floating 라이선스 수량별 단가표** (1/3/5/6/10 user) |
| 2 | **패키지 번들 할인 조건표** (5개 이상, 10개 이상 동시 도입 시) |

| 5 | **상세 견적서**: 우리 6종 패키지 구조에 맞춘 제품 매핑 포함 |

## 3. 슈어소프트테크 추가 문의사항에 대한 답변

### Q1. MLOps 체계를 구축하려는 목적은?

본 사업의 MLOps 체계는 **EU AI Act** 대응을 핵심 목적으로 합니다.

| 목적 | 상세 |
|:---|:---|
| **사후 모니터링** | 자율작업 건설기계 탑재 AI 모델의 필드 성능 저하(Data Drift) 실시간 탐지 |
| **모델 버전 관리** | 학습-검증-배포-업데이트 전 과정 추적/관리 (ISO/IEC 23894 대응) |
| **재학습 검증** | 필드 데이터 기반 모델 업데이트 시 안전성 검증 자동화 |
| **인적 감독 체계** | 모델 업데이트 승인 워크플로우 운영 (EU AI Act "Human Oversight") |

- Package 6(C3 모듈)에서 **MLflow + Kubeflow** 기반 오픈소스 플랫폼으로 구축
- **Evidently AI**를 통한 드리프트 탐지 결합

### Q2. 학습 및 배포 대상 주요 모델의 종류와 학습 대상 데이터 유형은?

**모델 종류: Deep Learning** (LLM이 아님)

| 구분 | 상세 |
|:---|:---|
| **주요 모델** | 객체 인식(Object Detection) - 건설현장 작업자, 장애물, 차량 인식 |
| **성능 지표** | mAP, IoU 기반 정확도 평가 |
| **설명가능성** | SHAP, LIME, Grad-CAM 기반 XAI 리포트 생성 |

**학습 대상 데이터 유형:**

| 데이터 유형 | 상세 | 규모 |
|:---|:---|:---|
| **이미지 데이터** | RGB 카메라 영상 (먼지/진동/저조도/역광 환경) | 10만장 이상 |
| **3D 포인트클라우드** | LiDAR 센서 데이터 (Velodyne/Ouster 에뮬 포함) | - |
| **시계열 데이터** | IMU, 유압 센서 등 센서 시계열 (드리프트 탐지 대상) | - |

### Q3. MLOps 체계 구축을 위한 HW 인프라는 보유하고 있는지?

**본 사업에 HW 인프라 구축이 포함되어 있습니다.**

| 장비 | 사양 | 수량 | 해당 패키지 | 예산 |

| **학습/검증 GPU 서버** | NVIDIA A100 80GB x4 | 2대 | Pkg 6 (C1) | 400백만원 |
