# 3. 융합 논리 자료 — 한국건설기계연구원 실증 내용

> 한국건설기계연구원(KOCETI) · 사업계획서 딥테크 지역확산형 **과제14 「초경량·고정밀 자율작업 건설기계의 핵심기술 개발 및 실증」** · ★제일 중요 자료

## 1. 과제간 연계성 및 융합 논리 모형 (한건연)

```
                    [KIST 등] 복합소재 원천기술
                  (초경량·고강도 섬유강화 복합소재)
                              │ 소재 적용 ▼        ▲ 소재 환류(closed-loop)
┌──── 자율작업 핵심기술 (본연구) : 비정형 환경 무인 자율작업 핵심기술 ────┐
│  주관: 생기원      공동: 한국건설기계연구원      공동: 한국전자기술연구원(KETI) │
│  도메인: 농기계      도메인: 건설기계(굴착기·AWP)    도메인: 특장차·센서/통신/VLA │
│  [공통 핵심기술 4종을 도메인별 평행 개발]                                       │
│   ① 비정형 인지·시맨틱  ② 자율작업 프레임워크  ③ DT 시뮬레이터  ④ 실작업데이터·실–가상검증 │
└──────────┬───────────────────────┬───────────────────────┬───────────────────┘
           │ 농기계                  │ 건설기계 (한건연 트랙)    │ 특장차
           ▼                         ▼                         ▼
   과제13 : 농기계 사업화    ★ 과제14 : 초경량·고정밀 자율작업       과제15 : 특수목적차량
      (생기원)              건설기계 핵심기술 개발·실증 (한건연 주관)   작업안전·사업화 (KETI)
                           → 초경량·고강도 복합소재 경량 구조 +
                             소방/방재 AWP : DT 원격작업·능동안전(전복방지) 실증
```

**핵심 메시지**
- **세로 연계성** : 한건연은 자율작업 핵심기술(본연구)에서 *건설기계 도메인 핵심기술*을 공동개발 → 과제14에서 *초경량·고강도 복합소재 적용 건설기계 핵심기술 개발·실증*으로 직결 → **"핵심기술 개발 → 실증·사업화" 단일 트랙**
- **가로 연계성** : 동일 4대 핵심기술을 농기계(생기원)·건설기계(한건연)·특장차(KETI)가 **도메인별 평행 개발** → 중복 아닌 분담
- **closed-loop** : **초경량·고강도 복합소재** 적용 → 구조 강성·진동·동특성 변화 → 디지털 트윈 반영 → AI 자율작업·능동안전 재학습 → 실차 검증 → 소재 환류

## 3. 실증 항목별 상세 및 그림안

### ◾ 1순위 — 초경량·고강도 복합소재 적용과 연계한 실증

**① 초경량·고강도 복합소재 붐(Arm) 적용 AWP 디지털 트윈·능동안전 실증**
- **복합소재 연계** : 초고강도·경량 섬유강화 복합소재 → 고소작업차(AWP) 붐/Arm 경량화
- **AI/DT closed-loop** : 경량 붐의 강성·진동·전복 특성을 DT 동역학 모델에 반영 → 능동안전(전복방지) 제어 재설계 → 실차 검증 → 소재 환류
- **실증** : 진우에스엠씨 고소작업차 실차, 익산, 작업반경·지지상태별 전복위험·정렬/조준 안정성 시험
- **소방/방재 연계** : 경량 붐으로 작업반경·가반하중 확대 → 소방/방재 AWP 자율분사·원격작업 적용
- *그림안 : 경량 붐 구조 + 전복안정성 DT 시뮬레이션 + 작업반경 안전맵*

**② 초경량·고강도 복합소재 작업장치(암·버킷) 적용 자율 굴착기 실증**
- **복합소재 연계** : 경량·고강도 복합소재 → 굴착기 암·버킷 등 작업장치 경량화
- **AI/DT closed-loop** : 경량화에 따른 작업장치 동특성·작업정밀도 변화를 DT에 반영 → 자율작업 제어·인식 파라미터 재검증 → 실차 검증 → 소재 환류
- **실증** : 30톤급 굴착기 실차, 한건연 군산 본원 시험장, 작업정밀도(geometric RMS)·cycle time·가반하중(페이로드) 효율 측정
- *그림안 : 경량 작업장치 구조 + 동특성 DT + 작업정밀도/가반하중 Before/After 그래프*

### ◾ 2순위 — 딥테크 지역 확산의 실증

**③ 새만금·나포 실증베드 토사 물성 상호작용 자율 굴착 실증**
- **AI/DT** : 토사 반력·물성(마사토·자갈) 상호작용 모델(Algoryx AGX) + DT 기반 자율 굴착 정책 학습(Sim-to-Real) → 실차 무인 굴착 검증
- **실증** : 새만금 매립지 마사토 베드 + 군산 나포 자갈 베드 / 지표 = 작업완료율·cycle time·geometric RMS·safety event rate *(ETHZ Hutter 그룹 표준 지표 — Physical AI 벤치마크 근거)*
- **지역확산** : 전북 건설기계 클러스터 자율작업 전환 거점
- *그림안 : 실증베드 위성도 + 토사 상호작용 시뮬레이션 + 무인 굴착 KPI 대시보드*

**④ 김제 특장차산업단지 연계 이기종 협력 자율작업 실증**
- **AI/DT** : 다채널 센서·VLA pipeline(KETI 원천 + 한건연 도메인 특화) + 굴착기–특장차 이기종 협력 제어, 디지털 트윈 연계 검증
- **실증** : 김제 특장차산업단지 30개사 이상 협력, 안전(KS B ISO 17757) 적합성·작업환경 인식 검증
- **지역확산** : 특장차 클러스터 확산 + 전북대·군산대 인력양성 연계
- *그림안 : 단지 배치도 + 이기종 협력 작업 + 안전 인증 항목 체크리스트*
