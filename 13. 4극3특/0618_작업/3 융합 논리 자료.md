## 1. 과제간 연계성 및 융합 논리 모형 (한건연)

```
                         [KIST] 복합소재 원천기술
                  (EMI 차폐 · 방열 · 초경량고강도 · 내화/차열)
                              │ 소재 적용 ▼        ▲ 소재 환류(closed-loop)
┌──────── 과제3 : 비정형 환경 무인 자율작업 핵심기술 (예비+본연구 통합) ────────┐
│  주관: 생기원      공동: 한국건설기계연구원      공동: 한국전자기술연구원(KETI) │
│  도메인: 농기계      도메인: 건설기계(굴착기·AWP)    도메인: 특장차·센서/통신/VLA │
│  [공통 핵심기술 4종을 도메인별 평행 개발]                                       │
│   ① 비정형 인지·시맨틱  ② 자율작업 프레임워크  ③ DT 시뮬레이터  ④ 실작업데이터·실–가상검증 │
└──────────┬───────────────────────┬───────────────────────┬───────────────────┘
           │ 농기계                  │ 건설기계 (한건연 트랙)    │ 특장차
           ▼                         ▼                         ▼
   과제7 : 농기계 사업화     ★ 과제8 : 초경량·고정밀 자율작업      과제9 : 특수목적차량
      (생기원)               건설기계 사업화 (한건연 주관)          작업안전·사업화 (KETI)
                            → 소방/방재 AWP : DT 원격작업·
                              능동안전(전복방지)·자율분사 상용화
```

**핵심 메시지**
- **세로 연계성** : 한건연은 과제3에서 *건설기계 도메인 핵심기술*을 공동개발 → 과제8에서 *AWP/소방 건설기계 사업화*로 직결 → **"핵심기술 개발 → 사업화" 단일 트랙**
- **가로 연계성** : 과제3의 동일 4대 핵심기술을 농기계(생기원)·건설기계(한건연)·특장차(KETI)가 **도메인별 평행 개발** → 중복 아닌 분담
- **closed-loop** : 복합소재 적용 → 시스템(열·EMI·강성) 변화 → 디지털 트윈 반영 → AI 자율작업 재학습 → 실차 검증 → 소재 환류

## 3. 실증 항목별 상세 및 그림안

### ◾ 1순위 — 복합소재 적용과 연계한 실증

**① EMI 차폐 복합소재 적용 자율 굴착기 통신간섭 제거**
- **복합소재 연계** : KIST 선택적 EMI 차폐 소재 → 전동화 제어 함체·자율주행 센서 함체에 적용
- **AI/DT closed-loop** : 차폐 소재 변경 → 시스템 배치·열·EMI 변화를 DT에 반영 → 자율주행 인식 안정성 재검증 *(KETI 텔레핸들러 CAN/통신 오류 해소 사례의 건설기계 확장)*
- **실증** : 30톤급 굴착기 실차, 한건연 군산 본원 시험장, CAN·통신 오류율 Before/After 정량 측정
- *그림안 : 차폐 함체 단면 + DT 화면 + 오류율 Before/After 그래프*

**② 초경량·고강도 복합소재 붐(Arm) 적용 AWP 디지털 트윈 실증**
- **복합소재 연계** : 초고강도·경량 소재 → 고소작업차 붐/Arm 경량화
- **AI/DT closed-loop** : 경량 붐의 강성·진동·전복 특성을 DT 동역학 모델에 반영 → 능동안전(전복방지) 제어 재설계 → 실차 검증
- **실증** : 진우에스엠씨 고소작업차 실차, 익산, 작업반경·지지상태별 전복위험·정렬/조준 안정성 시험
- *그림안 : 경량 붐 구조 + 전복안정성 DT 시뮬레이션 + 작업반경 안전맵*

**③ 내화/차열 복합소재 분사모듈 적용 소방 AWP 자율분사 실증**
- **복합소재 연계** : 내화/차열 소재 → 소방 분사모듈 장착부
- **AI/DT closed-loop** : 화재 고온환경 소재 거동을 DT 반영 → 열화상+RGB 융합 화재영역 인지 → 자율/원격 정밀 분사 제어 검증
- **실증** : 소방/방재 임무 시나리오(접근–정렬–분사–이탈), 전북 소방 실증환경/규제자유특구 연계, 화점 인식률·분사 정확도
- *그림안 : 화재현장 모식 + 열화상 인지 + 원격 마스터 작업기 + 자율 분사 궤적*

**④ 열관리·방열 복합소재 적용 전동 자율 건설기계 장기운전 실증**
- **복합소재 연계** : 열관리·방열/에너지 소재 → 전동화 파워트레인·배터리 함체
- **AI/DT closed-loop** : 방열 소재 적용 전후 열적 거동을 DT로 예측 → 장기 자율작업 시 열 안정성·가동률 검증
- **실증** : 전동 굴착기/특장차 장기 자율작업, 한건연 군산 본원, 온도·연속가동률 측정
- *그림안 : 방열 소재 적용부 + 열 분포 DT 히트맵 + 가동률 곡선*

### ◾ 2순위 — 딥테크 지역 확산의 실증

**⑤ 새만금·나포 실증베드 토사 물성 상호작용 자율 굴착 실증**
- **AI/DT** : 토사 반력·물성(마사토·자갈) 상호작용 모델(Algoryx AGX) + DT 기반 자율 굴착 정책 학습(Sim-to-Real) → 실차 무인 굴착 검증
- **실증** : 새만금 매립지 마사토 베드 + 군산 나포 자갈 베드 / 지표 = 작업완료율·cycle time·geometric RMS·safety event rate *(ETHZ Hutter 그룹 표준 지표 — Physical AI 벤치마크 근거)*
- **지역확산** : 전북 건설기계 클러스터 자율작업 전환 거점
- *그림안 : 실증베드 위성도 + 토사 상호작용 시뮬레이션 + 무인 굴착 KPI 대시보드*

**⑥ 김제 특장차산업단지 연계 이기종 협력 자율작업 실증**
- **AI/DT** : 다채널 센서·VLA pipeline(KETI 원천 + 한건연 도메인 특화) + 굴착기–특장차 이기종 협력 제어, 디지털 트윈 연계 검증
- **실증** : 김제 특장차산업단지 30개사 이상 협력, 안전(KS B ISO 17757) 적합성·작업환경 인식 검증
- **지역확산** : 특장차 클러스터 확산 + 전북대·군산대 인력양성 연계
- *그림안 : 단지 배치도 + 이기종 협력 작업 + 안전 인증 항목 체크리스트*
