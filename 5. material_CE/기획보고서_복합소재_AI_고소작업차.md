## 제1장 사업 필요성

### 1. 사업진행 당위성

---

#### ❑ 글로벌 고소작업차 시장의 급성장과 국내 기업의 기회

❍ 전 세계 고소작업차(Aerial Work Platform, AWP) 시장은 급격한 성장세를 보이고 있음

- 글로벌 고소작업차 시장 규모는 2025년 기준 약 **544억 5천만 달러**(약 72조원)로 추산되며, 연평균 **8.2% 이상**의 성장률을 기록하여 2035년에는 약 **1,197억 5천만 달러**(약 160조원)에 이를 것으로 전망됨 (출처: Research Nester)
- 특히 아시아 태평양 지역은 창고 인프라의 급속한 확장에 힘입어 2035년까지 전체 고소작업차 시장의 **40%**를 점유할 것으로 예상됨

❍ 고소작업차 수요 증가의 핵심 동인

| 동인 | 설명 |
|------|------|
| **도시화 가속** | 고층 건물 증가로 인한 외벽 청소, 유지보수 수요 확대 |
| **인프라 투자 확대** | 통신(5G 기지국), 전력망, 교량 점검 등 인프라 수요 증가 |
| **안전 규제 강화** | 고소작업 시 추락 재해 방지를 위한 장비 사용 의무화 |
| **노동력 고령화** | 사다리 대신 고소작업차 사용 증가 |
| **물류 창고 확대** | 대형 물류센터 내 고소 피킹 작업 증가 |

❍ 국내 고소작업차 시장에서 전북 지역 기업의 선도적 위치

- **호룡**(익산 소재)은 고소작업차 SKY 시리즈로 **국내 시장 점유율 1위**를 차지하고 있으며, 2025년 코스닥 상장을 추진하는 등 활발한 기업 활동을 이어가고 있음 (출처: 모멘스인사이트, 2025)
- 호룡은 1990년 설립 이후 고소작업차, 콘크리트펌프카, 사다리차 등 특장차 및 건설기계 분야에서 전문성을 보유하고 있음
- 이러한 국내 1위 기업이 전북 익산에 소재한다는 점은 본 사업의 **지역 연계성** 측면에서 최적의 조건을 갖추고 있음

---

#### ❑ 고소작업차에서 경량화가 특히 의미 있는 이유

❍ 고소작업차는 건설기계 중에서 **경량화 효과가 가장 직접적으로 나타나는** 장비임

고소작업차의 구조적 특성상, 작업대(바스켓)와 붐의 중량은 장비의 핵심 성능 지표에 직접적인 영향을 미침:

| 성능 지표 | 경량화 효과 | 설명 |
|----------|-----------|------|
| **작업 반경** | ✅ 확대 | 동일 차량 기반에서 더 높이, 더 멀리 도달 가능 |
| **안정성** | ✅ 향상 | 상부 중량 감소로 전복 모멘트 감소 |
| **탑승 인원** | ✅ 증가 | 허용 하중 여유 증가로 작업자 추가 탑승 가능 |
| **연비** | ✅ 개선 | 붐 작동 시 유압 에너지 소비 감소 |
| **차량 등급** | ✅ 하향 | 경량화로 소형 차량 기반 적용 가능 |

❍ 고소작업차 작업대의 현재 구조와 경량화 잠재력

- 현재 고소작업차 작업대(바스켓)는 대부분 **강철 구조물**로 제작되어 있으며, 안전 난간, 바닥판, 조작 패널 등이 통합된 형태임
- 30m급 고소작업차 기준, 작업대 중량은 약 **200~400kg** 수준이며, 붐 말단에 위치하여 전체 시스템에 미치는 영향이 큼
- 붐은 다단 신축 구조(telescopic boom)로, 최말단 섹션부터 경량화 적용 시 효과가 극대화됨

❍ 복합소재(CFRP) 적용 시 기대되는 경량화 효과

| 부품 | 현재 소재 | CFRP 적용 시 | 경량화율 |
|------|----------|-------------|---------|
| 작업대(바스켓) | 강철 | CFRP 복합재 | **30~50%** |
| 붐 말단 섹션 | 강철 | 하이브리드 | **20~30%** |
| 안전 난간 | 강철/알루미늄 | CFRP | **40~50%** |

#### ❑ AI 안전제어 기술의 필요성

❍ 고소작업차 사고의 주요 원인과 AI 기술의 역할

고소작업차 관련 중대재해는 주로 **전복**, **추락**, **충돌**에서 발생하며, 이러한 사고의 상당 부분은 **실시간 상황 인지 부족**에 기인함:

| 사고 유형 | 원인 | AI 기술 적용 방안 |
|----------|------|-----------------|
| **전복** | 과적, 불안정 지반, 급작동 | 실시간 하중·기울기 모니터링, 자동 제한 |
| **추락** | 안전장치 미착용, 과도한 리치 | 작업반경 자동제한, 경고 시스템 |
| **충돌** | 장애물 미인지, 시야 사각 | 센서 기반 장애물 감지, 자동 정지 |
| **협착** | 붐 작동 중 끼임 | 근접 센서, 안전 인터록 |

❍ AI 기반 안전제어 시스템의 핵심 기능

```
┌─────────────────────────────────────────────────────────────┐
│              AI 안전제어 시스템 아키텍처                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   [센서 레이어]                                             │
│      │                                                      │
│      ├─ IMU (기울기 센서) ─── 차량 자세 실시간 감지         │
│      ├─ 로드셀 (하중 센서) ─── 작업대 탑승자·하중 측정      │
│      ├─ 근접 센서 ─────────── 장애물·사람 감지              │
│      └─ GPS/RTK ────────────── 작업 위치·높이 추적          │
│                                                             │
│   [AI 분석 레이어]                                          │
│      │                                                      │
│      ├─ 전복 위험도 예측 모델                               │
│      ├─ 작업반경 자동계산 알고리즘                          │
│      └─ 이상 상황 조기 경보 시스템                          │
│                                                             │
│   [제어 레이어]                                             │
│      │                                                      │
│      ├─ 작업반경 자동제한 (Over-reach Protection)           │
│      ├─ 과적 시 동작 제한 (Overload Protection)             │
│      └─ 비상 정지 및 안전 하강                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

❍ 경량화와 AI 안전제어의 시너지

- **경량화**로 인해 작업반경이 확대되면, AI 시스템이 확대된 작업 영역을 **실시간으로 계산**하여 안전한 작업 범위를 자동으로 설정
- 경량 복합소재 구조물에 **센서 통합 설계**가 가능하여, 기존 강철 구조물 대비 더 정밀한 상태 모니터링 구현
- AI 시스템은 작업대의 하중 변화를 감지하여 **적응형 작업반경 조절**을 수행

#### ❑ 전북 지역 산업 생태계와의 연계

❍ 본 사업은 전북 지역의 핵심 산업 자원과 긴밀하게 연계됨

| 기관/기업 | 역할 | 소재지 | 연계 강점 |
|----------|------|--------|----------|
| **호룡** | 고소작업차 제조 | **익산** | 국내 시장 점유율 1위, 실증 플랫폼 제공 |
| **KIST 전북분원** | 복합소재 연구 | 완주 | 소재 물성 분석, 구조 해석 |
| **탄소융합연구원** | 탄소소재 제조 | 전주 | CFRP 성형 기술, 시제품 제작 |
| **한국건설기계연구원** | AI 제어, 안전 | 전북 | 안전제어 알고리즘, 실증 검증 |
| **전북 지역 대학** | 인력 양성 | 전북 | 석·박사 연구인력 |

❍ 전북 지역은 국가 탄소산업 클러스터로 지정되어 있으며, 복합소재 연구 인프라가 집적되어 있음

- KIST 전북분원, 탄소융합연구원, 생기원 전북본부 등이 반경 30km 이내에 위치
- 호룡(익산)과의 협력을 통해 **연구개발-실증-양산**의 전 주기를 지역 내에서 완결할 수 있는 최적의 조건

### 2. 결론

본 사업은 급성장하는 글로벌 고소작업차 시장에서 국내 1위 기업(호룡)이 소재한 전북 지역의 산업 생태계를 활용하여, **복합소재 경량화**와 **AI 안전제어** 기술을 개발하고자 함. 고소작업차는 경량화 효과가 가장 직접적으로 나타나는 건설기계로, 복합소재 적용 시 작업반경 확대, 안정성 향상, 연비 개선 등의 다중 효과를 기대할 수 있음. 이를 통해 국내 고소작업차 산업의 글로벌 경쟁력을 강화하고, 전북 지역 경제 활성화에 기여하고자 함.

### 3.2 세부과제별 연구 내용

#### 1세부과제: 복합소재 작업대 설계 및 제조

**주관: KIST 전북분원, 탄소융합연구원**

| 단계 | 연구 내용 | 산출물 |
|------|----------|--------|
| **1단계** (Y1) | 작업대 하중 해석, CFRP 물성 분석, 구조 설계 | 설계안 |
| **2단계** (Y2) | 작업대 시제품 제작, 안전 난간 통합 설계 | 시제품 |
| **3단계** (Y3) | 붐 말단 섹션 경량화, 금속-복합재 접합 | 붐 시제품 |
| **4단계** (Y4) | 양산 공정 개발, 품질 검증 | 양산 프로토 |

**핵심 기술요소**:
- CFRP 플랫폼 구조 설계 및 제조
- 안전 난간·조작 패널 통합 설계
- 금속-복합소재 하이브리드 접합 기술
- 반복 하중에 대한 피로 내구성 확보

#### 2세부과제: AI 안전제어 시스템 개발

**주관: 한국건설기계연구원**

| 단계 | 연구 내용 | 산출물 |
|------|----------|--------|
| **1단계** (Y1) | 센서 시스템 설계, 데이터 수집 체계 구축 | 센서 시스템 |
| **2단계** (Y2) | 전복예측 AI 모델 개발, 작업반경 알고리즘 | AI 알고리즘 |
| **3단계** (Y3) | 실장비 탑재, 필드 테스트 | 제어 시스템 |

- 다중 센서 융합 기반 상태 인식

- 적응형 작업반경 자동제한 알고리즘
- 실시간 경고 및 비상 제어 시스템

## 제5장 기대 효과

### 5.1 기술적 효과

❍ **원천기술 확보**
- 고소작업차용 CFRP 구조물 설계·제조 원천기술

### 5.3 사회적 효과

❍ **안전성 향상**
