# ○ A기술분야 과제별 세부 내용(과제별 작성)

## - 목표 : 자율 작업 굴착기 개발을 위한 디지털 트윈 환경 및 굴착기 통합 모델 개발

## ○ (자율작업 굴착기 기술 개발)

예비 사업('26.7~12)에서 구축한 **30톤급 굴착기 실차 데이터 취득 시스템, 표준 작업환경, 빅데이터 관리 시스템**의 성과를 기반으로, 디지털 트윈 기반 굴착기 통합 모델과 토사–장비 상호작용 시뮬레이션 환경을 구축하여, 무인·자율 작업 굴착기 개발을 위한 핵심 원천기술을 확보하고 건설기계 산업의 디지털 전환 및 자율화 경쟁력 강화를 목표로 함.

> **[그림 1] 예비 사업–본 과제 연계 전체 시스템 아키텍처** (별도 첨부)

---

## - 상세 수행 내용

### 1. 굴착기 실차 기반 디지털 트윈 모델 구축

실차 장비의 기구학·동역학 모델을 기반으로 가상 환경 내 디지털 트윈을 구축하고, 실차 센서 데이터와의 동기화 정합성 검증을 수행한다.

- 유압, 파워트레인, 전기·전자, 제어 등 굴착기 도메인별 모델의 구조 정의 및 모듈간 인터페이스 연계
- 실차 센서 데이터(관절각, 유압 압력, IMU, GNSS 등)를 활용한 모델 파라미터 캘리브레이션
- 도메인별 기본 모델 개발 및 통합 아키텍처 확립
- 디지털 트윈–실차 간 동기화 정합성 검증 프레임워크 구축 (시간 동기화 오차 ≤ 10ms 목표)

> ※ **예비 사업 연계**: 다채널 데이터 취득 시스템에서 수집된 조작 입력, 관절각, 유압 압력, 자세/위치 데이터를 디지털 트윈 모델의 입력 및 검증 데이터로 직접 활용

> **[그림 2] 굴착기 디지털 트윈 통합 모델 개념도** (별도 첨부)

### 2. 토사 물성 및 굴착기–환경 상호작용 모델 개발

다양한 토사 환경에서의 굴착기 작업을 정밀하게 시뮬레이션하기 위한 물리 기반 상호작용 모델을 개발한다.

- 토사 유형(진흙, 모래, 자갈, 풍화암 등)별 물성 데이터 수집 및 물리 기반 모델링
- 굴착·적재·선회·평탄화 작업별 굴착기–토사 상호작용 모델 구현
- FEM/DEM 기반 토사 거동 시뮬레이션 모델 개발 및 실측 데이터 비교 검증
- 토사 물성 변화(수분 함유량, 다짐도 등)에 따른 작업 하중 예측 모델 개발

> ※ **예비 사업 연계**: 표준 작업환경에서 토양 조건별(모래, 자갈, 토사)로 수집된 반복 데이터를 상호작용 모델 파라미터 튜닝 및 검증에 활용

### 3. 가상 학습 시스템 구축

예비 사업에서 취득한 실차 작업 세션 데이터를 가상 환경에서 재현하고, 자율작업 알고리즘 학습에 활용할 수 있는 체계적인 데이터 관리·학습 시스템을 개발한다.

- 실차 취득 세션의 가상 환경 리플레이 시스템 개발 (Real-to-Sim 재현)
- 토양별·시나리오별(굴착, 이송, 적재, 평탄화) 세션 분류 및 가상 작업 재현
- 학습용 데이터셋 패키징·버전 관리(v1.0, v1.1 …) 시스템 개발
- Sim-to-Real / Real-to-Sim 전이 학습 파이프라인 구축
- Domain Randomization 기반 학습 데이터 증강 기법 적용

> ※ **예비 사업 연계**: 빅데이터 관리 시스템에서 축적된 세션 메타 정보(작업 유형, 토양 종류, 장비 상태, 시나리오 ID 등)를 학습 데이터셋 원천 및 분류 기준으로 직접 활용

> **[그림 3] 자율작업 알고리즘 학습·검증 파이프라인** (별도 첨부)

### 4. 디지털 트윈 기반 자율작업 알고리즘 개발

모방학습·강화학습을 활용하여 굴착기 자율작업 경로를 생성하고, 생성된 경로에 대한 추종 알고리즘을 개발·검증한다.

- 모방학습(Imitation Learning) 기반 자율 굴착·적재 경로 생성 알고리즘 개발
  - 작업자 숙련 데이터 기반 행동 복제(Behavioral Cloning) 및 역강화학습(IRL) 적용
- 강화학습(RL) 기반 자율작업 정책 최적화
  - 작업 효율(연료 소비, 작업 시간, 버킷 적재율 등) 기반 보상 함수 설계
  - 다양한 토양·지형 조건에서의 범용 자율작업 정책 학습
- 생성된 경로에 대한 추종 알고리즘 개발 및 시뮬레이션 기반 검증
- 실차 기반 자율작업 알고리즘 성능 검증 (작업 정확도, 안정성, 효율성)
- 가상 작업 시나리오 기반 조건별(토양, 지형, 장애물 등) 자율작업 성능 평가

### 5. 실장비 연동 및 무인 자율 굴착기 구현·실증

디지털 트윈 환경과 실 굴착기 제어 시스템을 실시간 연동하고, 단계적으로 무인 자율 굴착 작업을 구현·실증한다.

- 디지털 트윈 환경과 실 굴착기 제어 시스템 실시간 연동 인터페이스 구축
- HIL(Hardware-in-the-Loop) 시뮬레이션 기반 사전 검증
- 준실장비(축소 장비) 수준의 무인 자율 굴착 작업 시연 (1~2차년도)
- 실장비(30톤급) 수준의 무인 자율 굴착 작업 시연 (3~4차년도)
- 디지털 트윈–실장비 간 거동 오차 분석 및 모델 고도화 (피드백 루프)
- 현장 실증을 통한 TRL 6~7 수준 기술 검증
