## 아이디어 1: 복합소재 고소작업차 작업대 (최우선 추천)

### 기본 정보

| 구분 | 내용 |
|------|------|
| **아이디어 명칭** | 복합소재 기반 경량 고강도 고소작업차 작업대 개발 |
| **적용 대상 기계** | 고소작업차 (Aerial Work Platform) |
| **목표 스펙** | 작업대 중량 30% 경량화, 작업 범위 20% 확장 |

### 기술적 차별성

❍ **경량화의 직접적 효과**

고소작업차는 경량화가 **가장 의미 있는** 건설기계 중 하나:

| 효과 | 설명 |
|------|------|
| 작업 반경 확대 | 동일 차량에서 더 높이, 더 멀리 작업 가능 |
| 안정성 향상 | 전복 모멘트 감소 |
| 탑승 인원 증가 | 허용 하중 여유 증가 |
| 연비 개선 | 붐 작동 에너지 절감 |

❍ **핵심 기술 요소**

1. **CFRP 작업대**: 경량화 + 고강도 + 내충격성
2. **복합재 붐 구조**: 단계적 경량화 (작업대 → 붐)
3. **AI 안전제어**: 작업 반경·하중 실시간 모니터링

### 전북 지역 연계성

| 기업/기관 | 역할 | 비고 |
|----------|------|------|
| **호룡** (익산) | 고소작업차 제조 | 국내 대표 업체 |
| KIST 전북분원 | 복합소재 설계 | 소재 연구 |
| 탄소융합연구원 | 제조 공정 | 성형 기술 |
| 한건연 | AI 제어·실증 | 안전시스템 |

### 예상 핵심 기술

```
┌─────────────────────────────────────────┐
│     복합소재 고소작업차 기술 구성도      │
├─────────────────────────────────────────┤
│                                         │
│   [복합소재 작업대]                     │
│      │                                  │
│      ├─ CFRP 플랫폼 구조               │
│      ├─ 안전 난간 통합 설계            │
│      └─ 금속-복합재 접합부             │
│                                         │
│   [경량 붐 시스템] (2단계)              │
│      │                                  │
│      ├─ 하이브리드 붐 구조             │
│      └─ 적층 최적화 설계               │
│                                         │
│   [AI 안전제어]                         │
│      │                                  │
│      ├─ 실시간 하중 모니터링           │
│      ├─ 작업반경 자동제한              │
│      └─ 전복방지 경고시스템            │
│                                         │
└─────────────────────────────────────────┘
```

### 추진 일정 (안)

| 연차 | 개발 내용 | 산출물 |
|------|----------|--------|
| 1차년도 | 작업대 설계, 소재 물성 분석 | 설계안 |
| 2차년도 | 작업대 시제품 제작 및 시험 | 시제품 |
| 3차년도 | 실장비 탑재, 필드 테스트 | 실증 결과 |
| 4차년도 | 양산성 검증, 인증 준비 | 양산 프로토 |

### 참여기관 역할 제안

| 기관 | 역할 | 예산 비율 |
|------|------|----------|
| KIST 전북분원 | 복합소재 설계·해석 | 25% |
| 탄소융합연구원 | 제조 공정, 시제품 | 30% |
| 한건연 | AI 안전제어, 실증 | 30% |
| 호룡 (기업) | 장비 제공, 상용화 | 15% |

## 아이디어 2: AI 연비최적화 펌프카

### 기본 정보

| 구분 | 내용 |
|------|------|
| **아이디어 명칭** | AI 기반 연비최적화 콘크리트 펌프카 시스템 |
| **적용 대상 기계** | 콘크리트 펌프카 (32~56m급) |
| **목표 스펙** | 붐 작동 연비 20% 개선, 복합소재 부분 적용 |

### 기술적 차별성

❍ **펌프카의 특성**

- 붐이 매우 길고 (32~56m), 작동 빈도 높음
- 붐 전개/수납 시 대량의 유압 에너지 소모
- 복합소재 적용 시 효과가 큰 분야

❍ **핵심 기술 요소**

1. **경량 붐 섹션**: 말단부터 단계적 복합소재 적용
2. **AI 최적경로 제어**: 콘크리트 타설 동선 최적화
3. **에너지 회생**: 붐 하강 시 에너지 회수

### 전북 지역 연계성

- 직접적인 펌프카 제조사는 전북에 없음
- 그러나 복합소재 연구 역량(KIST, 탄소융합)과 연계 가능
- 타 지역 기업(에버다임 등)과의 협력 필요

### 추진 일정 (안)

| 연차 | 개발 내용 |
|------|----------|
| 1~2차년도 | 붐 말단부 경량화, AI 알고리즘 개발 |
| 3~4차년도 | 실장비 실증, 양산성 검증 |

## 아이디어 3: 경량 소방특수차량

### 기본 정보

| 구분 | 내용 |
|------|------|
| **아이디어 명칭** | 복합소재 기반 경량 소방 사다리차/크레인 |
| **적용 대상 기계** | 소방 사다리차, 소방 크레인 |
| **목표 스펙** | 구조물 중량 25% 경량화, 작업 높이 확장 |

### 기술적 차별성

❍ **소방차량의 특수성**

- 긴급 출동 → 경량화로 기동성 향상
- 작업 높이 한계 → 경량화로 도달 범위 확장
- 고가의 특수 장비 → 비용보다 성능 우선

❍ **핵심 기술 요소**

1. **CFRP 사다리 구조**: 고강도 경량 사다리
2. **복합소재 바스켓**: 구조 인원용 작업대
3. **AI 안전제어**: 풍압·하중 실시간 모니터링

### 전북 지역 연계성

| 기업 | 위치 | 분야 |
|------|------|------|
| **광림** (익산 인접) | 소방차량 | 국내 소방차 시장 점유율 높음 |

> *통화 내용 참조: 익산에 소방 크레인/사다리차 제조 업체 있음*

### 추진 일정 (안)

| 연차 | 개발 내용 |
|------|----------|
| 1~2차년도 | 사다리/바스켓 복합소재 설계 및 제작 |
| 3~4차년도 | 실차량 탑재 실증, 소방 인증 |
