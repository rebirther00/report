# Cursor Prompt: 과기부 지역사업 건설기계 R&D 기획서 작성

## 역할 정의

너는 건설기계 R&D 기획 전문가이다. 정부 과제 기획서 작성 경험이 풍부하며, 복합소재/인공지능/모빌리티 분야의 기술 동향을 잘 알고 있다.

---

## 프로젝트 배경

### 사업 개요
- **주관기관**: KIST 전북분원
- **참여기관**: 탄소융합연구원, 한국건설기계연구원, 한국생산기술연구원 전북, 한국전자기술연구원, 전북 지역 대학/기업
- **예산**: 4년 300억 + 도비 매칭
- **시작**: 2026년 7월
- **1차년도**: 6개월, 약 88억 (학교 50억 / 사업화 50억 / R&D 100~150억 추정)

### 핵심 키워드
- 첨단소재 (복합소재, 경량, 고강도)
- 인공지능
- 모빌리티

### 사업 특성
- 과기부 사업으로 산업부 대비 사업성 압박이 상대적으로 낮음
- 전라북도 소재 기업/기관 참여 필수

---

## 기본 아이디어 (확장 대상)

### 아이디어 1: 복합소재 기반 경량화
- 굴착기 붐/암/버킷을 복합소재로 대체
- 경량화 및 고강도 실현
- 동일 작업 시 연비 효율 향상

### 아이디어 2: AI 부하감응 제어
- 인공지능 기반 실시간 부하 감지
- 최적 경로 계획 및 제어
- 동일 굴착 작업 시 연비 효율 향상

### 통합 아이디어
**복합소재 + AI 기술 결합 → 무인 작업 굴착기 → 연비 효율 극대화**

---

## 작업 요청

### Task 1: 기본 아이디어 확장 기획서

위 기본 아이디어를 기반으로 아래 구조의 기획서를 작성하라:

```
1. 사업 필요성
   - 국내외 건설기계 시장 동향
   - 탄소중립/친환경 규제 동향
   - 복합소재 적용 필요성
   - AI 자율화 기술 필요성

2. 기술 개발 목표
   - 정량적 목표 (경량화율, 연비개선율, 자율화 수준 등)
   - 정성적 목표

3. 연구 내용
   - 복합소재 모듈 개발 (붐/암/버킷)
   - AI 부하감응 제어 시스템 개발
   - 통합 시스템 및 실증

4. 추진 체계
   - 기관별 역할 분담
   - 연차별 추진 계획

5. 기대 효과
   - 기술적 효과
   - 경제적 효과
   - 사회적 효과 (탄소저감 등)
```

### Task 2: 추가 아이디어 제안 및 기획서

한국건설기계연구원이 추가로 수행 가능한 아이디어를 제안하라.

#### 고려 조건
- 복합소재 + AI 활용 가능 영역
- 건설기계/특수목적기계 범위: 굴착기, 고소작업차, 크레인카, 펌프카 등
- 전북 지역 기업 협력 가능성
- 4년 내 실증 가능한 현실적 수준

#### 제안 시 포함 사항
- 아이디어 명칭
- 기술적 차별성
- 적용 대상 기계
- 예상 핵심 기술
- 참여기관 역할 제안
- 간략 추진 일정

## 참고 자료

아래 첨부된 파일을 반드시 참고하라:
- 본부장 통화 요약본
- 통화 전체 텍스트

## 출력 형식

- 한글로 작성
- Markdown 형식
- 기획서 형태 (목차, 표, 그림 설명 포함 가능)
- 근거 없는 수치는 "추정" 또는 "목표(안)"으로 명시
- 각 섹션별 분량: 적정 수준 (과도한 나열 금지)

---

## 주의사항

1. 허위 정보 작성 금지. 불확실한 내용은 "추정" 또는 "추가 확인 필요"로 표기
2. 과기부 과제 특성상 원천기술 개발 관점 강조
3. 전북 지역 산업 연계성 명시
4. 참여기관(탄소융합연구원, 생기원, 전자연 등)의 강점 고려하여 역할 배분
5. 굴착기 외 타 기종 확장 가능성 열어둘 것
